# Vaktermen en vakwerkwoorden

Elk van deze vaktermen heeft in deze handleiding maar één betekenis. Elke taalversie van deze handleiding gebruikt voor elke vakterm maar één naam.

## Vaktermen

| Term | Definitie |
| --- | --- |
| app | Het programma Logic Analyze. |
| buffermodus | De bedrijfsmodus waarin het apparaat de samples tot het einde van de opname in het geheugen houdt. |
| opname | Eén registratie van de signalen, van de start tot de stop. |
| kanaal | Eén ingang van het apparaat en de rij die de gegevens ervan toont. |
| kanaalmodus | De instelling die het aantal kanalen en de maximale samplefrequentie selecteert. |
| cursor | Een verticale lijn op één tijd in de opname. U gebruikt cursors voor metingen. |
| decoder | Een deel van de app dat de gegevens leest en de frames van een protocol vindt. |
| demo-apparaat | Een apparaat in de app dat testsignalen maakt. Het heeft geen hardware. |
| apparaat | De logische analyser DSLogic of de oscilloscoop DSCope. |
| dock | Een paneel aan de zijkant van het golfvormgebied. |
| flank | Een overgang van een laag niveau naar een hoog niveau (stijgende flank) of van een hoog niveau naar een laag niveau (dalende flank). |
| massa | Het 0 V-punt van een schakeling. |
| niveau | De toestand van een digitaal signaal: hoog of laag. |
| meetdraad | De draad of de klem die een kanaal met de schakeling verbindt. |
| protocol | De specificatie voor gegevens op een bus, bijvoorbeeld UART, I2C of SPI. |
| puls | Een niveau tussen twee flanken. |
| sample | De waarde van een kanaal op één tijd. |
| sampleduur | De tijdsduur van een opname. |
| samplefrequentie | Het aantal samples per seconde voor elk kanaal. |
| sessie | Een bestand met de instellingen van de app en van het apparaat. |
| instelling | Een waarde die u in de app kunt wijzigen. |
| streammodus | De bedrijfsmodus waarin het apparaat de samples tijdens de opname naar de computer stuurt. |
| drempel | De spanning die een laag niveau van een hoog niveau scheidt. |
| tijdliniaal | De tijdschaal boven het golfvormgebied. |
| trigger | Een voorwaarde in de signalen die een tijd in de opname markeert. |
| triggerpositie | De positie van het triggerpunt in de opname, als percentage van de sampleduur. |
| golfvorm | De lijn die het signaal van een kanaal toont. |
| golfvormgebied | Het deel van het venster dat de golfvormen toont. |

## Vakwerkwoorden

| Werkwoord | Definitie |
| --- | --- |
| opnemen | De signalen met het apparaat registreren. |
| klikken | Een muisknop indrukken en loslaten. |
| decoderen | Gegevens lezen en de frames van een protocol vinden. |
| dubbelklikken | Twee keer snel klikken. |
| slepen | Een item bewegen terwijl u de muisknop ingedrukt houdt. |
| exporteren | Gegevens opslaan in een formaat voor een ander programma. |
| drukken | Een toets op het toetsenbord indrukken. |
| samplen | De waarde van een signaal op één tijd lezen. |
| typen | Tekst schrijven met het toetsenbord. |
| inzoomen, uitzoomen | Een korter of een langer deel van de golfvorm tonen. |
