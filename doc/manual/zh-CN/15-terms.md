# 技术名称和动词

在本手册中，以下每个技术名称只有一个含义。本手册的每个语言版本对每个技术名称只使用一个译名。

## 技术名称

| 名称 | 定义 |
| --- | --- |
| 应用 | Logic Analyze 程序。 |
| Buffer模式 | 一种运行模式。在此模式下，设备把采样点保存在内存中，直到采集结束。 |
| 采集 | 从开始到停止对信号的一次记录。 |
| 通道 | 设备的一个输入，以及显示其数据的行。 |
| 通道模式 | 选择通道数和最高采样率的设置。 |
| 光标 | 采集中某一时间处的一条竖线。光标用于测量。 |
| 解码器 | 应用中读取数据并找到协议帧的部分。 |
| 演示设备 | 应用中产生测试信号的设备。它没有硬件。 |
| 设备 | DSLogic 逻辑分析仪或 DSCope 示波器。 |
| 停靠面板 | 波形区旁边的面板。 |
| 边沿 | 从低电平到高电平的变化（上升沿），或从高电平到低电平的变化（下降沿）。 |
| 地 | 电路的 0 V 点。 |
| 电平 | 数字信号的状态：高或低。 |
| 探头 | 把通道连接到电路的线或夹子。 |
| 协议 | 总线上数据的规范，例如 UART、I2C 或 SPI。 |
| 脉冲 | 两个边沿之间的电平。 |
| 采样点 | 通道在某一时间的值。 |
| 采样时长 | 一次采集的时间长度。 |
| 采样率 | 每个通道每秒的采样点数。 |
| 会话 | 包含应用和设备设置的文件。 |
| 设置 | 您可以在应用中更改的值。 |
| Stream模式 | 一种运行模式。在此模式下，设备在采集期间把采样点发送到计算机。 |
| 阈值 | 区分低电平和高电平的电压。 |
| 时间标尺 | 波形区上方的时间刻度。 |
| 触发 | 信号中标记采集中某一时间的条件。 |
| 触发位置 | 触发点在采集中的位置，为采样时长的百分比。 |
| 波形 | 显示通道信号的线。 |
| 波形区 | 窗口中显示波形的部分。 |

## 技术动词

| 动词 | 定义 |
| --- | --- |
| 采集 | 用设备记录信号。 |
| 单击 | 按下并松开鼠标按钮。 |
| 解码 | 读取数据并找到协议的帧。 |
| 双击 | 快速单击两次。 |
| 拖动 | 按住鼠标按钮移动一个项目。 |
| 导出 | 以供其他程序使用的格式保存数据。 |
| 按 | 按下键盘上的键。 |
| 采样 | 读取信号在某一时间的值。 |
| 输入 | 用键盘写入文本。 |
| 放大、缩小 | 显示波形较短或较长的部分。 |
