# 示波器和数据记录仪模式

Logic Analyze 也可以操作 DreamSourceLab 的 DSCope 示波器。DSCope 有两种设备模式：

- **示波器**：用于周期恒定的信号和单个信号条件。
- **数据记录仪**：用于长时间的慢速信号，例如电源电压或传感器输出。

DSLogic 设备没有这些模式。本章只给出主要步骤。

## 连接 DSCope

> [!WARNING]
> 不要把探头连接到市电电压。不要把探头连接到与市电电压有电气连接的电路。此电压可能导致受伤或死亡。

> [!CAUTION]
> 探头的地、DSCope 的地和计算机的地连接在一起。只把探头的地连接到与计算机的地电压相同的点。电压差可能损坏设备。

1. 用 USB 线缆把 DSCope 连接到计算机。
2. 启动 Logic Analyze。确认设备列表显示 DSCope。
3. 把探头连接到 DSCope 的输入端。
4. 设置每个探头上的衰减开关。
5. 把每个探头的接地夹连接到电路的地。
6. 把探头针尖连接到信号。

## 设备选项

单击 **选项** › **设备选项...** 或按 `O`。

- **运行模式**：**正常** 用于测量。**内部测试** 只用于测试设备。
- **带宽限制**：**全带宽** 或 **20MHz**。20 MHz 限制减少高频噪声。

## 校准 DSCope

输入的增益和偏置随温度和湿度变化。校准 DSCope 以保持测量准确。

### 自动校准

> [!CAUTION]
> 校准之前，从输入端断开所有探头。校准期间输入端上的信号会产生不正确的校准值。

1. 打开 **设备选项** 窗口。
2. 单击 **自动校准**。
3. 断开所有探头。单击 **确定**。校准持续几分钟。
4. 校准完成后，单击 **保存** 保留结果。

要停止校准，单击 **放弃**。然后设备使用以前的校准值。

### 手动校准

1. 打开 **设备选项** 窗口。
2. 单击 **手动校准**。
3. 单击工具栏上的 **开始**。
4. 要调整偏置，把探头连接到地。要调整增益，把探头连接到已知电压的信号。
5. 设置要校准的垂直刻度。
6. 移动该通道的 **偏置** 或 **增益** 滑块，直到波形正确。
7. 对每个垂直刻度重复步骤 5 和 6。
8. 单击 **保存**。

要放弃更改，单击 **放弃**。要只在断开设备之前使用这些更改，单击 **退出**。要恢复初始值，单击 **重置**。重置之后，再次执行自动校准。

## 通道设置

每个通道在波形区左侧有以下控件：

- **启用**：打开或关闭通道。
- **垂直刻度**：每格的电压。窗口有 10 格。要更改刻度，在旋钮上转动鼠标滚轮，或单击旋钮的上部或下部。您也可以按 `0` 或 `1` 选择一个通道的旋钮，然后按 `↑` 或 `↓`。
- **耦合**：**直流** 或 **交流**。
- **探头衰减**：设置 **x1** 或 **x10**，与探头上的开关一致。
- **自动**：为输入端上的信号设置垂直刻度、水平刻度和触发电平。

要向上或向下移动通道的波形，拖动通道标签。

## 水平刻度

在工具栏上的列表中选择每格的时间。您也可以在波形区中转动鼠标滚轮。

## 开始和停止

- 单击 **开始** 或按 `S` 开始连续采集。单击 **停止** 停止采集。
- 单击 **单次** 或按 `I` 采集一个波形后停止。

## 触发

单击 **触发** 或按 `T` 打开触发停靠面板。停靠面板有以下设置：

- **触发位置**：触发点在采集中的位置，为百分比。
- **触发释抑时间**：触发后设备忽略新触发的时间。用它从脉冲组得到稳定的波形。
- **触发灵敏度**：触发所需的电压变化。值越大，忽略的噪声越多。
- **触发源**：**自动**、**通道 0**、**通道 1**、**通道 0 && 1** 或 **通道 0 | 1**。
- **触发类型**：**上升沿** 或 **下降沿**。

要设置触发电平，单击该通道的触发电平标签。移动鼠标。再次单击以设置电平。

## 测量

### 自动测量

波形区底部有 10 个自动测量框。

1. 单击一个测量框。
2. 选择通道。
3. 选择测量项。要清除该框，单击 **重置**。

下次启动时，应用保留这些设置。

### 光标

- 要添加时间光标，单击时间标尺。您也可以在波形区中单击鼠标右键，然后选择 **添加Y轴光标**。
- 要添加电压光标，在波形区中单击鼠标右键，然后选择 **添加X光标**。每个电压光标有两条水平线。两条线之间的标签显示电压差。
- 要测量两个光标之间的时间，使用测量停靠面板中的 **光标距离** 组。

### 用指针测量

停止采集后，把指针放在波形上。应用显示指针处采样点的电压。

要测量时间，在波形的空白区域双击。在第二个点处单击。在第三个点处单击，查看频率、周期和占空比。单击鼠标右键取消。

## 频谱（FFT）

1. 单击 **函数** › **FFT**。
2. 选择 **FFT使能**。
3. 设置 **FFT长度**、**抽样间隔**、**FFT通道** 和 **FFT加窗**。
4. 设置 **Y轴模式** 和 **DBV范围**。
5. 单击 **确定**。

频谱显示在波形下方。在频谱中转动鼠标滚轮可缩放频率刻度。拖动频谱可移动它。把指针放在频谱上，查看频率和幅度。

## 数学运算通道

1. 单击 **函数** › **数学运算**。
2. 选择 **启用**。
3. 选择 **运算类型**：**加**、**减**、**乘** 或 **除**。
4. 选择 **第一操作数** 和 **第二操作数**。
5. 单击 **确定**。

## 李萨如图

1. 单击 **选项** › **显示** › **李萨如图**。
2. 选择 **启用**。
3. 为 **X轴** 和 **Y轴** 选择通道。
4. 单击 **确定**。

## 数据记录仪模式

1. 在工具栏上的设备模式列表中，选择 **数据记录仪**。
2. 打开 **设备选项** 窗口。
3. 为每个通道设置 **启用**、**耦合** 和 **电压/格**。
4. 要显示其他单位，设置 **对应单位**、**对应最小值** 和 **对应最大值**。例如，以 °C 显示温度传感器的输出。
5. 单击 **确定**。
6. 在工具栏上选择采样率和采样时长。
7. 单击 **开始** 或按 `S`。

采集期间不能更改通道设置。在最高采样率 10 MHz 下，最大采样时长约为 10 秒。在 1 kHz 下，采集可以持续一天。

数据记录仪模式使用示波器模式的校准。如果某个通道显示偏置，在示波器模式下校准设备。
