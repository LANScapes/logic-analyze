# 简介

## 关于 Logic Analyze

Logic Analyze 是一个 macOS 应用，用于 DreamSourceLab 的逻辑分析仪。LANScapes 提供此应用。此应用来自 DSView。DSView 是 DreamSourceLab 的程序。DSView 使用 sigrok 项目的软件。

此应用从 DSLogic 逻辑分析仪记录数字信号。然后，应用把信号显示为波形。您可以测量波形，也可以解码串行协议。您还可以保存数据，并把数据导出为其他格式。

本手册的示例使用 DSLogic Plus。其他 DSLogic 型号使用相同的步骤。它们的通道数、内存和采样率的上限不同。

此应用还包含 `dslcap` 工具。此工具不使用主窗口采集数据。参阅 [dslcap 工具](13-dslcap.md)。

## 关于本手册

本手册使用 ASD-STE100 简化技术英语的规则编写。每个句子都很短。步骤中的每一步只给出一条指令。本手册中的每个技术名称只有一个含义。[技术名称和动词](15-terms.md)列出了这些技术名称。

本手册使用以下文本格式：

- **粗体文本**表示应用中的标签，例如按钮、菜单项或输入框。
- `代码文本`表示键盘上的键、命令、文件名或您输入的值。
- 菜单路径使用符号 ›，例如 **文件** › **保存**。
- 带编号的步骤列表是一个操作步骤。按给定的顺序执行这些步骤。

## 安全说明

本手册使用以下安全标签：

- **警告** 表示有受伤或死亡的风险。
- **注意** 表示有损坏设备的风险，或有丢失数据的风险。
- **说明** 给出对您有帮助的信息。**说明** 后面的信息不是指令。

安全说明位于它适用的步骤之前。开始操作之前，阅读所有安全说明。

> [!WARNING]
> 不要把探头连接到市电电压。不要把探头连接到与市电电压有电气连接的电路。探头与计算机有电气连接。此电压可能导致受伤或死亡。

> [!CAUTION]
> 不要在通道输入端施加超过设备规格限值的电压。电压过高可能损坏逻辑分析仪。

> [!CAUTION]
> 逻辑分析仪的地线通过 USB 线缆与计算机的地相连。只把地线连接到您测量的电路的地。如果两个地的电压不同，可能流过大电流，损坏电路、逻辑分析仪和计算机。

## 系统要求

需要以下设备：

- 一台装有 macOS 的 Mac。发行说明给出最低 macOS 版本。
- 一个 USB 端口。USB 3.0 端口速度最高。USB 2.0 端口也可以使用。
- 一台 DSLogic 逻辑分析仪、它的 USB 线缆和它的探头线缆。

没有逻辑分析仪时，您也可以使用此应用。**演示** 设备产生测试信号。您也可以打开以前采集的数据文件。
