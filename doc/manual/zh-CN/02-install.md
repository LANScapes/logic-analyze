# 安装和启动应用

## 安装应用

1. 打开项目的发布页面：<https://github.com/LANScapes/logic-analyze/releases>。
2. 下载最新发布版本的 ZIP 文件。
3. 在 Finder 中打开 ZIP 文件。Finder 解压出 **Logic Analyze.app**。
4. 把 **Logic Analyze.app** 拖到 **应用程序** 文件夹。

此应用包含所有必需的库、固件和协议解码器。在 macOS 上不需要安装驱动程序。

## 启动应用

1. 把逻辑分析仪连接到计算机。参阅[连接 DSLogic Plus](04-connect.md)。
2. 从 **应用程序** 文件夹或从启动台打开 **Logic Analyze**。
3. 如果 macOS 显示关于此应用的消息，单击 **打开**。

应用第一次启动时，可能显示 **文档** 窗口。单击 **打开** 阅读本手册。单击 **忽略** 关闭此窗口。如果您不想再看到此窗口，单击 **不再显示**。

## 更新应用

1. 单击 **帮助** › **更新**。应用在您的网页浏览器中打开发布页面。
2. 如果发布页面显示更新的版本，下载该版本。
3. 退出 Logic Analyze。
4. 用新版本替换 **应用程序** 文件夹中的 **Logic Analyze.app**。

替换应用后，应用保留您的设置。

## 打开本手册

单击 **帮助** › **手册**。应用以用户界面的语言打开本手册。如果没有该语言的手册，应用打开英文手册。

## 更改语言

1. 单击 **帮助** › **语言**。
2. 从列表中选择一种语言。

用户界面变为您选择的语言。

## 更改主题

1. 单击 **选项** › **显示** › **主题**。
2. 选择 **暗黑** 或 **清新**。

## 移动工具栏

您可以把工具栏放在窗口的顶部、底部、左侧或右侧。工具栏在左侧或右侧时，16 个通道可以使用窗口的全部高度。

1. 把指针放在工具栏起始处的拖动手柄上。
2. 按住鼠标按钮。
3. 把工具栏拖到窗口的一条边。
4. 松开鼠标按钮。

再次启动时，应用保留工具栏的位置。

## 显示选项

要更改显示选项，单击 **选项** › **显示** › **选项**。**显示选项** 窗口显示以下设置：

| 设置 | 功能 |
| --- | --- |
| **基于鼠标拖拽的波形滚动** | 快速拖动波形并松开后，波形继续移动。然后波形移动变慢并停止。 |
| **重复模式下停止后更新最新数据** | 在 **重复** 模式下停止采集时，应用显示最后一次采集的数据。这次采集不完整。 |
| **自动滚动到最新数据** | 在 Stream模式下，波形移动以显示最新的数据。 |
| **触发位置自动居中显示** | 在示波器模式下，应用在窗口中间显示触发位置。 |
| **标题栏显示配置文件名** | 标题栏显示会话文件的名称。 |
| **字体大小** | 波形区中文本的大小。 |

## 日志选项

应用可以记录日志文件。日志文件有助于找到问题的原因。

1. 单击 **帮助** › **日志选项**。
2. 在 **日志级别** 中选择 0 到 5 之间的值。值越大，记录的消息越多。
3. 选择 **保存到文件**。
4. 要把新消息添加到现有日志文件的末尾，选择 **追加模式**。
5. 单击 **确定**。

要查看日志文件，在 **日志选项** 窗口中单击 **打开**。要清除日志文件，单击 **清除**。

## 报告问题

单击 **帮助** › **报告问题**。应用在您的网页浏览器中打开项目的问题页面。在报告中写明应用版本、macOS 版本和设备型号。如果可以，附上日志文件。
