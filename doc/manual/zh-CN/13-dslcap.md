# dslcap 工具

`dslcap` 工具不使用主窗口，从 DSLogic 设备采集数据。在脚本和自动测试中使用它。此工具把采样点写入一个二进制文件。它把一个包含结果的 JSON 对象写到标准输出。

此工具位于应用包中：

```sh
"/Applications/Logic Analyze.app/Contents/MacOS/dslcap"
```

> [!NOTE]
> 同一时间只有一个程序可以使用设备。使用 `dslcap` 之前，退出 Logic Analyze。

## 列出设备

要列出库可以找到的设备，输入以下命令：

```sh
dslcap --list
```

要列出每个已连接的 DSLogic 设备的 USB 标识符，输入以下命令：

```sh
dslcap --list-ids
```

`--list-ids` 命令只读取 macOS 保存的 USB 设备信息。它不向设备发送数据。输出给出每个设备的型号、USB 位置和注册表标识符。

## 采集数据

此命令在通道 0 和 1 上以 10 MHz 采集 1000000 个采样点：

```sh
dslcap --channels 0,1 --samplerate 10000000 --samples 1000000 --out /tmp/capture
```

此工具把采样点写入 `/tmp/capture.bin`。如果已有同名文件，工具报错并停止。此工具不替换文件。

采集选项如下：

| 选项 | 功能 | 初始值 |
| --- | --- | --- |
| `--channels LIST` | 要记录的通道，例如 `0,1,2`。 | `0` |
| `--samplerate HZ` | 采样率，单位为 Hz。 | `10000000` |
| `--samples N` | 每个通道的采样点数。 | `1000000` |
| `--vth VOLTS` | 阈值电压。 | `1.6` |
| `--mode MODE` | `buffer` 或 `stream`。 | `buffer` |
| `--trigger CH[:T]` | 通道 CH 上的触发。T 使用 `R`（上升沿）、`F`（下降沿）、`C`（上升沿或下降沿）、`1`（高电平）或 `0`（低电平）。 | 无触发。只给出 CH 时为 `R`。 |
| `--trigpos PERCENT` | 触发位置，为采样点数的百分比。 | `10` |
| `--timeout SEC` | 采集的最长时间，单位为秒。 | `30` |
| `--out PATH` | 输出文件的路径，不含 `.bin` 扩展名。 | 必须使用此选项。 |
| `--log-level N` | 标准错误输出上库消息的数量，从 0（无）到 5（全部）。 | `1` |

此工具在使用设备之前检查所有选项。如果某个选项不正确，工具停止并报错。

## 输出文件

`.bin` 文件按通道编号从小到大的顺序包含各通道。对于每个通道，文件包含该通道的所有采样点。每个字节保存 8 个采样点。第一个采样点是最低有效位。每个通道的数据填满整数个 8 字节单元。因此，每个通道使用 `ceil(samples / 64) × 8` 字节。

## JSON 结果

此工具在一行中写入一个 JSON 对象。采集正确时，该对象给出设备名称、采样率、采样点数和通道。它还给出阈值电压、模式、触发、采集时间和 `.bin` 文件的路径。如果采集不正确，该对象包含 `error` 键。此时工具不生成 `.bin` 文件。

只在退出状态为 0 且 JSON 对象完整时使用结果。

## 退出状态

| 状态 | 含义 |
| --- | --- |
| 0 | 采集完成。 |
| 1 | 操作期间发生错误，例如 I/O 错误。 |
| 2 | 选项不正确，或设备上没有该设置。 |
| 3 | 采集没有完成。 |

## 用于启动 dslcap 的程序的选项

- `--parent-fd N`：启动此工具的程序关闭描述符为 N 的管道时，工具停止。如果采集没有完成，工具随后删除其输出文件。
- `--res DIR`：存放固件文件的文件夹。通常，工具自动找到此文件夹。您也可以设置 `DSLCAP_RES` 环境变量。
- `--res-manifest FD`：工具在把每个固件文件发送到设备之前，检查该文件的 SHA-256 值。

源代码中的 `tools/dslcap/README.md` 文件给出这些选项的全部说明。
