# 连接 DSLogic Plus

## 连接 USB 线缆

> [!NOTE]
> 使用设备随附的 USB 线缆，或使用质量好的短 USB 线缆。把线缆直接连接到计算机上的端口。USB 集线器或长线缆可能导致采集出错。

1. 把 USB 线缆连接到 DSLogic Plus。
2. 把 USB 线缆的另一端连接到计算机上的 USB 端口。
3. 确认 DSLogic Plus 上的指示灯亮起。应用启动之前，指示灯为红色。
4. 启动 Logic Analyze。
5. 确认指示灯变为绿色。
6. 确认工具栏上的设备列表显示 **DSLogic Plus**。

![USB 连接](../figures/usb-connection.png)

如果设备列表不显示该设备，执行以下步骤：

1. 从计算机断开 USB 线缆。
2. 等待 5 秒。
3. 把 USB 线缆连接到另一个 USB 端口。
4. 如果执行步骤 3 后设备列表仍不显示该设备，退出应用并重新启动。

> [!NOTE]
> 同一时间只有一个程序可以使用设备。如果 `dslcap` 或其他程序正在使用设备，应用找不到该设备。

## 连接探头线缆

探头线缆有 16 根通道线。每根通道线有屏蔽层、信号端和接地端。线的颜色标识通道 0 到 15。另外一根线有以下信号：

- **CK**：外部时钟输入。只在使用 **使用外部输入时钟采样** 设置时使用。
- **TI**：外部触发信号输入。
- **TO**：触发信号输出。触发发生时，设备在 TO 上发出一个脉冲。

通常不连接 CK、TI 和 TO 线。

![探头线缆及其通道](../figures/probe-cable-channels.png)

1. 把探头线缆连接到 DSLogic Plus 的输入连接器。
2. 把连接器完全推入设备。

## 把通道连接到电路

> [!WARNING]
> 不要把探头连接到市电电压。不要把探头连接到与市电电压有电气连接的电路。此电压可能导致受伤或死亡。

> [!CAUTION]
> 连接地线之前，确认电路的地和计算机的地电压相同。电压差可能产生大电流，损坏设备。

1. 断开被测电路的电源。
2. 至少把一根地线连接到电路的地。
3. 把您使用的每根通道线连接到电路中的一个信号。
4. 确认没有探头接触其他触点。
5. 接通电路的电源。

![接地连接：一个公共地（左）或每个通道一个地（右）](../figures/probe-grounding.png)

对于频率低于 5 MHz 的信号，所有通道使用一根地线就足够。对于频率更高的信号，把每根通道线的接地端连接到该信号附近的地。短的接地连接使信号边沿清晰。

## 断开 DSLogic Plus

> [!CAUTION]
> 采集期间不要断开 USB 线缆。如果断开，采集的数据可能出错。

1. 停止采集。如果工具栏上显示 **停止**，单击它。
2. 断开电路的电源。
3. 从电路断开探头。
4. 断开 USB 线缆。
