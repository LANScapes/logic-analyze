# 트리거

트리거는 신호의 조건입니다. 조건이 발생하면 장치는 그 시간을 트리거 지점으로 표시합니다. 트리거를 사용하면 검사하려는 신호 부분을 캡처할 수 있습니다.

앱에는 두 가지 트리거 유형이 있습니다.

- **단순 트리거**: 하나 이상의 채널의 에지 또는 레벨.
- **고급 트리거**: 조건의 순서 또는 직렬 버스의 값.

트리거 도크를 열려면 도구 막대에서 **트리거**를 클릭하거나 `T`를 누르십시오.

> [!NOTE]
> 신호가 트리거 조건과 일치하지 않으면 캡처는 계속 기다립니다. 트리거 없이 신호를 보려면 **즉시**를 클릭하십시오. 대기를 멈추려면 **정지**를 클릭하십시오.

## 트리거 위치

**트리거 위치** 설정은 캡처 안에서 트리거 지점의 위치를 정합니다. 값은 샘플 시간에 대한 백분율입니다.

- 작은 값(예: 10%)은 트리거 뒤의 신호를 더 많이 표시합니다.
- 큰 값(예: 90%)은 트리거 앞의 신호를 더 많이 표시합니다.

트리거 위치는 장치의 메모리를 사용합니다. 그래서 버퍼 모드에서만 설정할 수 있습니다. 스트림 모드에서 트리거 위치는 항상 약 1%입니다.

## 단순 트리거

파형 영역의 각 채널 레이블에는 트리거 버튼이 다섯 개 있습니다. 왼쪽부터 오른쪽으로 버튼은 다음과 같습니다.

1. 상승 에지
2. 하이 레벨
3. 하강 에지
4. 로우 레벨
5. 상승 에지 또는 하강 에지

![채널 레이블의 트리거 버튼](../figures/simple-trigger-buttons.png)

단순 트리거를 설정하려면 다음 단계를 수행하십시오.

1. 트리거 도크를 여십시오.
2. **단순 트리거**를 선택하십시오.
3. 채널 레이블에서 원하는 트리거 버튼을 클릭하십시오. 버튼의 색이 바뀝니다.
4. 채널에서 트리거를 제거하려면 같은 버튼을 다시 클릭하십시오.
5. **트리거 위치**를 설정하십시오.

둘 이상의 채널에 트리거를 설정하면 모든 조건이 같은 샘플에서 발생해야 합니다(논리 AND).

## 고급 트리거

> [!NOTE]
> 고급 트리거는 버퍼 모드에서만 사용할 수 있습니다. 사용하려면 **작동 모드**를 **버퍼 모드**로 설정하십시오. [장치 옵션](05-device-options.md)을 참조하십시오.

고급 트리거를 사용하려면 트리거 도크에서 **고급 트리거**를 선택하십시오. 그런 다음 **단계 트리거** 탭 또는 **직렬 트리거** 탭을 선택하십시오.

### 채널별 값

단계 트리거와 직렬 트리거는 16개 문자로 된 행을 사용합니다. 각 문자는 채널 하나의 조건입니다. 오른쪽 문자는 채널 0입니다. 왼쪽 문자는 채널 15입니다.

| 문자 | 조건 |
| --- | --- |
| `X` | 모든 값(채널이 영향을 주지 않음). |
| `0` | 로우 레벨. |
| `1` | 하이 레벨. |
| `R` | 상승 에지. |
| `F` | 하강 에지. |
| `C` | 상승 에지 또는 하강 에지. |

### 단계 트리거

단계 트리거는 조건의 순서입니다. 각 조건이 단계입니다. 장치는 먼저 단계 0을 검사합니다. 단계의 조건이 발생하면 장치는 다음 단계로 갑니다. 마지막 단계가 완료되면 트리거가 발생합니다. 단계는 16개까지 사용할 수 있습니다.

각 단계에는 다음 설정이 있습니다.

- 채널 조건 행 두 개.
- 각 행에 `==` 또는 `!=`. `==`이면 채널이 행과 일치할 때 조건이 발생합니다. `!=`이면 채널이 행과 일치하지 않을 때 조건이 발생합니다.
- **And** 또는 **Or**. 이 설정은 두 행을 연결합니다.
- **카운터**: 단계가 완료되기 전에 조건이 발생해야 하는 횟수.
- **연속**: 이 체크 상자를 선택하면 조건이 끊김 없이 이어지는 샘플에서 발생해야 합니다.

![단계 트리거 설정](../figures/stage-trigger-panel.png)
<!-- TODO: new screenshot -->

단계 트리거를 설정하려면 다음 단계를 수행하십시오.

1. **전체 트리거 단계**에서 단계 수를 선택하십시오.
2. 오른쪽의 단계 목록에서 단계 0을 클릭하십시오.
3. 첫 번째 행에 채널 조건을 입력하십시오.
4. 필요하면 두 번째 행에 채널 조건을 입력하고 **And** 또는 **Or**를 선택하십시오.
5. **카운터**에 값을 입력하십시오.
6. 다른 단계마다 2~5단계를 다시 수행하십시오.

다음은 세 가지 예입니다.

**예 1.** 채널 0이 1000 샘플보다 오래 하이로 유지될 때 트리거:

1. **전체 트리거 단계**를 1로 설정하십시오.
2. 단계 0의 첫 번째 행에서 채널 0에 `1`을 입력하십시오.
3. **연속**을 선택하십시오.
4. **카운터**를 1000으로 설정하십시오.

![예 1](../figures/stage-example-level-count.png)

**예 2.** 채널 0의 상승 에지 또는 채널 1의 하강 에지에서 트리거:

1. **전체 트리거 단계**를 1로 설정하십시오.
2. 단계 0의 첫 번째 행에서 채널 0에 `R`을 입력하십시오.
3. 두 번째 행에서 채널 1에 `F`를 입력하십시오.
4. **Or**를 선택하십시오.

![예 2](../figures/stage-example-or.png)

**예 3.** 채널 0의 상승 에지, 그다음 채널 1의 하강 에지 100개, 그다음 채널 2의 하이 레벨에서 트리거:

1. **전체 트리거 단계**를 3으로 설정하십시오.
2. 단계 0에서 채널 0에 `R`을 입력하십시오.
3. 단계 1에서 채널 1에 `F`를 입력하십시오. **카운터**를 100으로 설정하십시오.
4. 단계 2에서 채널 2에 `1`을 입력하십시오.

![예 3](../figures/stage-example-sequence.png)

### 직렬 트리거

직렬 트리거는 직렬 버스에서 데이터 값을 찾습니다. 직렬 트리거는 시프트 레지스터처럼 작동합니다. 설정은 다음과 같습니다.

- **시작 플래그**: 직렬 트리거를 시작하는 조건.
- **정지 플래그**: 시프트 레지스터를 지우는 조건.
- **클록 플래그**: 시프트 레지스터에 비트 하나를 추가하는 조건.
- **데이터 채널**: 데이터를 전송하는 채널.
- **데이터 비트**: 값의 비트 수.
- **데이터 값**: 트리거를 일으키는 값.

시작 플래그가 발생하면 장치는 클록 플래그마다 데이터 채널을 읽습니다. 장치는 이 비트를 시프트 레지스터로 옮깁니다. 시프트 레지스터의 마지막 비트가 **데이터 값**과 같으면 트리거가 발생합니다. 정지 플래그가 발생하면 장치는 시프트 레지스터를 지웁니다.

**예 4.** I2C 버스에 값 `010000100`이 나타날 때 트리거. 채널 0은 SCL, 채널 1은 SDA입니다.

1. **시작 플래그**를 SCL이 하이일 때 SDA의 하강 에지로 설정하십시오: 오른쪽 두 문자에 `F1`.
2. **정지 플래그**를 SCL이 하이일 때 SDA의 상승 에지로 설정하십시오: `R1`.
3. **클록 플래그**를 SCL의 상승 에지로 설정하십시오: 채널 0에 `R`.
4. **데이터 채널**을 1로 설정하십시오.
5. **데이터 비트**를 9로 설정하십시오.
6. **데이터 값**에 `010000100`을 입력하십시오.

![예 4](../figures/serial-example-i2c.png)

**예 5.** SPI 버스의 MOSI에 값 `0x1234`가 나타날 때 트리거. 채널 0은 CS#, 채널 1은 CLK, 채널 2는 MISO, 채널 3은 MOSI입니다.

1. **시작 플래그**를 CS#의 하강 에지로 설정하십시오: 채널 0에 `F`.
2. **정지 플래그**를 CS#의 상승 에지로 설정하십시오: 채널 0에 `R`.
3. **클록 플래그**를 CLK의 상승 에지로 설정하십시오: 채널 1에 `R`.
4. **데이터 채널**을 3으로 설정하십시오.
5. **데이터 비트**를 16으로 설정하십시오.
6. **데이터 값**에 `0001001000110100`을 입력하십시오.

![예 5](../figures/serial-example-spi.png)

값을 16진수로 입력하려면 **16진수 형식으로 입력**을 선택하십시오. 그런 다음 **16진수** 필드에 값을 입력하십시오.
