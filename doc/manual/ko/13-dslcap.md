# dslcap 도구

`dslcap` 도구는 주 창 없이 DSLogic 장치에서 데이터를 캡처합니다. 스크립트와 자동 테스트에서 사용하십시오. 이 도구는 샘플을 바이너리 파일에 씁니다. 결과는 JSON 객체 하나로 표준 출력에 씁니다.

이 도구는 앱 번들 안에 있습니다.

```sh
"/Applications/Logic Analyze.app/Contents/MacOS/dslcap"
```

> [!NOTE]
> 한 번에 하나의 프로그램만 장치를 사용할 수 있습니다. `dslcap`을 사용하기 전에 Logic Analyze를 종료하십시오.

## 장치 나열

라이브러리가 찾을 수 있는 장치를 나열하려면 다음 명령을 입력하십시오.

```sh
dslcap --list
```

연결된 각 DSLogic 장치의 USB 식별자를 나열하려면 다음 명령을 입력하십시오.

```sh
dslcap --list-ids
```

`--list-ids` 명령은 macOS가 USB 장치에 대해 보관하는 정보만 읽습니다. 장치에 데이터를 보내지 않습니다. 출력에는 장치마다 모델, USB 위치, 레지스트리 식별자가 있습니다.

## 데이터 캡처

다음 명령은 채널 0과 1에서 10 MHz로 샘플 1000000개를 캡처합니다.

```sh
dslcap --channels 0,1 --samplerate 10000000 --samples 1000000 --out /tmp/capture
```

도구는 샘플을 `/tmp/capture.bin`에 씁니다. 이 이름의 파일이 있으면 도구는 오류와 함께 멈춥니다. 도구는 파일을 대체하지 않습니다.

캡처 옵션은 다음과 같습니다.

| 옵션 | 기능 | 시작 값 |
| --- | --- | --- |
| `--channels LIST` | 기록할 채널. 예: `0,1,2`. | `0` |
| `--samplerate HZ` | Hz 단위의 샘플 레이트. | `10000000` |
| `--samples N` | 채널마다의 샘플 수. | `1000000` |
| `--vth VOLTS` | 임계 전압. | `1.6` |
| `--mode MODE` | `buffer` 또는 `stream`. | `buffer` |
| `--trigger CH[:T]` | 채널 CH의 트리거. T에는 `R`(상승 에지), `F`(하강 에지), `C`(상승 에지 또는 하강 에지), `1`(하이 레벨) 또는 `0`(로우 레벨)을 사용하십시오. | 트리거 없음. CH만 주면 `R`. |
| `--trigpos PERCENT` | 샘플에 대한 백분율로 나타낸 트리거 위치. | `10` |
| `--timeout SEC` | 초 단위의 최대 캡처 시간. | `30` |
| `--out PATH` | `.bin` 확장자를 뺀 출력 파일 경로. | 이 옵션은 필수입니다. |
| `--log-level N` | 표준 오류 출력에 쓰는 라이브러리 메시지 양. 0(없음)부터 5(모두)까지. | `1` |

도구는 장치를 사용하기 전에 모든 옵션을 검사합니다. 옵션이 올바르지 않으면 도구는 멈추고 오류를 표시합니다.

## 출력 파일

`.bin` 파일에는 채널이 가장 낮은 번호부터 번호 순서로 들어 있습니다. 각 채널마다 파일에는 그 채널의 모든 샘플이 들어 있습니다. 바이트 하나에 샘플 8개가 들어 있습니다. 첫 번째 샘플은 최하위 비트입니다. 각 채널의 데이터는 8바이트 단위의 정수 배를 채웁니다. 그래서 각 채널은 `ceil(samples / 64) × 8` 바이트를 사용합니다.

## JSON 결과

도구는 JSON 객체 하나를 한 줄에 씁니다. 캡처가 올바르면 객체에 장치 이름, 샘플 레이트, 샘플 수, 채널이 들어 있습니다. 임계 전압, 모드, 트리거, 캡처 시간, `.bin` 파일 경로도 들어 있습니다. 캡처가 올바르지 않으면 객체에 `error` 키가 들어 있습니다. 그러면 도구는 `.bin` 파일을 만들지 않습니다.

종료 상태가 0이고 JSON 객체가 완전할 때만 결과를 사용하십시오.

## 종료 상태

| 상태 | 의미 |
| --- | --- |
| 0 | 캡처가 완료되었습니다. |
| 1 | 작업 중 오류가 발생했습니다. 예: I/O 오류. |
| 2 | 옵션이 올바르지 않거나 장치에서 설정을 사용할 수 없습니다. |
| 3 | 캡처가 완료되지 않았습니다. |

## dslcap을 시작하는 프로그램용 옵션

- `--parent-fd N`: 도구를 시작한 프로그램이 디스크립터 N의 파이프를 닫으면 도구가 멈춥니다. 그러면 캡처가 완료되지 않은 경우 도구가 출력 파일을 제거합니다.
- `--res DIR`: 펌웨어 파일이 있는 폴더. 보통 도구가 이 폴더를 자동으로 찾습니다. `DSLCAP_RES` 환경 변수를 설정할 수도 있습니다.
- `--res-manifest FD`: 도구가 각 펌웨어 파일을 장치로 보내기 전에 SHA-256 값을 검사합니다.

소스 코드의 `tools/dslcap/README.md` 파일에 이 옵션의 모든 정보가 있습니다.
