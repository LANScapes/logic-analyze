# 파일과 세션

파일 메뉴를 열려면 도구 막대에서 **파일**을 클릭하십시오. 메뉴에는 다음 항목이 있습니다.

- **세션**: 세션을 불러오고 저장하는 메뉴.
- **열기...**: 데이터 파일을 엽니다.
- **저장...**: 캡처 데이터를 저장합니다.
- **내보내기...**: 데이터를 다른 형식으로 내보냅니다.
- **스크린샷...**: 창의 이미지를 저장합니다.

## 세션

세션 파일에는 설정이 들어 있지만 캡처 데이터는 들어 있지 않습니다. 세션에는 장치 옵션, 활성화한 채널, 채널 이름과 색, 트리거 설정이 들어 있습니다. 세션 파일의 확장자는 `.dsc`입니다.

### 세션 저장

1. **파일** › **세션** › **세션 저장**을 클릭하십시오.
2. 폴더를 선택하고 파일 이름을 입력하십시오.
3. **저장**을 클릭하십시오.

### 세션 불러오기

1. **파일** › **세션** › **세션 불러오기**를 클릭하십시오.
2. 세션 파일을 선택하십시오.
3. **열기**를 클릭하십시오.

### 초기 설정으로 돌아가기

**파일** › **세션** › **기본 세션 불러오기**를 클릭하십시오. 앱이 장치의 모든 설정을 초기값으로 되돌립니다.

종료할 때 앱은 설정을 자동으로 저장합니다. 앱을 다시 시작하면 마지막 세션의 설정을 불러옵니다.

## 데이터 저장

1. **파일** › **저장...**을 클릭하십시오.
2. 폴더를 선택하고 파일 이름을 입력하십시오.
3. **저장**을 클릭하십시오.

앱은 데이터와 설정을 확장자가 `.dsl`인 파일에 저장합니다. 이 파일은 Logic Analyze에서 다시 열 수 있습니다.

> [!CAUTION]
> 앱은 데이터를 자동으로 저장하지 않습니다. 새 캡처를 시작하거나 앱을 종료하기 전에 데이터를 저장하십시오. 새 캡처는 이전 캡처의 데이터를 대체합니다.

## 데이터 파일 열기

1. **파일** › **열기...**를 클릭하십시오.
2. 확장자가 `.dsl`인 파일을 선택하십시오.
3. **열기**를 클릭하십시오.

앱이 파형 영역에 데이터를 표시합니다. 장치 유형 레이블에 **파일**이 표시됩니다.

## 데이터 내보내기

내보내기는 다른 프로그램이 읽을 수 있는 파일을 만듭니다.

1. **파일** › **내보내기...**를 클릭하십시오. **내보내기** 창이 열립니다.
2. **경로**를 클릭하십시오.
3. 폴더를 선택하고, 파일 이름을 입력하고, 형식을 선택하십시오.
4. **저장**을 클릭하십시오.
5. 형식이 CSV이면 **원본 데이터** 또는 **압축 데이터**를 선택하십시오. 압축 데이터에는 값이 바뀔 때마다 한 행만 있습니다.
6. **확인**을 클릭하십시오.

로직 분석기 모드에서는 다음 형식을 사용할 수 있습니다.

| 형식 | 확장자 | 용도 |
| --- | --- | --- |
| CSV | `.csv` | 스프레드시트 프로그램과 스크립트. |
| VCD | `.vcd` | 파형 프로그램. 예: GTKWave. |
| Gnuplot | `.gnuplot` | Gnuplot 프로그램. |
| srzip | `.srzip` | sigrok 프로그램. 예: PulseView. |

오실로스코프 모드와 데이터 수집 모드에서는 CSV만 사용할 수 있습니다.

## 창의 이미지 저장

1. **파일** › **스크린샷...**을 클릭하십시오.
2. 폴더를 선택하고 파일 이름을 입력하십시오.
3. PNG 또는 JPEG를 선택하십시오.
4. **저장**을 클릭하십시오.
