# 오실로스코프 모드와 데이터 수집 모드

Logic Analyze는 DreamSourceLab의 DSCope 오실로스코프도 작동시킬 수 있습니다. DSCope에는 장치 모드가 두 개 있습니다.

- **오실로스코프**: 주기가 일정한 신호와 신호 조건 하나에 사용합니다.
- **데이터 수집**: 긴 시간 동안의 느린 신호에 사용합니다. 예: 전원 전압 또는 센서 출력.

이 모드는 DSLogic 장치에서는 사용할 수 없습니다. 이 장은 주요 절차만 설명합니다.

## DSCope 연결

> [!WARNING]
> 프로브를 상용 전원 전압에 연결하지 마십시오. 상용 전원 전압과 전기적으로 연결된 회로에 프로브를 연결하지 마십시오. 이 전압은 부상 또는 사망을 일으킬 수 있습니다.

> [!CAUTION]
> 프로브의 접지, DSCope의 접지, 컴퓨터의 접지는 서로 연결되어 있습니다. 프로브 접지는 컴퓨터 접지와 전압이 같은 지점에만 연결하십시오. 전압 차이는 장비를 손상시킬 수 있습니다.

1. USB 케이블로 DSCope를 컴퓨터에 연결하십시오.
2. Logic Analyze를 시작하십시오. 장치 목록에 DSCope가 표시되는지 확인하십시오.
3. 프로브를 DSCope의 입력에 연결하십시오.
4. 각 프로브의 감쇠 스위치를 설정하십시오.
5. 각 프로브의 접지 클립을 회로의 접지에 연결하십시오.
6. 프로브 팁을 신호에 연결하십시오.

## 장치 옵션

**옵션** › **장치 옵션...**을 클릭하거나 `O`를 누르십시오.

- **작동 모드**: 측정에는 **보통**. **내부 테스트**는 장치 테스트 전용입니다.
- **대역폭 제한**: **전체 대역폭** 또는 **20MHz**. 20 MHz 제한은 고주파 노이즈를 줄입니다.

## DSCope 교정

입력의 이득과 오프셋은 온도와 습도에 따라 바뀝니다. 측정을 정확하게 유지하려면 DSCope를 교정하십시오.

### 자동 교정

> [!CAUTION]
> 교정 전에 입력에서 모든 프로브를 분리하십시오. 교정 중에 입력에 신호가 있으면 교정 값이 올바르지 않습니다.

1. **장치 옵션** 창을 여십시오.
2. **자동 교정**을 클릭하십시오.
3. 모든 프로브를 분리하십시오. **확인**을 클릭하십시오. 교정은 몇 분 동안 계속됩니다.
4. 교정이 완료되면 결과를 유지하려면 **저장**을 클릭하십시오.

교정을 멈추려면 **중단**을 클릭하십시오. 그러면 장치는 이전 교정 값을 사용합니다.

### 수동 교정

1. **장치 옵션** 창을 여십시오.
2. **수동 교정**을 클릭하십시오.
3. 도구 막대에서 **시작**을 클릭하십시오.
4. 오프셋을 조정하려면 프로브를 접지에 연결하십시오. 이득을 조정하려면 전압을 아는 신호에 프로브를 연결하십시오.
5. 교정할 수직 스케일을 설정하십시오.
6. 파형이 올바를 때까지 채널의 **VOFF** 또는 **VGAIN** 슬라이더를 움직이십시오.
7. 수직 스케일마다 5단계와 6단계를 다시 수행하십시오.
8. **저장**을 클릭하십시오.

변경을 버리려면 **중단**을 클릭하십시오. 장치를 분리할 때까지만 변경을 사용하려면 **종료**를 클릭하십시오. 초기값으로 돌아가려면 **재설정**을 클릭하십시오. 재설정 후에는 자동 교정을 다시 하십시오.

## 채널 설정

각 채널에는 파형 영역 왼쪽에 다음 컨트롤이 있습니다.

- **활성화**: 채널을 켜거나 끕니다.
- **수직 스케일**: 한 눈금의 전압입니다. 창에는 눈금이 10개 있습니다. 스케일을 변경하려면 노브 위에서 마우스 휠을 돌리거나 노브의 위쪽 또는 아래쪽을 클릭하십시오. `0` 또는 `1`을 눌러 채널의 노브를 선택한 다음 `↑` 또는 `↓`를 눌러도 됩니다.
- **커플링**: **DC** 또는 **AC**.
- **프로브 감쇠**: 프로브의 스위치와 맞게 **x1** 또는 **x10**을 설정하십시오.
- **자동**: 입력의 신호에 맞게 수직 스케일, 수평 스케일, 트리거 레벨을 설정합니다.

채널의 파형을 위나 아래로 이동하려면 채널 레이블을 드래그하십시오.

## 수평 스케일

도구 막대의 목록에서 한 눈금의 시간을 선택하십시오. 파형 영역에서 마우스 휠을 돌려도 됩니다.

## 시작과 정지

- 연속 캡처를 시작하려면 **시작**을 클릭하거나 `S`를 누르십시오. 멈추려면 **정지**를 클릭하십시오.
- 파형 하나를 캡처하고 멈추려면 **단일**을 클릭하거나 `I`를 누르십시오.

## 트리거

트리거 도크를 열려면 **트리거**를 클릭하거나 `T`를 누르십시오. 도크에는 다음 설정이 있습니다.

- **트리거 위치**: 캡처 안의 트리거 지점 위치를 백분율로 나타낸 값.
- **홀드오프 시간**: 트리거 후에 장치가 새 트리거를 무시하는 시간. 펄스 묶음에서 안정된 파형을 얻을 때 사용하십시오.
- **트리거 감도**: 트리거에 필요한 전압 변화. 값이 클수록 노이즈를 더 많이 무시합니다.
- **트리거 소스**: **자동**, **채널 0**, **채널 1**, **채널 0 && 1** 또는 **채널 0 | 1**.
- **트리거 유형**: **상승 에지** 또는 **하강 에지**.

트리거 레벨을 설정하려면 채널의 트리거 레벨 레이블을 클릭하십시오. 마우스를 움직이십시오. 레벨을 설정하려면 다시 클릭하십시오.

## 측정

### 자동 측정

파형 영역 아래쪽에 자동 측정 상자가 10개 있습니다.

1. 측정 상자를 클릭하십시오.
2. 채널을 선택하십시오.
3. 측정 항목을 선택하십시오. 상자를 비우려면 **재설정**을 클릭하십시오.

앱은 다음 시작을 위해 이 설정을 유지합니다.

### 커서

- 시간 커서를 추가하려면 시간 눈금자를 클릭하십시오. 파형 영역에서 마우스 오른쪽 버튼을 클릭하고 **Y 커서 추가**를 선택해도 됩니다.
- 전압 커서를 추가하려면 파형 영역에서 마우스 오른쪽 버튼을 클릭하고 **X 커서 추가**를 선택하십시오. 각 전압 커서에는 수평선이 두 개 있습니다. 선 사이의 레이블은 전압 차이를 표시합니다.
- 두 커서 사이의 시간을 측정하려면 측정 도크의 **커서 간 거리** 그룹을 사용하십시오.

### 포인터로 측정

캡처를 정지한 후 파형에 포인터를 놓으십시오. 앱이 포인터 위치 샘플의 전압을 표시합니다.

시간을 측정하려면 파형의 빈 영역에서 더블클릭하십시오. 두 번째 지점을 클릭하십시오. 주파수, 주기, 듀티 사이클을 보려면 세 번째 지점을 클릭하십시오. 취소하려면 마우스 오른쪽 버튼을 클릭하십시오.

## 스펙트럼(FFT)

1. **함수** › **FFT**를 클릭하십시오.
2. **FFT 활성화**를 선택하십시오.
3. **FFT 길이**, **샘플 간격**, **FFT 소스**, **FFT 윈도우**를 설정하십시오.
4. **Y축 모드**와 **DBV 범위**를 설정하십시오.
5. **확인**을 클릭하십시오.

스펙트럼은 파형 아래에 표시됩니다. 주파수 스케일을 확대/축소하려면 스펙트럼에서 마우스 휠을 돌리십시오. 스펙트럼을 이동하려면 드래그하십시오. 주파수와 진폭을 보려면 스펙트럼에 포인터를 놓으십시오.

## 연산 채널

1. **함수** › **연산**을 클릭하십시오.
2. **활성화**를 선택하십시오.
3. **연산 유형**을 선택하십시오: **더하기**, **빼기**, **곱하기** 또는 **나누기**.
4. **첫 번째 소스**와 **두 번째 소스**를 선택하십시오.
5. **확인**을 클릭하십시오.

## 리사주 도형

1. **옵션** › **표시** › **리사주**를 클릭하십시오.
2. **활성화**를 선택하십시오.
3. **X축**과 **Y축**의 채널을 선택하십시오.
4. **확인**을 클릭하십시오.

## 데이터 수집 모드

1. 도구 막대의 장치 모드 목록에서 **데이터 수집**을 선택하십시오.
2. **장치 옵션** 창을 여십시오.
3. 채널마다 **활성화**, **커플링**, **Volts/div**를 설정하십시오.
4. 다른 단위를 표시하려면 **매핑 단위**, **매핑 최소값**, **매핑 최대값**을 설정하십시오. 예를 들어 온도 센서의 출력을 °C로 표시하십시오.
5. **확인**을 클릭하십시오.
6. 도구 막대에서 샘플 레이트와 샘플 시간을 선택하십시오.
7. **시작**을 클릭하거나 `S`를 누르십시오.

캡처 중에는 채널 설정을 변경할 수 없습니다. 최고 샘플 레이트인 10 MHz에서 최대 샘플 시간은 약 10초입니다. 1 kHz에서는 캡처가 하루 동안 계속될 수 있습니다.

데이터 수집 모드는 오실로스코프 모드의 교정을 사용합니다. 채널에 오프셋이 보이면 오실로스코프 모드에서 장치를 교정하십시오.
