# 주 창

## 주 창의 구성

주 창은 다음 부분으로 되어 있습니다.

- **도구 막대.** 도구 막대에는 장치, 캡처, 도구의 컨트롤이 있습니다.
- **파형 영역.** 파형 영역은 채널마다 한 행을 표시합니다. 행 위에 시간 눈금자가 있습니다.
- **채널 레이블.** 각 행 왼쪽의 레이블은 채널 번호, 이름, 트리거 버튼을 표시합니다.
- **도크.** 도크는 파형 영역 옆의 패널입니다. 트리거, 디코더, 측정, 검색 도구는 도크에서 열립니다.

## 도구 막대

도구 막대에는 처음부터 끝까지 다음 항목이 있습니다.

| 항목 | 기능 |
| --- | --- |
| **파일** | 데이터를 열고, 저장하고, 내보내고, 세션을 저장하는 메뉴입니다. [파일과 세션](12-files.md)을 참조하십시오. |
| 장치 유형 | 연결을 표시하는 레이블입니다: **USB 2.0**, **USB 3.0**, **데모** 또는 **파일**. |
| 장치 목록 | 앱이 사용하는 장치입니다. 여기에서 다른 장치나 데모 장치를 선택하십시오. |
| 장치 모드 | **로직 분석기**, **오실로스코프** 또는 **데이터 수집**. 목록에는 장치에서 사용할 수 있는 모드만 표시됩니다. |
| 샘플 시간 | 캡처 한 번의 시간 길이입니다. |
| 샘플 레이트 | 채널마다 1초 동안의 샘플 수입니다. |
| **모드** | 캡처 모드입니다: **단일**, **반복** 또는 **루프**. |
| **시작** | 캡처를 시작합니다. 캡처 중에는 이 버튼이 **정지**로 바뀝니다. |
| **즉시** | 트리거를 기다리지 않는 캡처를 시작합니다. |
| **트리거** | 트리거 도크를 엽니다. |
| **디코드** | 디코더 도크를 엽니다. |
| **측정** | 측정 도크를 엽니다. |
| **검색** | 검색 막대를 엽니다. |
| **옵션** | **장치 옵션...**과 **표시** 메뉴가 있는 메뉴입니다. |
| **도움말** | 언어, 이 설명서, 업데이트 페이지, 로그 옵션, 문제 보고 페이지가 있는 메뉴입니다. |

장치 유형 레이블은 다음 값을 표시합니다.

- **USB 3.0**: 장치가 USB 3.0 연결을 사용합니다.
- **USB 2.0**: 장치가 USB 2.0 연결을 사용합니다. 장치에 USB 3.0 연결이 있으면 USB 3.0 포트에 연결하십시오. USB 2.0 연결은 스트림 모드의 최대 샘플 레이트를 낮춥니다.
- **데모**: 장치가 데모 장치입니다. 데모 장치는 테스트 신호를 만듭니다. 앱의 기능을 시험할 때 사용하십시오.
- **파일**: 앱이 파일의 데이터를 표시합니다. 장치는 없습니다.

## 키보드 단축키

| 키 | 기능 |
| --- | --- |
| `S` | 캡처를 시작하거나 정지합니다. |
| `I` | 즉시 캡처를 시작하거나 정지합니다. 오실로스코프 모드에서는 캡처를 한 번 하고 정지합니다. |
| `T` | 트리거 도크를 열거나 닫습니다. |
| `D` | 디코더 도크를 열거나 닫습니다. |
| `M` | 측정 도크를 열거나 닫습니다. |
| `R` | 검색 막대를 열거나 닫습니다. |
| `O` | **장치 옵션** 창을 엽니다. |
| `Page Up` | 파형을 창 너비 하나만큼 왼쪽으로 이동합니다. |
| `Page Down` | 파형을 창 너비 하나만큼 오른쪽으로 이동합니다. |
| `←` | 확대합니다. |
| `→` | 축소합니다. |
| `0`, `1` | 오실로스코프 모드에서 채널 0 또는 채널 1의 스케일 컨트롤을 선택하거나 해제합니다. |
| `↑`, `↓` | 오실로스코프 모드에서 선택한 채널의 수직 스케일을 변경합니다. |

단축키는 파형 영역에 키보드 포커스가 있을 때 작동합니다.
