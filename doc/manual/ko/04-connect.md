# DSLogic Plus 연결

## USB 케이블 연결

> [!NOTE]
> 장치와 함께 제공된 USB 케이블이나 품질이 좋은 짧은 USB 케이블을 사용하십시오. 케이블을 컴퓨터의 포트에 직접 연결하십시오. USB 허브나 긴 케이블은 캡처에 오류를 일으킬 수 있습니다.

1. USB 케이블을 DSLogic Plus에 연결하십시오.
2. USB 케이블의 다른 쪽 끝을 컴퓨터의 USB 포트에 연결하십시오.
3. DSLogic Plus의 표시등이 켜지는지 확인하십시오. 앱이 시작되기 전에는 표시등이 빨간색입니다.
4. Logic Analyze를 시작하십시오.
5. 표시등이 녹색으로 바뀌는지 확인하십시오.
6. 도구 막대의 장치 목록에 **DSLogic Plus**가 표시되는지 확인하십시오.

![USB 연결](../figures/usb-connection.png)

장치 목록에 장치가 표시되지 않으면 다음 단계를 수행하십시오.

1. 컴퓨터에서 USB 케이블을 분리하십시오.
2. 5초 동안 기다리십시오.
3. USB 케이블을 다른 USB 포트에 연결하십시오.
4. 3단계 후에도 장치 목록에 장치가 표시되지 않으면 앱을 종료하고 다시 시작하십시오.

> [!NOTE]
> 한 번에 하나의 프로그램만 장치를 사용할 수 있습니다. `dslcap`이나 다른 프로그램이 장치를 사용하면 앱이 장치를 찾을 수 없습니다.

## 프로브 케이블 연결

프로브 케이블에는 채널선이 16개 있습니다. 각 채널선에는 실드, 신호 끝, 접지 끝이 있습니다. 선의 색은 채널 0부터 15까지를 구별합니다. 선 하나에는 다음 신호가 더 있습니다.

- **CK**: 외부 클록 입력입니다. **외부 클록 사용** 설정과 함께만 사용하십시오.
- **TI**: 외부 트리거 신호 입력입니다.
- **TO**: 트리거 신호 출력입니다. 트리거가 발생하면 장치가 TO로 펄스를 보냅니다.

보통 CK, TI, TO 선은 연결하지 않습니다.

![프로브 케이블과 채널](../figures/probe-cable-channels.png)

1. 프로브 케이블을 DSLogic Plus의 입력 커넥터에 연결하십시오.
2. 커넥터를 장치에 끝까지 밀어 넣으십시오.

## 채널을 회로에 연결

> [!WARNING]
> 프로브를 상용 전원 전압에 연결하지 마십시오. 상용 전원 전압과 전기적으로 연결된 회로에 프로브를 연결하지 마십시오. 이 전압은 부상 또는 사망을 일으킬 수 있습니다.

> [!CAUTION]
> 접지선을 연결하기 전에 회로의 접지와 컴퓨터의 접지가 같은 전압인지 확인하십시오. 전압 차이는 큰 전류를 일으켜 장비를 손상시킬 수 있습니다.

1. 측정하는 회로의 전원을 분리하십시오.
2. 접지선을 하나 이상 회로의 접지에 연결하십시오.
3. 사용하는 각 채널선을 회로의 신호에 연결하십시오.
4. 프로브가 다른 접점에 닿지 않는지 확인하십시오.
5. 회로에 전원을 연결하십시오.

![접지 연결: 공통 접지 하나(왼쪽) 또는 채널마다 접지 하나(오른쪽)](../figures/probe-grounding.png)

주파수가 5 MHz보다 낮은 신호에서는 모든 채널에 접지선 하나로 충분합니다. 주파수가 더 높은 신호에서는 각 채널선의 접지 끝을 해당 신호 가까이의 접지에 연결하십시오. 접지 연결이 짧으면 신호 에지가 깨끗합니다.

## DSLogic Plus 분리

> [!CAUTION]
> 캡처 중에 USB 케이블을 분리하지 마십시오. 분리하면 캡처 데이터에 오류가 생길 수 있습니다.

1. 캡처를 정지하십시오. 도구 막대에 **정지**가 표시되면 클릭하십시오.
2. 회로의 전원을 분리하십시오.
3. 회로에서 프로브를 분리하십시오.
4. USB 케이블을 분리하십시오.
