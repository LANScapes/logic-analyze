# 측정

마우스나 커서로 파형을 측정할 수 있습니다. 커서는 캡처의 한 시간에 있는 수직선입니다.

## 포인터로 펄스 측정

채널의 펄스에 포인터를 놓으십시오. 포인터 근처의 상자에 펄스의 다음 값이 표시됩니다.

- **폭**: 펄스의 시간 길이.
- **주기**: 한 에지부터 같은 방향의 다음 에지까지의 시간.
- **주파수**: 1을 주기로 나눈 값.
- **듀티 사이클**: 주기에 대한 하이 시간의 백분율.

![포인터 위치의 측정](../figures/hover-measurement.png)

이 상자를 켜거나 끄려면 측정 도크를 열고 **플로팅 측정 활성화**를 사용하십시오.

## 영역 안의 에지 세기

1. 채널의 파형에서 하이 레벨과 로우 레벨 사이에 포인터를 놓으십시오.
2. 포인터를 영역의 시작으로 옮기십시오.
3. 마우스 왼쪽 버튼을 클릭하십시오.
4. 포인터를 영역의 끝으로 옮기십시오. 앱이 에지, 상승 에지, 하강 에지의 수를 표시합니다.
5. 측정을 마치려면 마우스 왼쪽 버튼을 다시 클릭하십시오.

## 두 에지 사이의 시간 측정

1. 첫 번째 에지에 포인터를 놓으십시오.
2. 마우스 왼쪽 버튼을 클릭하십시오.
3. 포인터를 두 번째 에지로 옮기십시오. 앱이 두 에지 사이의 시간과 샘플 수를 표시합니다.
4. 측정을 마치려면 마우스 왼쪽 버튼을 다시 클릭하십시오.

![두 에지 사이의 시간](../figures/edge-distance.png)

## 커서 추가

다음 방법 중 하나를 사용하십시오.

- 파형 영역에서 원하는 시간에 마우스 왼쪽 버튼을 더블클릭하십시오. 포인터가 에지 가까이에 있으면 커서가 에지로 이동합니다.
- 시간 눈금자에서 마우스 왼쪽 버튼을 클릭하십시오. 눈금자에 화살표가 나타납니다. 커서를 추가하려면 화살표를 클릭하십시오.

![시간 눈금자에서 커서 추가](../figures/ruler-insert-cursor.png)

각 커서에는 번호가 있습니다. 번호는 1부터 시작합니다.

## 커서 이동

다음 방법 중 하나를 사용하십시오.

- 커서에 포인터를 놓으십시오. 커서 선이 굵어집니다. 커서를 클릭하십시오. 마우스를 움직이십시오. 커서를 놓으려면 다시 클릭하십시오. 에지 가까이에서는 커서가 에지로 이동합니다.
- 시간 눈금자에서 새 시간에 마우스 왼쪽 버튼을 클릭하십시오. 눈금자에 모든 커서의 번호가 표시됩니다. 이동할 커서의 번호를 클릭하십시오.

![시간 눈금자에서 커서 이동](../figures/ruler-move-cursor.png)

## 커서로 이동

1. 시간 눈금자에서 마우스 오른쪽 버튼을 클릭하십시오. 눈금자에 모든 커서의 번호가 표시됩니다.
2. 커서 번호를 클릭하십시오. 파형이 그 커서의 위치로 이동합니다.

![커서 3으로 이동](../figures/ruler-jump-cursor.png)

## 커서로 측정

측정 도크를 열려면 도구 막대에서 **측정**을 클릭하거나 `M`을 누르십시오. 도크에는 다음 그룹이 있습니다.

- **커서 간 거리**: 두 커서 사이의 시간과 샘플 수.
- **에지**: 두 커서 사이에서 채널 하나의 에지 수.
- **커서**: 각 커서의 시간과 샘플 번호.

시간 측정을 추가하려면 다음 단계를 수행하십시오.

1. **커서 간 거리** 그룹에서 **+** 버튼을 클릭하십시오.
2. 시작 필드를 클릭하고 첫 번째 커서를 선택하십시오.
3. 끝 필드를 클릭하고 두 번째 커서를 선택하십시오.

도크의 **시간/샘플** 열에 결과가 표시됩니다.

에지 수 측정을 추가하려면 다음 단계를 수행하십시오.

1. **에지** 그룹에서 **+** 버튼을 클릭하십시오.
2. 시작 커서와 끝 커서를 선택하십시오.
3. 채널을 선택하십시오.

도크에 상승 에지, 하강 에지, 모든 에지의 수가 표시됩니다.

측정을 제거하려면 그 행의 **×** 버튼을 클릭하십시오.

## 커서 삭제

다음 방법 중 하나를 사용하십시오.

- 시간 눈금자의 커서 레이블에서 **×**를 클릭하십시오.
- 측정 도크의 **커서** 그룹에서 커서의 **×** 버튼을 클릭하십시오.

앱은 남은 커서에 새 번호를 줍니다.
