# 기술 용어와 동사

이 설명서에서 각 기술 용어는 뜻이 하나뿐입니다. 이 설명서의 각 언어판은 기술 용어마다 이름 하나만 사용합니다.

## 기술 용어

| 용어 | 정의 |
| --- | --- |
| 앱 | Logic Analyze 프로그램. |
| 버퍼 모드 | 캡처가 끝날 때까지 장치가 샘플을 메모리에 저장하는 작동 모드. |
| 캡처 | 시작부터 정지까지 신호를 한 번 기록한 것. |
| 채널 | 장치의 입력 하나와 그 데이터를 표시하는 행. |
| 채널 모드 | 채널 수와 최대 샘플 레이트를 선택하는 설정. |
| 커서 | 캡처의 한 시간에 있는 수직선. 측정에 커서를 사용합니다. |
| 디코더 | 데이터를 읽고 프로토콜의 프레임을 찾는 앱의 부분. |
| 데모 장치 | 테스트 신호를 만드는 앱 안의 장치. 하드웨어가 없습니다. |
| 장치 | DSLogic 로직 분석기 또는 DSCope 오실로스코프. |
| 도크 | 파형 영역 옆의 패널. |
| 에지 | 로우 레벨에서 하이 레벨로의 변화(상승 에지) 또는 하이 레벨에서 로우 레벨로의 변화(하강 에지). |
| 접지 | 회로의 0 V 지점. |
| 레벨 | 디지털 신호의 상태: 하이 또는 로우. |
| 프로브 | 채널을 회로에 연결하는 선 또는 클립. |
| 프로토콜 | 버스 데이터의 규격. 예: UART, I2C, SPI. |
| 펄스 | 두 에지 사이의 레벨. |
| 샘플 | 한 시간에서 채널의 값. |
| 샘플 시간 | 캡처 한 번의 시간 길이. |
| 샘플 레이트 | 채널마다 1초 동안의 샘플 수. |
| 세션 | 앱과 장치의 설정이 들어 있는 파일. |
| 설정 | 앱에서 변경할 수 있는 값. |
| 스트림 모드 | 캡처 중에 장치가 샘플을 컴퓨터로 보내는 작동 모드. |
| 임계값 | 로우 레벨과 하이 레벨을 나누는 전압. |
| 시간 눈금자 | 파형 영역 위의 시간 눈금. |
| 트리거 | 캡처에서 한 시간을 표시하는 신호 조건. |
| 트리거 위치 | 캡처 안의 트리거 지점 위치. 샘플 시간에 대한 백분율. |
| 파형 | 채널의 신호를 나타내는 선. |
| 파형 영역 | 창에서 파형을 표시하는 부분. |

## 기술 동사

| 동사 | 정의 |
| --- | --- |
| 캡처하다 | 장치로 신호를 기록하다. |
| 클릭하다 | 마우스 버튼을 눌렀다가 놓다. |
| 디코드하다 | 데이터를 읽고 프로토콜의 프레임을 찾다. |
| 더블클릭하다 | 빠르게 두 번 클릭하다. |
| 드래그하다 | 마우스 버튼을 누른 상태로 항목을 옮기다. |
| 내보내다 | 다른 프로그램용 형식으로 데이터를 저장하다. |
| 누르다 | 키보드의 키를 누르다. |
| 샘플링하다 | 한 시간에서 신호의 값을 읽다. |
| 입력하다 | 키보드로 텍스트를 쓰다. |
| 확대하다, 축소하다 | 파형의 더 짧은 부분 또는 더 긴 부분을 표시하다. |
