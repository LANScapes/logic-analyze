# 앱 설치 및 시작

## 앱 설치

1. 프로젝트의 릴리스 페이지로 이동하십시오: <https://github.com/LANScapes/logic-analyze/releases>.
2. 최신 릴리스의 ZIP 파일을 다운로드하십시오.
3. Finder에서 ZIP 파일을 여십시오. Finder가 **Logic Analyze.app**을 추출합니다.
4. **Logic Analyze.app**을 **응용 프로그램** 폴더로 드래그하십시오.

앱에는 필요한 라이브러리, 펌웨어, 프로토콜 디코더가 모두 들어 있습니다. macOS에서는 드라이버를 설치하지 않습니다.

## 앱 시작

1. 로직 분석기를 컴퓨터에 연결하십시오. [DSLogic Plus 연결](04-connect.md)을 참조하십시오.
2. **응용 프로그램** 폴더 또는 Launchpad에서 **Logic Analyze**를 여십시오.
3. macOS가 앱에 대한 메시지를 표시하면 **열기**를 클릭하십시오.

앱을 처음 시작하면 **문서** 창이 나타날 수 있습니다. 이 설명서를 읽으려면 **열기**를 클릭하십시오. 창을 닫으려면 **무시**를 클릭하십시오. 이 창을 다시 보지 않으려면 **다시 표시 안 함**을 클릭하십시오.

## 앱 업데이트

1. **도움말** › **업데이트**를 클릭하십시오. 앱이 웹 브라우저에서 릴리스 페이지를 엽니다.
2. 릴리스 페이지에 더 새로운 버전이 있으면 다운로드하십시오.
3. Logic Analyze를 종료하십시오.
4. **응용 프로그램** 폴더의 **Logic Analyze.app**을 새 버전으로 교체하십시오.

앱을 교체해도 설정은 유지됩니다.

## 이 설명서 열기

**도움말** › **설명서...**를 클릭하십시오. 앱은 사용자 인터페이스의 언어로 이 설명서를 엽니다. 그 언어의 설명서가 없으면 앱은 영어 설명서를 엽니다.

## 언어 변경

1. **도움말** › **언어**를 클릭하십시오.
2. 목록에서 언어를 선택하십시오.

사용자 인터페이스가 선택한 언어로 바뀝니다.

## 테마 변경

1. **옵션** › **표시** › **테마**를 클릭하십시오.
2. **다크** 또는 **라이트**를 선택하십시오.

## 도구 막대 이동

도구 막대를 창의 위, 아래, 왼쪽 또는 오른쪽에 둘 수 있습니다. 도구 막대가 왼쪽이나 오른쪽에 있으면 16개 채널이 창의 전체 높이를 사용할 수 있습니다.

1. 도구 막대 시작 부분의 손잡이에 포인터를 놓으십시오.
2. 마우스 버튼을 누른 상태로 유지하십시오.
3. 도구 막대를 창의 가장자리로 드래그하십시오.
4. 마우스 버튼을 놓으십시오.

앱을 다시 시작해도 도구 막대의 위치는 유지됩니다.

## 표시 옵션

표시 옵션을 변경하려면 **옵션** › **표시** › **옵션**을 클릭하십시오. **표시 옵션** 창에 다음 설정이 있습니다.

| 설정 | 기능 |
| --- | --- |
| **마우스 드래그로 파형 스크롤** | 파형을 빠르게 드래그하고 놓으면 파형이 계속 움직입니다. 그런 다음 느려지고 멈춥니다. |
| **반복 모드 정지 시 최신 데이터로 업데이트** | **반복** 모드에서 캡처를 정지하면 앱이 마지막 캡처의 데이터를 표시합니다. 이 데이터는 완전하지 않습니다. |
| **최신 데이터로 자동 스크롤** | 스트림 모드에서 파형이 움직여 가장 새로운 데이터를 표시합니다. |
| **트리거 위치를 가운데에 표시** | 오실로스코프 모드에서 앱이 트리거 위치를 창의 가운데에 표시합니다. |
| **제목 표시줄에 세션 이름 표시** | 제목 표시줄에 세션 파일의 이름이 표시됩니다. |
| **글꼴 크기** | 파형 영역의 텍스트 크기입니다. |

## 로그 옵션

앱은 로그 파일을 기록할 수 있습니다. 로그 파일은 문제의 원인을 찾는 데 도움이 됩니다.

1. **도움말** › **로그 옵션**을 클릭하십시오.
2. **로그 수준**에서 0부터 5까지의 값을 선택하십시오. 값이 높을수록 더 많은 메시지를 기록합니다.
3. **파일로 저장**을 선택하십시오.
4. 기존 로그 파일의 끝에 새 메시지를 추가하려면 **추가 모드**를 선택하십시오.
5. **확인**을 클릭하십시오.

로그 파일을 보려면 **로그 옵션** 창에서 **열기**를 클릭하십시오. 로그 파일을 지우려면 **지우기**를 클릭하십시오.

## 문제 보고

**도움말** › **버그 보고**를 클릭하십시오. 앱이 웹 브라우저에서 프로젝트의 이슈 페이지를 엽니다. 보고서에 앱 버전, macOS 버전, 장치 모델을 적으십시오. 가능하면 로그 파일을 첨부하십시오.
