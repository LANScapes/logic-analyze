# Триггеры

Триггер — это условие в сигналах. Когда условие выполняется, устройство отмечает этот момент как точку триггера. Триггер позволяет захватить ту часть сигнала, которую вы хотите изучить.

В приложении есть два типа триггера:

- **Простой триггер**: Перепад или уровень на одном или нескольких каналах.
- **Расширенный триггер**: Последовательность условий или значение на последовательной шине.

Чтобы открыть панель триггера, щелкните **Триггер** на панели инструментов или нажмите `T`.

> [!NOTE]
> Если сигнал не соответствует условию триггера, захват продолжает ждать. Чтобы увидеть сигнал без триггера, щелкните **Сразу**. Чтобы прекратить ожидание, щелкните **Стоп**.

## Позиция триггера

Настройка **Позиция триггера** задает место точки триггера в захвате. Значение — это процент от длительности захвата.

- Малое значение, например 10%, показывает больше сигнала после триггера.
- Большое значение, например 90%, показывает больше сигнала до триггера.

Позиция триггера использует память устройства. Поэтому ее можно задать только в режиме буфера. В потоковом режиме позиция триггера всегда около 1%.

## Простой триггер

Каждая метка канала в области осциллограмм имеет пять кнопок триггера. Слева направо это такие кнопки:

1. Фронт
2. Высокий уровень
3. Спад
4. Низкий уровень
5. Фронт или спад

![Кнопки триггера на метке канала](../figures/simple-trigger-buttons.png)

Чтобы задать простой триггер, выполните такие шаги:

1. Откройте панель триггера.
2. Выберите **Простой триггер**.
3. На метке канала щелкните нужную кнопку триггера. Кнопка меняет цвет.
4. Чтобы удалить триггер с канала, щелкните ту же кнопку еще раз.
5. Задайте **Позиция триггера**.

Если вы задаете триггер на нескольких каналах, все условия должны выполняться на одной и той же выборке (логическое И).

## Расширенный триггер

> [!NOTE]
> Расширенный триггер доступен только в режиме буфера. Чтобы использовать его, задайте для **Режим работы** значение **Режим буфера**. См. [Параметры устройства](05-device-options.md).

Чтобы использовать расширенный триггер, выберите **Расширенный триггер** на панели триггера. Затем выберите вкладку **Многоступенчатый триггер** или вкладку **Последовательный триггер**.

### Значения для каждого канала

Многоступенчатый триггер и последовательный триггер используют строку из 16 символов. Каждый символ — это условие для одного канала. Правый символ — это канал 0. Левый символ — это канал 15.

| Символ | Условие |
| --- | --- |
| `X` | Любое значение (канал не влияет). |
| `0` | Низкий уровень. |
| `1` | Высокий уровень. |
| `R` | Фронт. |
| `F` | Спад. |
| `C` | Фронт или спад. |

### Многоступенчатый триггер

Многоступенчатый триггер — это последовательность условий. Каждое условие — это ступень. Устройство сначала проверяет ступень 0. Когда условие ступени выполняется, устройство переходит к следующей ступени. Триггер срабатывает, когда последняя ступень завершена. Можно использовать до 16 ступеней.

Каждая ступень имеет такие настройки:

- Две строки условий каналов.
- Для каждой строки `==` или `!=`. При `==` условие выполняется, когда каналы соответствуют строке. При `!=` условие выполняется, когда каналы не соответствуют строке.
- **И** или **ИЛИ**. Эта настройка связывает две строки.
- **Счётчик**: Сколько раз условие должно выполниться, чтобы ступень была завершена.
- **Подряд**: Если установить этот флажок, условие должно выполняться в выборках, которые идут друг за другом без перерыва.

Чтобы задать многоступенчатый триггер, выполните такие шаги:

1. В поле **Всего ступеней триггера** выберите число ступеней.
2. В списке ступеней справа щелкните ступень 0.
3. Введите условия каналов в первой строке.
4. Если нужно, введите условия каналов во второй строке и выберите **И** или **ИЛИ**.
5. Введите значение в поле **Счётчик**.
6. Повторите шаги 2–5 для каждой другой ступени.

Вот три примера.

**Пример 1.** Триггер, когда канал 0 находится в высоком уровне больше 1000 выборок:

1. Задайте для **Всего ступеней триггера** значение 1.
2. В ступени 0 введите `1` для канала 0 в первой строке.
3. Выберите **Подряд**.
4. Задайте для **Счётчик** значение 1000.

![Пример 1](../figures/stage-example-level-count.png)

**Пример 2.** Триггер по фронту на канале 0 или по спаду на канале 1:

1. Задайте для **Всего ступеней триггера** значение 1.
2. В ступени 0 введите `R` для канала 0 в первой строке.
3. Введите `F` для канала 1 во второй строке.
4. Выберите **ИЛИ**.

![Пример 2](../figures/stage-example-or.png)

**Пример 3.** Триггер по фронту на канале 0, затем по 100 спадам на канале 1, затем по высокому уровню на канале 2:

1. Задайте для **Всего ступеней триггера** значение 3.
2. В ступени 0 введите `R` для канала 0.
3. В ступени 1 введите `F` для канала 1. Задайте для **Счётчик** значение 100.
4. В ступени 2 введите `1` для канала 2.

![Пример 3](../figures/stage-example-sequence.png)

### Последовательный триггер

Последовательный триггер находит значение данных на последовательной шине. Он работает как сдвиговый регистр. Вот его настройки:

- **Флаг начала**: Условие, которое запускает последовательный триггер.
- **Флаг конца**: Условие, которое очищает сдвиговый регистр.
- **Флаг тактирования**: Условие, которое добавляет один бит в сдвиговый регистр.
- **Канал данных**: Канал, который передает данные.
- **Биты данных**: Число битов в значении.
- **Значение данных**: Значение, которое вызывает триггер.

После флага начала устройство читает канал данных на каждом флаге тактирования. Устройство сдвигает этот бит в сдвиговый регистр. Когда последние биты сдвигового регистра равны **Значение данных**, триггер срабатывает. Когда появляется флаг конца, устройство очищает сдвиговый регистр.

![Настройки последовательного триггера](../figures/serial-trigger-panel.png)

**Пример 4.** Триггер, когда на шине I2C появляется значение `010000100`. Канал 0 — это SCL, канал 1 — это SDA.

1. Задайте для **Флаг начала** спад на SDA при высоком уровне SCL: `F1` в двух правых символах.
2. Задайте для **Флаг конца** фронт на SDA при высоком уровне SCL: `R1`.
3. Задайте для **Флаг тактирования** фронт на SCL: `R` для канала 0.
4. Задайте для **Канал данных** значение 1.
5. Задайте для **Биты данных** значение 9.
6. Введите `010000100` в поле **Значение данных**.

![Пример 4](../figures/serial-example-i2c.png)

**Пример 5.** Триггер, когда на линии MOSI шины SPI появляется значение `0x1234`. Канал 0 — это CS#, канал 1 — это CLK, канал 2 — это MISO, канал 3 — это MOSI.

1. Задайте для **Флаг начала** спад на CS#: `F` для канала 0.
2. Задайте для **Флаг конца** фронт на CS#: `R` для канала 0.
3. Задайте для **Флаг тактирования** фронт на CLK: `R` для канала 1.
4. Задайте для **Канал данных** значение 3.
5. Задайте для **Биты данных** значение 16.
6. Введите `0001001000110100` в поле **Значение данных**.

![Пример 5](../figures/serial-example-spi.png)

Чтобы ввести значение в шестнадцатеричном виде, выберите **Ввод в шестнадцатеричном формате**. Затем введите значение в поле **Hex**.
