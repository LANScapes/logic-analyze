# Введение

## О программе Logic Analyze

Logic Analyze — это приложение для macOS для логических анализаторов DreamSourceLab. Приложение поставляет компания LANScapes. Приложение создано на основе DSView — программы DreamSourceLab. DSView использует программное обеспечение проекта sigrok.

Приложение записывает цифровые сигналы с логического анализатора DSLogic. Затем оно показывает сигналы как осциллограммы. Вы можете измерять осциллограммы и декодировать последовательные протоколы. Вы также можете сохранять данные и экспортировать их в другие форматы.

В примерах этого руководства используется DSLogic Plus. Другие модели DSLogic работают по тем же процедурам. Их ограничения по каналам, памяти и частоте дискретизации другие.

В приложение также входит инструмент `dslcap`. Этот инструмент захватывает данные без главного окна. См. [Инструмент dslcap](13-dslcap.md).

## Об этом руководстве

Это руководство написано по правилам ASD-STE100 Simplified Technical English. Каждое предложение короткое. Каждый шаг процедуры содержит одну инструкцию. Каждый технический термин в этом руководстве имеет только одно значение. В разделе [Технические термины и глаголы](15-terms.md) дан список технических терминов.

В этом руководстве используются такие форматы текста:

- **Жирный текст** показывает надпись в приложении, например кнопку, пункт меню или поле.
- `Моноширинный текст` показывает клавишу, команду, имя файла или значение, которое вы вводите.
- Путь по меню обозначается знаком ›, например **Файл** › **Сохранить…**.
- Список шагов с номерами — это процедура. Выполняйте шаги в указанной последовательности.

## Указания по безопасности

В указаниях по безопасности это руководство использует такие слова:

- **ПРЕДУПРЕЖДЕНИЕ** обозначает риск травмы или смерти.
- **ВНИМАНИЕ** обозначает риск повреждения оборудования или риск для ваших данных.
- **ПРИМЕЧАНИЕ** дает полезную информацию. Текст после слова **ПРИМЕЧАНИЕ** не содержит инструкций.

Указание по безопасности стоит перед шагом, к которому оно относится. Прочитайте все указания по безопасности перед началом процедуры.

> [!WARNING]
> Не подключайте щупы к сетевому напряжению. Не подключайте щупы к цепи, которая имеет электрическое соединение с сетевым напряжением. Щупы имеют электрическое соединение с компьютером. Напряжение может стать причиной травмы или смерти.

> [!CAUTION]
> Не подавайте на вход канала напряжение выше предела, указанного в спецификации устройства. Слишком высокое напряжение может повредить логический анализатор.

> [!CAUTION]
> Провода земли логического анализатора соединены с землей компьютера через кабель USB. Подключайте провода земли только к земле цепи, которую вы измеряете. Если две земли имеют разное напряжение, может пройти большой ток и повредить цепь, логический анализатор и компьютер.

## Системные требования

Необходимо такое оборудование:

- Компьютер Mac с macOS. Минимальная версия macOS указана в примечаниях к выпуску.
- Порт USB. Порт USB 3.0 дает самую высокую скорость. Порт USB 2.0 тоже работает.
- Логический анализатор DSLogic, его кабель USB и его кабель щупов.

Вы можете использовать приложение без логического анализатора. Устройство **Демо** создает тестовые сигналы. Вы также можете открыть файл данных предыдущего захвата.
