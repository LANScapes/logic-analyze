# Технические термины и глаголы

Каждый из этих технических терминов имеет в этом руководстве только одно значение. Каждая языковая версия этого руководства использует только одно слово для каждого технического термина.

## Технические термины

| Термин | Определение |
| --- | --- |
| приложение | Программа Logic Analyze. |
| режим буфера | Режим работы, в котором устройство хранит выборки в своей памяти до конца захвата. |
| захват | Одна запись сигналов от пуска до остановки. |
| канал | Один вход устройства и строка, которая показывает его данные. |
| режим каналов | Настройка, которая выбирает число каналов и максимальную частоту дискретизации. |
| курсор | Вертикальная линия в момент времени в захвате. Курсоры используют для измерений. |
| декодер | Часть приложения, которая читает данные и находит кадры протокола. |
| демо-устройство | Устройство в приложении, которое создает тестовые сигналы. Оно не имеет аппаратной части. |
| устройство | Логический анализатор DSLogic или осциллограф DSCope. |
| боковая панель | Панель сбоку от области осциллограмм. |
| перепад | Переход от низкого уровня к высокому (фронт) или от высокого уровня к низкому (спад). |
| земля | Точка 0 V цепи. |
| уровень | Состояние цифрового сигнала: высокий или низкий. |
| щуп | Провод или зажим, который соединяет канал с цепью. |
| протокол | Спецификация данных на шине, например UART, I2C или SPI. |
| импульс | Уровень между двумя перепадами. |
| выборка | Значение канала в один момент времени. |
| длительность захвата | Время одного захвата. |
| частота дискретизации | Число выборок в секунду для каждого канала. |
| сеанс | Файл с настройками приложения и устройства. |
| настройка | Значение, которое можно изменить в приложении. |
| потоковый режим | Режим работы, в котором устройство передает выборки в компьютер во время захвата. |
| порог | Напряжение, которое разделяет низкий уровень и высокий уровень. |
| шкала времени | Шкала времени над областью осциллограмм. |
| триггер | Условие в сигналах, которое отмечает момент времени в захвате. |
| позиция триггера | Положение точки триггера в захвате в процентах от длительности захвата. |
| осциллограмма | Линия, которая показывает сигнал канала. |
| область осциллограмм | Часть окна, которая показывает осциллограммы. |

## Технические глаголы

| Глагол | Определение |
| --- | --- |
| захватить | Записать сигналы с помощью устройства. |
| щелкнуть | Нажать и отпустить кнопку мыши. |
| декодировать | Прочитать данные и найти кадры протокола. |
| дважды щелкнуть | Быстро щелкнуть два раза. |
| перетащить | Переместить элемент при нажатой кнопке мыши. |
| экспортировать | Сохранить данные в формате для другой программы. |
| нажать | Нажать клавишу на клавиатуре. |
| сделать выборку | Прочитать значение сигнала в один момент времени. |
| ввести | Написать текст с клавиатуры. |
| увеличить масштаб, уменьшить масштаб | Показать более короткую или более длинную часть осциллограммы. |
