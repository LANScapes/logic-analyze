# Инструмент dslcap

Инструмент `dslcap` захватывает данные с устройства DSLogic без главного окна. Используйте его в скриптах и в автоматических тестах. Инструмент записывает выборки в двоичный файл. Он выводит один объект JSON с результатом в стандартный вывод.

Инструмент находится в пакете приложения:

```sh
"/Applications/Logic Analyze.app/Contents/MacOS/dslcap"
```

> [!NOTE]
> Устройство может использовать только одна программа в один момент. Закройте Logic Analyze перед использованием `dslcap`.

## Выведите список устройств

Чтобы вывести список устройств, которые может найти библиотека, введите эту команду:

```sh
dslcap --list
```

Чтобы вывести идентификатор USB каждого подключенного устройства DSLogic, введите эту команду:

```sh
dslcap --list-ids
```

Команда `--list-ids` читает только информацию, которую macOS хранит об устройствах USB. Она не передает данные в устройство. Вывод содержит модель, расположение USB и идентификатор реестра для каждого устройства.

## Захватите данные

Эта команда захватывает 1000000 выборок на каналах 0 и 1 с частотой 10 MHz:

```sh
dslcap --channels 0,1 --samplerate 10000000 --samples 1000000 --out /tmp/capture
```

Инструмент записывает выборки в `/tmp/capture.bin`. Если файл с этим именем уже есть, инструмент останавливается с ошибкой. Инструмент не заменяет файлы.

Вот параметры захвата:

| Параметр | Функция | Начальное значение |
| --- | --- | --- |
| `--channels LIST` | Каналы для записи, например `0,1,2`. | `0` |
| `--samplerate HZ` | Частота дискретизации в Hz. | `10000000` |
| `--samples N` | Число выборок для каждого канала. | `1000000` |
| `--vth VOLTS` | Пороговое напряжение. | `1.6` |
| `--mode MODE` | `buffer` или `stream`. | `buffer` |
| `--trigger CH[:T]` | Триггер на канале CH. Для T используйте `R` (фронт), `F` (спад), `C` (фронт или спад), `1` (высокий уровень) или `0` (низкий уровень). | Без триггера. `R`, если указан только CH. |
| `--trigpos PERCENT` | Позиция триггера в процентах от числа выборок. | `10` |
| `--timeout SEC` | Максимальное время захвата в секундах. | `30` |
| `--out PATH` | Путь к выходному файлу без расширения `.bin`. | Этот параметр обязателен. |
| `--log-level N` | Количество сообщений библиотеки в стандартном выводе ошибок, от 0 (нет) до 5 (все). | `1` |

Инструмент проверяет все параметры до использования устройства. Если параметр неверен, инструмент останавливается и выдает ошибку.

## Выходной файл

Файл `.bin` содержит каналы в порядке их номеров, начиная с наименьшего номера. Для каждого канала файл содержит все выборки этого канала. Каждый байт содержит 8 выборок. Первая выборка — это младший бит. Данные каждого канала занимают целое число блоков по 8 байтов. Поэтому каждый канал занимает `ceil(samples / 64) × 8` байтов.

## Результат JSON

Инструмент выводит один объект JSON в одной строке. После правильного захвата объект содержит имя устройства, частоту дискретизации, число выборок и каналы. Он также содержит пороговое напряжение, режим, триггер, время захвата и путь к файлу `.bin`. Если захват неправильный, объект содержит ключ `error`. В этом случае инструмент не создает файл `.bin`.

Используйте результат только тогда, когда код выхода равен 0 и объект JSON полный.

## Код выхода

| Код | Значение |
| --- | --- |
| 0 | Захват завершен. |
| 1 | Во время работы произошла ошибка, например ошибка ввода-вывода. |
| 2 | Параметр неверен или настройка недоступна на устройстве. |
| 3 | Захват не завершен. |

## Параметры для программ, которые запускают dslcap

- `--parent-fd N`: Инструмент останавливается, когда программа, которая его запустила, закрывает канал (pipe) с дескриптором N. Затем инструмент удаляет свой выходной файл, если захват не завершен.
- `--res DIR`: Папка с файлами прошивки. Обычно инструмент находит эту папку автоматически. Вы также можете задать переменную окружения `DSLCAP_RES`.
- `--res-manifest FD`: Инструмент проверяет значение SHA-256 каждого файла прошивки до передачи файла в устройство.

Файл `tools/dslcap/README.md` в исходном коде содержит всю информацию об этих параметрах.
