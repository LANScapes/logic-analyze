# Декодеры протоколов

Декодер протокола читает данные захвата и находит кадры протокола, например UART, I2C или SPI. Приложение показывает результат в новой строке над каналами. В приложении больше 100 декодеров.

Чтобы открыть панель декодеров, щелкните **Декодер** на панели инструментов или нажмите `D`. Панель состоит из двух частей:

- Список декодеров с полем **Поиск декодера...** вверху.
- Список **Результаты декодирования**. Этот список показывает каждый элемент декодера как строку текста.

## Добавьте декодер

> [!NOTE]
> Декодер с префиксом `0:` — это упрощенная версия. Она не показывает биты. На нее нельзя добавить протокол более высокого уровня. Она декодирует быстрее и использует меньше памяти.

1. Щелкните поле **Поиск декодера...**. Открывается список декодеров.
2. Введите часть имени протокола, например `I2C`. Список показывает только декодеры, которые соответствуют тексту.
3. Щелкните декодер. Открывается окно **Параметры декодера**.
4. Задайте каналы протокола. Например, задайте **SCL** и **SDA** для I2C.
5. Задайте параметры протокола, например скорость UART в бодах.
6. Выберите строки результатов, которые показывает приложение.
7. Если нужно, задайте область декодирования. См. [Декодируйте часть захвата](#decode-region).
8. Щелкните **OK**.

Приложение декодирует данные и показывает результаты в новой строке в области осциллограмм.

Чтобы добавить другие декодеры, повторите процедуру для каждого декодера.

![Кнопки декодера: кнопка настроек открывает параметры декодера](../figures/decoder-buttons.png)

Чтобы изменить настройки декодера, щелкните кнопку настроек этого декодера на панели.

## Добавьте многоуровневый декодер

Некоторые протоколы используют протокол более низкого уровня. Например, протокол 24xx EEPROM использует I2C. Когда вы добавляете протокол более высокого уровня, приложение также добавляет протоколы более низкого уровня.

1. В поле **Поиск декодера...** введите имя протокола более высокого уровня, например `24xx`.
2. Щелкните декодер.
3. В окне **Параметры декодера** задайте параметры для каждого уровня протокола.
4. Щелкните **OK**.

Результаты показывают кадры протокола более низкого уровня, а также команды и данные протокола более высокого уровня.

## Декодируйте часть захвата {#decode-region}

Обычно приложение декодирует все данные. Чтобы декодировать только часть, задайте курсор начала и курсор конца. Например, так можно пропустить шум при сбросе цепи. Меньшая область также уменьшает время декодирования.

1. Добавьте два курсора в начале и в конце области. См. [Измерения](10-measure.md).
2. Откройте окно **Параметры декодера** этого декодера.
3. В списке **Начало** выберите курсор начала.
4. В списке **Конец** выберите курсор конца.
5. Щелкните **OK**.

## Читайте список результатов

Список **Результаты декодирования** показывает элементы декодера в порядке времени. Щелкните строку, чтобы сдвинуть осциллограмму к этому элементу.

Чтобы изменить столбцы списка, щелкните кнопку настроек вверху списка.

## Найдите текст в результатах

1. Введите текст в поле поиска списка **Результаты декодирования**.
2. Щелкните правую стрелку, чтобы перейти к следующей строке с этим текстом. Щелкните левую стрелку, чтобы перейти к предыдущей строке.

Осциллограмма сдвигается к элементу каждой строки, которую находит поиск. Если вы сначала щелкнете строку, поиск начинается с этой строки.

![Поиск в результатах декодирования](../figures/decoder-list-search.png)

Чтобы найти последовательность байтов, поставьте знак `-` между байтами. Например, `70-70-70` находит три байта подряд со значением 70.

![Поиск последовательности байтов](../figures/decoder-multibyte-search.png)

> [!NOTE]
> Поиск последовательности байтов работает только с декодерами UART, I2C и SPI.

## Экспортируйте результаты

1. Щелкните кнопку сохранения вверху списка **Результаты декодирования**. Открывается окно **Экспорт протокола**.
2. В поле **Формат экспорта** выберите CSV или TXT.
3. Выберите каждый столбец, который вы хотите экспортировать. Приложение помещает все столбцы в один файл в порядке времени.
4. Щелкните **OK**.
5. Выберите папку и введите имя файла.
6. Щелкните **Сохранить**.

## Удалите декодер

![Удаление одного декодера или всех декодеров](../figures/decoder-delete.png)

- Чтобы удалить один декодер, щелкните кнопку **×** в строке этого декодера.
- Чтобы удалить все декодеры, щелкните кнопку **×** вверху панели, рядом с кнопкой **+**.
