# Установка и запуск приложения

## Установите приложение

1. Откройте страницу выпусков проекта: <https://github.com/LANScapes/logic-analyze/releases>.
2. Загрузите ZIP-файл самого нового выпуска.
3. Откройте ZIP-файл в Finder. Finder извлекает **Logic Analyze.app**.
4. Перетащите **Logic Analyze.app** в папку **Программы**.

Приложение содержит все необходимые библиотеки, прошивки и декодеры протоколов. В macOS не нужно устанавливать драйвер.

## Запустите приложение

1. Подключите логический анализатор к компьютеру. См. [Подключение DSLogic Plus](04-connect.md).
2. Откройте **Logic Analyze** из папки **Программы** или из Launchpad.
3. Если macOS показывает сообщение о приложении, щелкните **Открыть**.

При первом запуске приложение может показать окно **Документ**. Щелкните **Открыть**, чтобы прочитать это руководство. Щелкните **Игнорировать**, чтобы закрыть окно. Щелкните **Больше не показывать**, если вы не хотите видеть это окно снова.

## Обновите приложение

1. Щелкните **Справка** › **Обновление**. Приложение открывает страницу выпусков в веб-браузере.
2. Если на странице выпусков есть более новая версия, загрузите ее.
3. Закройте Logic Analyze.
4. Замените **Logic Analyze.app** в папке **Программы** новой версией.

После замены приложение сохраняет ваши настройки.

## Откройте это руководство

Щелкните **Справка** › **Руководство…**. Приложение открывает это руководство на языке интерфейса. Если руководства на этом языке нет, приложение открывает руководство на английском языке.

## Измените язык

1. Щелкните **Справка** › **Язык**.
2. Выберите язык в списке.

Интерфейс переключается на выбранный язык.

## Измените тему

1. Щелкните **Параметры** › **Вид** › **Темы**.
2. Выберите **Тёмная** или **Светлая**.

## Переместите панель инструментов

Панель инструментов можно разместить сверху, снизу, слева или справа в окне. Если панель инструментов слева или справа, 16 каналов могут занять всю высоту окна.

1. Наведите указатель на маркер в начале панели инструментов.
2. Нажмите и удерживайте кнопку мыши.
3. Перетащите панель инструментов к краю окна.
4. Отпустите кнопку мыши.

При следующем запуске приложение сохраняет положение панели инструментов.

## Параметры отображения

Чтобы изменить параметры отображения, щелкните **Параметры** › **Вид** › **Параметры**. Окно **Параметры отображения** показывает такие настройки:

| Настройка | Функция |
| --- | --- |
| **Прокрутка осциллограммы перетаскиванием мыши** | Если быстро перетащить осциллограмму и отпустить ее, осциллограмма продолжает двигаться. Затем она замедляется и останавливается. |
| **Обновлять данные при остановке в режиме повтора** | Когда вы останавливаете захват в режиме **Повторно**, приложение показывает данные последнего захвата, который не завершен. |
| **Автопрокрутка к последним данным** | В потоковом режиме осциллограмма движется и показывает самые новые данные. |
| **Позиция триггера по центру** | В режиме осциллографа приложение показывает позицию триггера в середине окна. |
| **Показывать сеанс в заголовке окна** | Строка заголовка показывает имя файла сеанса. |
| **Размер шрифта** | Размер текста в области осциллограмм. |

## Журналирование

Приложение может записывать файл журнала. Файл журнала помогает найти причину проблемы.

1. Щелкните **Справка** › **Журналирование**.
2. В поле **Уровень журнала** выберите значение от 0 до 5. Чем выше значение, тем больше сообщений записывается.
3. Выберите **Сохранять в файл**.
4. Чтобы добавлять новые сообщения в конец имеющегося файла журнала, выберите **Режим дозаписи**.
5. Щелкните **OK**.

Чтобы просмотреть файл журнала, щелкните **Открыть** в окне **Параметры журнала**. Чтобы стереть файл журнала, щелкните **Очистить**.

## Сообщите о проблеме

Щелкните **Справка** › **Сообщить об ошибке**. Приложение открывает страницу проблем проекта в веб-браузере. Укажите в сообщении версию приложения, версию macOS и модель устройства. Если возможно, приложите файл журнала.
