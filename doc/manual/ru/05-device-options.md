# Параметры устройства

## Откройте параметры устройства

1. Щелкните **Параметры** › **Параметры устройства...** на панели инструментов. Вы также можете нажать `O`.
2. Измените настройки в окне **Параметры устройства**.
3. Щелкните **OK**.

Настройки в окне разные для каждой модели устройства. В этой главе даны настройки DSLogic Plus.

> [!NOTE]
> Во время захвата параметры устройства изменить нельзя.

## Режим работы

Настройка **Режим работы** выбирает, как устройство передает данные в компьютер.

**Режим буфера.** Во время захвата устройство хранит выборки во внутренней памяти. После захвата устройство передает данные в компьютер через USB. Память быстрее, чем USB. Поэтому режим буфера дает самые высокие частоты дискретизации. Объем памяти ограничивает длину захвата. Используйте режим буфера для быстрых сигналов и коротких захватов.

**Потоковый режим.** Устройство передает выборки в компьютер во время захвата. Память компьютера ограничивает длину захвата. Вы можете видеть данные во время захвата. Скорость подключения USB ограничивает частоту дискретизации. Используйте потоковый режим для медленных сигналов и длинных захватов.

**Внутренний тест.** Этот режим предназначен только для тестов устройства. Не используйте его для измерений.

## Параметры остановки

Настройка **Параметры остановки** действует только в режиме буфера. Она задает, как работает приложение, когда вы останавливаете захват до конца.

- **Остановить немедленно**: Приложение не получает данные от устройства. Приложение не показывает данные.
- **Выгрузить захваченные данные**: Приложение получает данные, которые устройство записало до остановки. Приложение показывает эти данные.

## Пороговый уровень

Настройка **Пороговый уровень** — это напряжение, которое разделяет низкий уровень и высокий уровень. Сигнал выше порога — это высокий уровень. Сигнал ниже порога — это низкий уровень.

Можно задать значение от 0,0 V до 5,0 V с шагом 0,1 V. Задайте порог около 50% от логического напряжения цепи. Для цепи 3,3 V задайте около 1,6 V.

## Фильтрация

Настройка **Фильтрация** удаляет короткие импульсы из данных.

- **Нет**: Приложение показывает все выборки.
- **1 такт дискретизации**: Приложение удаляет каждый импульс короче одного периода дискретизации.

## Максимальная высота

Настройка **Макс. высота** задает максимальную высоту каждой строки канала в области осциллограмм. **1X** — это одна единица высоты. Используйте большее значение, если вы показываете только небольшое число каналов.

## Сжатие RLE

Если выбрать **Сжатие RLE**, устройство сжимает данные в своей памяти (кодирование длин серий). Эта настройка действует только в режиме буфера. Если в сигналах мало перепадов, устройство может хранить в памяти более длинный захват. Если в сигналах много перепадов, сжатие не увеличивает длину захвата.

## Внешний тактовый сигнал

Если выбрать **Внешний тактовый сигнал**, устройство делает выборку каналов на каждом перепаде тактового сигнала на проводе CK. Устройство не использует свой внутренний тактовый сигнал. Используйте эту настройку для записи шины, которая имеет тактовый сигнал.

## Тактирование по спаду

Эта настройка действует только вместе с **Внешний тактовый сигнал**. Обычно устройство делает выборку каналов по фронту тактового сигнала. Если выбрать **Тактирование по спаду**, устройство делает выборку каналов по спаду тактового сигнала.

## Режим каналов

Режим каналов задает число каналов, которые может использовать устройство. Он также задает максимальную частоту дискретизации. Меньшее число каналов дает более высокую максимальную частоту дискретизации. Выберите режим каналов, который соответствует числу и частоте ваших сигналов.

Для DSLogic Plus есть такие режимы каналов:

| Режим работы | Режим каналов | Максимальная частота дискретизации |
| --- | --- | --- |
| Режим буфера | Каналы 0–15 | 100 MHz |
| Режим буфера | Каналы 0–7 | 200 MHz |
| Режим буфера | Каналы 0–3 | 400 MHz |
| Потоковый режим | 16 каналов | 20 MHz |
| Потоковый режим | 12 каналов | 25 MHz |
| Потоковый режим | 6 каналов | 50 MHz |
| Потоковый режим | 3 канала | 100 MHz |

## Включите и отключите каналы

Под режимами каналов окно показывает флажок для каждого канала.

1. Установите флажок для каждого канала, который вы используете.
2. Снимите флажок для каждого канала, который вы не используете.
3. Чтобы выбрать все каналы, щелкните **Включить все**. Чтобы снять все флажки, щелкните **Отключить все**.

В потоковом режиме меньшее число включенных каналов может позволить более высокую частоту дискретизации.
