# Fachbegriffe und Fachverben

Jeder dieser Fachbegriffe hat in diesem Handbuch nur eine Bedeutung. Jede Sprachversion dieses Handbuchs verwendet für jeden Fachbegriff nur eine Bezeichnung.

## Fachbegriffe

| Begriff | Definition |
| --- | --- |
| App | Das Programm Logic Analyze. |
| Puffermodus | Der Betriebsmodus, in dem das Gerät die Abtastwerte bis zum Ende der Erfassung in seinem Speicher hält. |
| Erfassung | Eine Aufzeichnung der Signale, vom Start bis zum Stopp. |
| Kanal | Ein Eingang des Geräts und die Zeile, die seine Daten zeigt. |
| Kanalmodus | Die Einstellung, die die Anzahl der Kanäle und die maximale Abtastrate auswählt. |
| Cursor | Eine senkrechte Linie bei einer Zeit in der Erfassung. Sie verwenden Cursor für Messungen. |
| Dekoder | Ein Teil der App, der die Daten liest und die Frames eines Protokolls findet. |
| Demo-Gerät | Ein Gerät in der App, das Testsignale erzeugt. Es hat keine Hardware. |
| Gerät | Der DSLogic-Logikanalysator oder das DSCope-Oszilloskop. |
| Dock | Ein Bereich an der Seite des Signalbereichs. |
| Flanke | Ein Wechsel von einem Low-Pegel zu einem High-Pegel (steigende Flanke) oder von einem High-Pegel zu einem Low-Pegel (fallende Flanke). |
| Masse | Der 0-V-Punkt einer Schaltung. |
| Pegel | Der Zustand eines digitalen Signals: high oder low. |
| Messleitung | Die Leitung oder die Klemme, die einen Kanal mit der Schaltung verbindet. |
| Protokoll | Die Spezifikation für Daten auf einem Bus, zum Beispiel UART, I2C oder SPI. |
| Impuls | Ein Pegel zwischen zwei Flanken. |
| Abtastwert | Der Wert eines Kanals zu einer Zeit. |
| Abtastdauer | Die Zeitdauer einer Erfassung. |
| Abtastrate | Die Anzahl der Abtastwerte pro Sekunde für jeden Kanal. |
| Sitzung | Eine Datei mit den Einstellungen der App und des Geräts. |
| Einstellung | Ein Wert, den Sie in der App ändern können. |
| Stream-Modus | Der Betriebsmodus, in dem das Gerät die Abtastwerte während der Erfassung an den Computer sendet. |
| Schwelle | Die Spannung, die einen Low-Pegel von einem High-Pegel trennt. |
| Zeitlineal | Die Zeitskala über dem Signalbereich. |
| Trigger | Eine Bedingung in den Signalen, die eine Zeit in der Erfassung markiert. |
| Triggerposition | Die Position des Triggerpunkts in der Erfassung als Prozentsatz der Abtastdauer. |
| Signalverlauf | Die Linie, die das Signal eines Kanals zeigt. |
| Signalbereich | Der Teil des Fensters, der die Signalverläufe zeigt. |

## Fachverben

| Verb | Definition |
| --- | --- |
| erfassen | Die Signale mit dem Gerät aufzeichnen. |
| klicken | Eine Maustaste drücken und loslassen. |
| dekodieren | Daten lesen und die Frames eines Protokolls finden. |
| doppelklicken | Zweimal schnell klicken. |
| ziehen | Ein Element mit gedrückter Maustaste bewegen. |
| exportieren | Daten in einem Format für ein anderes Programm speichern. |
| drücken | Eine Taste auf der Tastatur betätigen. |
| abtasten | Den Wert eines Signals zu einer Zeit lesen. |
| eingeben | Text mit der Tastatur schreiben. |
| vergrößern, verkleinern | Einen kürzeren oder längeren Teil des Signalverlaufs zeigen. |
