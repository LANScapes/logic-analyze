# Тригери

Тригер — це умова в сигналах. Коли умова виконується, пристрій позначає цей момент як точку тригера. Тригер дозволяє захопити ту частину сигналу, яку ви хочете дослідити.

У застосунку є два типи тригера:

- **Простий тригер**: Перепад або рівень на одному чи кількох каналах.
- **Розширений тригер**: Послідовність умов або значення на послідовній шині.

Щоб відкрити панель тригера, клацніть **Тригер** на панелі інструментів або натисніть `T`.

> [!NOTE]
> Якщо сигнал не відповідає умові тригера, захоплення продовжує чекати. Щоб побачити сигнал без тригера, клацніть **Одразу**. Щоб припинити очікування, клацніть **Стоп**.

## Позиція тригера

Налаштування **Позиція тригера** задає місце точки тригера в захопленні. Значення — це відсоток від тривалості захоплення.

- Мале значення, наприклад 10%, показує більше сигналу після тригера.
- Велике значення, наприклад 90%, показує більше сигналу до тригера.

Позиція тригера використовує пам'ять пристрою. Тому її можна задати лише в буферному режимі. У потоковому режимі позиція тригера завжди близько 1%.

## Простий тригер

Кожна мітка каналу в області осцилограм має п'ять кнопок тригера. Зліва направо це такі кнопки:

1. Фронт
2. Високий рівень
3. Спад
4. Низький рівень
5. Фронт або спад

![Кнопки тригера на мітці каналу](../figures/simple-trigger-buttons.png)

Щоб задати простий тригер, виконайте такі кроки:

1. Відкрийте панель тригера.
2. Виберіть **Простий тригер**.
3. На мітці каналу клацніть потрібну кнопку тригера. Кнопка змінює колір.
4. Щоб видалити тригер з каналу, клацніть ту саму кнопку ще раз.
5. Задайте **Позиція тригера**.

Якщо ви задаєте тригер на кількох каналах, усі умови мають виконуватися на тому самому відліку (логічне І).

## Розширений тригер

> [!NOTE]
> Розширений тригер доступний лише в буферному режимі. Щоб використовувати його, задайте для **Режим роботи** значення **Буферний режим**. Див. [Параметри пристрою](05-device-options.md).

Щоб використовувати розширений тригер, виберіть **Розширений тригер** на панелі тригера. Потім виберіть вкладку **Багаторівневий тригер** або вкладку **Послідовний тригер**.

### Значення для кожного каналу

Багаторівневий тригер і послідовний тригер використовують рядок із 16 символів. Кожен символ — це умова для одного каналу. Правий символ — це канал 0. Лівий символ — це канал 15.

| Символ | Умова |
| --- | --- |
| `X` | Будь-яке значення (канал не впливає). |
| `0` | Низький рівень. |
| `1` | Високий рівень. |
| `R` | Фронт. |
| `F` | Спад. |
| `C` | Фронт або спад. |

### Багаторівневий тригер

Багаторівневий тригер — це послідовність умов. Кожна умова — це ступінь. Пристрій спочатку перевіряє ступінь 0. Коли умова ступеня виконується, пристрій переходить до наступного ступеня. Тригер спрацьовує, коли останній ступінь завершено. Можна використовувати до 16 ступенів.

Кожен ступінь має такі налаштування:

- Два рядки умов каналів.
- Для кожного рядка `==` або `!=`. При `==` умова виконується, коли канали відповідають рядку. При `!=` умова виконується, коли канали не відповідають рядку.
- **І** або **АБО**. Це налаштування поєднує два рядки.
- **Лічильник**: Скільки разів умова має виконатися, щоб ступінь було завершено.
- **Поспіль**: Якщо встановити цей прапорець, умова має виконуватися у відліках, які йдуть один за одним без перерви.

Щоб задати багаторівневий тригер, виконайте такі кроки:

1. У полі **Кількість рівнів тригера** виберіть кількість ступенів.
2. У списку ступенів праворуч клацніть ступінь 0.
3. Введіть умови каналів у першому рядку.
4. Якщо потрібно, введіть умови каналів у другому рядку й виберіть **І** або **АБО**.
5. Введіть значення в поле **Лічильник**.
6. Повторіть кроки 2–5 для кожного іншого ступеня.

Ось три приклади.

**Приклад 1.** Тригер, коли канал 0 перебуває у високому рівні понад 1000 відліків:

1. Задайте для **Кількість рівнів тригера** значення 1.
2. На ступені 0 введіть `1` для каналу 0 у першому рядку.
3. Виберіть **Поспіль**.
4. Задайте для **Лічильник** значення 1000.

![Приклад 1](../figures/stage-example-level-count.png)

**Приклад 2.** Тригер за фронтом на каналі 0 або за спадом на каналі 1:

1. Задайте для **Кількість рівнів тригера** значення 1.
2. На ступені 0 введіть `R` для каналу 0 у першому рядку.
3. Введіть `F` для каналу 1 у другому рядку.
4. Виберіть **АБО**.

![Приклад 2](../figures/stage-example-or.png)

**Приклад 3.** Тригер за фронтом на каналі 0, потім за 100 спадами на каналі 1, потім за високим рівнем на каналі 2:

1. Задайте для **Кількість рівнів тригера** значення 3.
2. На ступені 0 введіть `R` для каналу 0.
3. На ступені 1 введіть `F` для каналу 1. Задайте для **Лічильник** значення 100.
4. На ступені 2 введіть `1` для каналу 2.

### Послідовний тригер

Послідовний тригер знаходить значення даних на послідовній шині. Він працює як регістр зсуву. Ось його налаштування:

- **Ознака старту**: Умова, яка запускає послідовний тригер.
- **Ознака стопу**: Умова, яка очищає регістр зсуву.
- **Ознака такту**: Умова, яка додає один біт у регістр зсуву.
- **Канал даних**: Канал, який передає дані.
- **Біти даних**: Кількість бітів у значенні.
- **Значення даних**: Значення, яке спричиняє тригер.

Після ознаки старту пристрій читає канал даних на кожній ознаці такту. Пристрій зсуває цей біт у регістр зсуву. Коли останні біти регістра зсуву дорівнюють **Значення даних**, тригер спрацьовує. Коли з'являється ознака стопу, пристрій очищає регістр зсуву.

**Приклад 4.** Тригер, коли на шині I2C з'являється значення `010000100`. Канал 0 — це SCL, канал 1 — це SDA.

1. Задайте для **Ознака старту** спад на SDA при високому рівні SCL: `F1` у двох правих символах.
2. Задайте для **Ознака стопу** фронт на SDA при високому рівні SCL: `R1`.
3. Задайте для **Ознака такту** фронт на SCL: `R` для каналу 0.
4. Задайте для **Канал даних** значення 1.
5. Задайте для **Біти даних** значення 9.
6. Введіть `010000100` у поле **Значення даних**.

![Приклад 4](../figures/serial-example-i2c.png)

**Приклад 5.** Тригер, коли на лінії MOSI шини SPI з'являється значення `0x1234`. Канал 0 — це CS#, канал 1 — це CLK, канал 2 — це MISO, канал 3 — це MOSI.

1. Задайте для **Ознака старту** спад на CS#: `F` для каналу 0.
2. Задайте для **Ознака стопу** фронт на CS#: `R` для каналу 0.
3. Задайте для **Ознака такту** фронт на CLK: `R` для каналу 1.
4. Задайте для **Канал даних** значення 3.
5. Задайте для **Біти даних** значення 16.
6. Введіть `0001001000110100` у поле **Значення даних**.

![Приклад 5](../figures/serial-example-spi.png)

Щоб ввести значення в шістнадцятковому вигляді, виберіть **Введення в шістнадцятковому форматі**. Потім введіть значення в поле **Шістн.**.
