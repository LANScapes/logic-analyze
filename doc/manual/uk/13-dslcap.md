# Інструмент dslcap

Інструмент `dslcap` захоплює дані з пристрою DSLogic без головного вікна. Використовуйте його в скриптах і в автоматичних тестах. Інструмент записує відліки у двійковий файл. Він виводить один об'єкт JSON із результатом у стандартний вивід.

Інструмент розміщено в пакеті застосунку:

```sh
"/Applications/Logic Analyze.app/Contents/MacOS/dslcap"
```

> [!NOTE]
> Пристрій може використовувати лише одна програма одночасно. Закрийте Logic Analyze перед використанням `dslcap`.

## Виведіть список пристроїв

Щоб вивести список пристроїв, які може знайти бібліотека, введіть цю команду:

```sh
dslcap --list
```

Щоб вивести ідентифікатор USB кожного підключеного пристрою DSLogic, введіть цю команду:

```sh
dslcap --list-ids
```

Команда `--list-ids` читає лише інформацію, яку macOS зберігає про пристрої USB. Вона не передає дані в пристрій. Вивід містить модель, розташування USB та ідентифікатор реєстру для кожного пристрою.

## Захопіть дані

Ця команда захоплює 1000000 відліків на каналах 0 і 1 із частотою 10 MHz:

```sh
dslcap --channels 0,1 --samplerate 10000000 --samples 1000000 --out /tmp/capture
```

Інструмент записує відліки в `/tmp/capture.bin`. Якщо файл із цим ім'ям уже є, інструмент зупиняється з помилкою. Інструмент не замінює файли.

Ось параметри захоплення:

| Параметр | Функція | Початкове значення |
| --- | --- | --- |
| `--channels LIST` | Канали для запису, наприклад `0,1,2`. | `0` |
| `--samplerate HZ` | Частота дискретизації в Hz. | `10000000` |
| `--samples N` | Кількість відліків для кожного каналу. | `1000000` |
| `--vth VOLTS` | Порогова напруга. | `1.6` |
| `--mode MODE` | `buffer` або `stream`. | `buffer` |
| `--trigger CH[:T]` | Тригер на каналі CH. Для T використовуйте `R` (фронт), `F` (спад), `C` (фронт або спад), `1` (високий рівень) або `0` (низький рівень). | Без тригера. `R`, якщо вказано лише CH. |
| `--trigpos PERCENT` | Позиція тригера у відсотках від кількості відліків. | `10` |
| `--timeout SEC` | Максимальний час захоплення в секундах. | `30` |
| `--out PATH` | Шлях до вихідного файлу без розширення `.bin`. | Цей параметр обов'язковий. |
| `--log-level N` | Кількість повідомлень бібліотеки в стандартному виводі помилок, від 0 (немає) до 5 (усі). | `1` |

Інструмент перевіряє всі параметри до використання пристрою. Якщо параметр неправильний, інструмент зупиняється й видає помилку.

## Вихідний файл

Файл `.bin` містить канали в порядку їхніх номерів, починаючи з найменшого номера. Для кожного каналу файл містить усі відліки цього каналу. Кожен байт містить 8 відліків. Перший відлік — це молодший біт. Дані кожного каналу займають цілу кількість блоків по 8 байтів. Тому кожен канал займає `ceil(samples / 64) × 8` байтів.

## Результат JSON

Інструмент виводить один об'єкт JSON в одному рядку. Після правильного захоплення об'єкт містить ім'я пристрою, частоту дискретизації, кількість відліків і канали. Він також містить порогову напругу, режим, тригер, час захоплення та шлях до файлу `.bin`. Якщо захоплення неправильне, об'єкт містить ключ `error`. У цьому разі інструмент не створює файл `.bin`.

Використовуйте результат лише тоді, коли код виходу дорівнює 0 і об'єкт JSON повний.

## Код виходу

| Код | Значення |
| --- | --- |
| 0 | Захоплення завершено. |
| 1 | Під час роботи сталася помилка, наприклад помилка введення-виведення. |
| 2 | Параметр неправильний або налаштування недоступне на пристрої. |
| 3 | Захоплення не завершено. |

## Параметри для програм, які запускають dslcap

- `--parent-fd N`: Інструмент зупиняється, коли програма, яка його запустила, закриває канал (pipe) із дескриптором N. Потім інструмент видаляє свій вихідний файл, якщо захоплення не завершено.
- `--res DIR`: Папка з файлами мікропрограми. Зазвичай інструмент знаходить цю папку автоматично. Ви також можете задати змінну середовища `DSLCAP_RES`.
- `--res-manifest FD`: Інструмент перевіряє значення SHA-256 кожного файлу мікропрограми до передачі файлу в пристрій.

Файл `tools/dslcap/README.md` у вихідному коді містить усю інформацію про ці параметри.
