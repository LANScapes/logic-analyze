# Технічні терміни та дієслова

Кожен із цих технічних термінів має в цьому посібнику лише одне значення. Кожна мовна версія цього посібника використовує лише одне слово для кожного технічного терміна.

## Технічні терміни

| Термін | Визначення |
| --- | --- |
| застосунок | Програма Logic Analyze. |
| буферний режим | Режим роботи, у якому пристрій зберігає відліки у своїй пам'яті до кінця захоплення. |
| захоплення | Один запис сигналів від пуску до зупинки. |
| канал | Один вхід пристрою та рядок, який показує його дані. |
| режим каналів | Налаштування, яке вибирає кількість каналів і максимальну частоту дискретизації. |
| курсор | Вертикальна лінія в момент часу в захопленні. Курсори використовують для вимірювань. |
| декодер | Частина застосунку, яка читає дані й знаходить кадри протоколу. |
| демопристрій | Пристрій у застосунку, який створює тестові сигнали. Він не має апаратної частини. |
| пристрій | Логічний аналізатор DSLogic або осцилограф DSCope. |
| бічна панель | Панель збоку від області осцилограм. |
| перепад | Перехід від низького рівня до високого (фронт) або від високого рівня до низького (спад). |
| земля | Точка 0 V кола. |
| рівень | Стан цифрового сигналу: високий або низький. |
| щуп | Дріт або затискач, який з'єднує канал із колом. |
| протокол | Специфікація даних на шині, наприклад UART, I2C або SPI. |
| імпульс | Рівень між двома перепадами. |
| відлік | Значення каналу в один момент часу. |
| тривалість захоплення | Час одного захоплення. |
| частота дискретизації | Кількість відліків за секунду для кожного каналу. |
| сеанс | Файл із налаштуваннями застосунку та пристрою. |
| налаштування | Значення, яке можна змінити в застосунку. |
| потоковий режим | Режим роботи, у якому пристрій передає відліки в комп'ютер під час захоплення. |
| поріг | Напруга, яка розділяє низький і високий рівень. |
| шкала часу | Шкала часу над областю осцилограм. |
| тригер | Умова в сигналах, яка позначає момент часу в захопленні. |
| позиція тригера | Положення точки тригера в захопленні у відсотках від тривалості захоплення. |
| осцилограма | Лінія, яка показує сигнал каналу. |
| область осцилограм | Частина вікна, яка показує осцилограми. |

## Технічні дієслова

| Дієслово | Визначення |
| --- | --- |
| захопити | Записати сигнали за допомогою пристрою. |
| клацнути | Натиснути й відпустити кнопку миші. |
| декодувати | Прочитати дані й знайти кадри протоколу. |
| двічі клацнути | Швидко клацнути два рази. |
| перетягнути | Перемістити елемент з натиснутою кнопкою миші. |
| експортувати | Зберегти дані у форматі для іншої програми. |
| натиснути | Натиснути клавішу на клавіатурі. |
| зробити відлік | Прочитати значення сигналу в один момент часу. |
| ввести | Написати текст із клавіатури. |
| збільшити масштаб, зменшити масштаб | Показати коротшу або довшу частину осцилограми. |
