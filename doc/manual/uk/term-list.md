# Список термінів: англійська › українська

Використовуйте в українському посібнику лише ці переклади. Написи інтерфейсу **жирним шрифтом** — це точні тексти з файлів `lang/uk/*.json` перекладу застосунку (без символів `&`). Напис без перекладу в цих файлах залишається англійською. Процедури використовують ввічливу форму наказового способу: «Клацніть», «Виберіть», «Натисніть».

Примітка: інтерфейс називає ступені тригера «рівнями» (**Кількість рівнів тригера**). У тексті посібника ступінь тригера — це «ступінь», щоб не плутати його з рівнем сигналу.
