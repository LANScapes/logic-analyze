# Installare e avviare l'applicazione

## Installare l'applicazione

1. Andare alla pagina delle versioni del progetto: <https://github.com/LANScapes/logic-analyze/releases>.
2. Scaricare il file ZIP della versione più recente.
3. Aprire il file ZIP nel Finder. Il Finder estrae **Logic Analyze.app**.
4. Trascinare **Logic Analyze.app** nella cartella **Applicazioni**.

L'applicazione contiene tutte le librerie, il firmware e i decodificatori di protocollo necessari. Su macOS non è necessario installare un driver.

## Avviare l'applicazione

1. Collegare l'analizzatore logico al computer. Vedere [Collegare il DSLogic Plus](04-connect.md).
2. Aprire **Logic Analyze** dalla cartella **Applicazioni** o dal Launchpad.
3. Se macOS mostra un messaggio sull'applicazione, fare clic su **Apri**.

Al primo avvio, l'applicazione può mostrare la finestra **Documento**. Fare clic su **Apri** per leggere questo manuale. Fare clic su **Ignora** per chiudere la finestra. Fare clic su **Non mostrare più** per non vedere più questa finestra.

## Aggiornare l'applicazione

1. Fare clic su **Aiuto** › **Aggiorna**. L'applicazione apre la pagina delle versioni nel browser web.
2. Se la pagina delle versioni mostra una versione più recente, scaricarla.
3. Uscire da Logic Analyze.
4. Sostituire **Logic Analyze.app** nella cartella **Applicazioni** con la nuova versione.

L'applicazione conserva le impostazioni quando la si sostituisce.

## Aprire questo manuale

Fare clic su **Aiuto** › **Manuale...**. L'applicazione apre questo manuale nella lingua dell'interfaccia utente. Se il manuale non è disponibile in quella lingua, l'applicazione apre il manuale in inglese.

## Cambiare la lingua

1. Fare clic su **Aiuto** › **Lingua**.
2. Selezionare una lingua dall'elenco.

L'interfaccia utente passa alla lingua selezionata.

## Cambiare il tema

1. Fare clic su **Opzioni** › **Display** › **Temi**.
2. Selezionare **Scuro** o **Chiaro**.

## Spostare la barra degli strumenti

È possibile posizionare la barra degli strumenti in alto, in basso, a sinistra o a destra della finestra. Con la barra degli strumenti a sinistra o a destra, 16 canali possono usare tutta l'altezza della finestra.

1. Posizionare il puntatore sulla maniglia all'inizio della barra degli strumenti.
2. Tenere premuto il pulsante del mouse.
3. Trascinare la barra degli strumenti verso un bordo della finestra.
4. Rilasciare il pulsante del mouse.

L'applicazione conserva la posizione della barra degli strumenti al successivo avvio.

## Opzioni di visualizzazione

Per cambiare le opzioni di visualizzazione, fare clic su **Opzioni** › **Display** › **Opzioni**. La finestra **Opzioni di visualizzazione** mostra queste impostazioni:

| Impostazione | Funzione |
| --- | --- |
| **Scorrimento forma d'onda trascinando con il mouse** | Quando si trascina rapidamente la forma d'onda e la si rilascia, la forma d'onda continua a muoversi. Poi rallenta e si ferma. |
| **Aggiorna gli ultimi dati all'arresto in modalità ripetuta** | Quando si arresta un'acquisizione in modalità **Ripetuta**, l'applicazione mostra i dati dell'ultima acquisizione, che non è completa. |
| **Scorrimento automatico agli ultimi dati** | In modalità streaming, la forma d'onda si sposta per mostrare i dati più recenti. |
| **Mostra la posizione del trigger al centro** | In modalità oscilloscopio, l'applicazione mostra la posizione del trigger al centro della finestra. |
| **Mostra la sessione nella barra del titolo** | La barra del titolo mostra il nome del file di sessione. |
| **Dimensione carattere** | La dimensione del testo nell'area delle forme d'onda. |

## Opzioni log

L'applicazione può registrare un file di log. Il file di log aiuta a trovare la causa di un problema.

1. Fare clic su **Aiuto** › **Opzioni log**.
2. Selezionare un valore da 0 a 5 in **Livello di log**. Un valore più alto registra più messaggi.
3. Selezionare **Salva su file**.
4. Per aggiungere i nuovi messaggi alla fine del file di log esistente, selezionare **Modalità di accodamento**.
5. Fare clic su **OK**.

Per vedere il file di log, fare clic su **Apri** nella finestra **Opzioni log**. Per cancellare il file di log, fare clic su **Cancella**.

## Segnalare un problema

Fare clic su **Aiuto** › **Segnala bug**. L'applicazione apre la pagina delle segnalazioni del progetto nel browser web. Indicare nella segnalazione la versione dell'applicazione, la versione di macOS e il modello del dispositivo. Se possibile, allegare il file di log.
