# Elenco dei termini (italiano)

Termini fissi della traduzione italiana del manuale. Ogni termine inglese ha una sola traduzione.

| English | Italiano |
| --- | --- |
| app | applicazione |
| buffer mode | modalità buffer |
| capture (n) | acquisizione |
| capture (v) | acquisire |
| channel | canale |
| channel mode | modalità canali |
| click | fare clic su |
| cursor | cursore |
| decode | decodificare |
| decoder | decodificatore |
| demo device | dispositivo demo |
| device | dispositivo |
| dock | pannello |
| double-click | fare doppio clic |
| drag | trascinare |
| edge | fronte |
| export | esportare |
| falling edge | fronte di discesa |

| ground | massa |
| level | livello |
| press | premere |

| protocol | protocollo |
| pulse | impulso |
| rising edge | fronte di salita |
| sample (n) | campione |
| sample (v) | campionare |
| sample duration | durata di campionamento |
| sample rate | frequenza di campionamento |
| select | selezionare |
| session | sessione |
| setting | impostazione |
| stream mode | modalità streaming |
| threshold | soglia |
| time ruler | righello del tempo |
| toolbar | barra degli strumenti |

| trigger position | posizione del trigger |
| type | digitare |
| waveform | forma d'onda |
| waveform area | area delle forme d'onda |
| zoom in, zoom out | ingrandire, ridurre |
| WARNING / CAUTION / NOTE | AVVERTENZA / ATTENZIONE / NOTA |

Istruzioni: infinito ("Fare clic su", "Selezionare", "Premere").

Etichette dell'interfaccia in grassetto: testo esatto di lang/it/*.json della traduzione dell'applicazione (ramo i18n/app-translations), senza gli acceleratori "&" e senza i due punti finali. Etichette lasciate in inglese perché non hanno traduzione: **OK**, **USB 2.0**, **USB 3.0**, **CK**, **TI**, **TO**, **SCL**, **SDA**, **1X**, **x1**, **x10**, **+**, **×**. La cartella di macOS **Applications** è scritta **Applicazioni**, come la mostra il Finder in italiano.
