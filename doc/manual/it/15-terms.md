# Termini tecnici e verbi

Ognuno di questi termini tecnici ha un solo significato in questo manuale. Ogni versione linguistica di questo manuale usa un solo termine per ogni termine tecnico.

## Termini tecnici

| Termine | Definizione |
| --- | --- |
| applicazione | Il programma Logic Analyze. |
| modalità buffer | La modalità operativa in cui il dispositivo conserva i campioni nella sua memoria fino alla fine dell'acquisizione. |
| acquisizione | Una registrazione dei segnali, dall'avvio all'arresto. |
| canale | Un ingresso del dispositivo, e la riga che mostra i suoi dati. |
| modalità canali | L'impostazione che seleziona il numero di canali e la frequenza di campionamento massima. |
| cursore | Una linea verticale in un istante dell'acquisizione. I cursori servono per le misure. |
| decodificatore | Una parte dell'applicazione che legge i dati e trova i frame di un protocollo. |
| dispositivo demo | Un dispositivo dell'applicazione che genera segnali di prova. Non ha hardware. |
| dispositivo | L'analizzatore logico DSLogic o l'oscilloscopio DSCope. |
| pannello | Una zona a lato dell'area delle forme d'onda. |
| fronte | Un passaggio da un livello basso a un livello alto (fronte di salita) o da un livello alto a un livello basso (fronte di discesa). |
| massa | Il punto a 0 V di un circuito. |
| livello | Lo stato di un segnale digitale: alto o basso. |
| sonda | Il filo o il morsetto che collega un canale al circuito. |
| protocollo | La specifica dei dati su un bus, per esempio UART, I2C o SPI. |
| impulso | Un livello tra due fronti. |
| campione | Il valore di un canale in un istante. |
| durata di campionamento | La durata di un'acquisizione. |
| frequenza di campionamento | Il numero di campioni al secondo, per ogni canale. |
| sessione | Un file con le impostazioni dell'applicazione e del dispositivo. |
| impostazione | Un valore che è possibile cambiare nell'applicazione. |
| modalità streaming | La modalità operativa in cui il dispositivo invia i campioni al computer durante l'acquisizione. |
| soglia | La tensione che separa un livello basso da un livello alto. |
| righello del tempo | La scala del tempo sopra l'area delle forme d'onda. |
| trigger | Una condizione nei segnali che segna un istante nell'acquisizione. |
| posizione del trigger | La posizione del punto di trigger nell'acquisizione, come percentuale della durata di campionamento. |
| forma d'onda | La linea che mostra il segnale di un canale. |
| area delle forme d'onda | La parte della finestra che mostra le forme d'onda. |

## Verbi tecnici

| Verbo | Definizione |
| --- | --- |
| acquisire | Registrare i segnali con il dispositivo. |
| fare clic | Premere e rilasciare un pulsante del mouse. |
| decodificare | Leggere i dati e trovare i frame di un protocollo. |
| fare doppio clic | Fare clic due volte rapidamente. |
| trascinare | Spostare un elemento tenendo premuto il pulsante del mouse. |
| esportare | Salvare i dati in un formato per un altro programma. |
| premere | Premere un tasto della tastiera. |
| campionare | Leggere il valore di un segnale in un istante. |
| digitare | Scrivere testo con la tastiera. |
| ingrandire, ridurre | Mostrare una parte più corta o più lunga della forma d'onda. |
