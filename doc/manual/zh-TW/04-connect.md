# 連接 DSLogic Plus

## 連接 USB 纜線

> [!NOTE]
> 使用裝置隨附的 USB 纜線，或使用品質良好的短 USB 纜線。把纜線直接連接到電腦上的連接埠。USB 集線器或長纜線可能造成擷取錯誤。

1. 把 USB 纜線連接到 DSLogic Plus。
2. 把 USB 纜線的另一端連接到電腦上的 USB 連接埠。
3. 確認 DSLogic Plus 上的指示燈亮起。應用程式啟動之前，指示燈為紅色。
4. 啟動 Logic Analyze。
5. 確認指示燈變為綠色。
6. 確認工具列上的裝置清單顯示 **DSLogic Plus**。

![USB 連線](../figures/usb-connection.png)

如果裝置清單不顯示該裝置，執行以下步驟：

1. 從電腦拔除 USB 纜線。
2. 等待 5 秒。
3. 把 USB 纜線連接到另一個 USB 連接埠。
4. 如果執行步驟 3 後裝置清單仍不顯示該裝置，結束應用程式並重新啟動。

> [!NOTE]
> 同一時間只有一個程式可以使用裝置。如果 `dslcap` 或其他程式正在使用裝置，應用程式找不到該裝置。

## 連接探棒纜線

探棒纜線有 16 條通道線。每條通道線有遮蔽層、訊號端和接地端。線的顏色標示通道 0 到 15。另外一條線有以下訊號：

- **CK**：外部時脈輸入。只在使用 **使用外部時脈** 設定時使用。
- **TI**：外部觸發訊號輸入。
- **TO**：觸發訊號輸出。觸發發生時，裝置在 TO 上送出一個脈衝。

通常不連接 CK、TI 和 TO 線。

![探棒纜線及其通道](../figures/probe-cable-channels.png)

1. 把探棒纜線連接到 DSLogic Plus 的輸入連接器。
2. 把連接器完全推入裝置。

## 把通道連接到電路

> [!WARNING]
> 不要把探棒連接到市電電壓。不要把探棒連接到與市電電壓有電氣連接的電路。此電壓可能造成受傷或死亡。

> [!CAUTION]
> 連接接地線之前，確認電路的接地和電腦的接地電壓相同。電壓差可能產生大電流，損壞設備。

1. 切斷被測電路的電源。
2. 至少把一條接地線連接到電路的接地。
3. 把您使用的每條通道線連接到電路中的一個訊號。
4. 確認沒有探棒接觸其他接點。
5. 接通電路的電源。

![接地連線：一個共用接地（左）或每個通道一個接地（右）](../figures/probe-grounding.png)

對於頻率低於 5 MHz 的訊號，所有通道使用一條接地線就足夠。對於頻率更高的訊號，把每條通道線的接地端連接到該訊號附近的接地。短的接地連線使訊號邊緣清楚。

## 中斷 DSLogic Plus 的連線

> [!CAUTION]
> 擷取期間不要拔除 USB 纜線。如果拔除，擷取的資料可能出錯。

1. 停止擷取。如果工具列上顯示 **停止**，按一下它。
2. 切斷電路的電源。
3. 從電路移除探棒。
4. 拔除 USB 纜線。
