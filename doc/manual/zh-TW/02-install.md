# 安裝和啟動應用程式

## 安裝應用程式

<!-- edition: download -->
1. 前往專案的發行頁面：<https://github.com/LANScapes/logic-analyze/releases>。
2. 下載最新發行版本的 ZIP 檔案。
3. 在 Finder 中開啟 ZIP 檔案。Finder 解壓縮出 **Logic Analyze.app**。
4. 把 **Logic Analyze.app** 拖曳到 **應用程式** 資料夾。
<!-- end edition -->
<!-- edition: appstore -->
1. 在 Mac 上開啟 App Store。
2. 在 App Store 中找到 Logic Analyze。
3. 安裝應用程式。App Store 把 **Logic Analyze.app** 放到 **應用程式** 資料夾。
<!-- end edition -->

此應用程式包含所有必要的程式庫、韌體和協定解碼器。在 macOS 上不需要安裝驅動程式。

## 啟動應用程式

1. 把邏輯分析儀連接到電腦。請參閱[連接 DSLogic Plus](04-connect.md)。
2. 從 **應用程式** 資料夾或從啟動台開啟 **Logic Analyze**。
3. 如果 macOS 顯示關於此應用程式的訊息，按一下 **開啟**。

應用程式第一次啟動時，可能顯示 **文件** 視窗。按一下 **開啟** 閱讀本手冊。按一下 **忽略** 關閉此視窗。如果您不想再看到此視窗，按一下 **不再顯示**。

## 更新應用程式

<!-- edition: download -->
1. 按一下 **說明** › **更新**。應用程式在您的網頁瀏覽器中開啟發行頁面。
2. 如果發行頁面顯示較新的版本，下載該版本。
3. 結束 Logic Analyze。
4. 用新版本取代 **應用程式** 資料夾中的 **Logic Analyze.app**。

取代應用程式後，應用程式保留您的設定。
<!-- end edition -->
<!-- edition: appstore -->
App Store 會更新應用程式。若要立即尋找更新，請執行以下步驟：

1. 在 Mac 上開啟 App Store。
2. 開啟更新列表。
3. 如果列表中有 Logic Analyze，更新它。

應用程式更新後，應用程式保留您的設定。
<!-- end edition -->

## 開啟本手冊

按一下 **說明** › **手冊...**。應用程式以使用者介面的語言開啟本手冊。如果沒有該語言的手冊，應用程式開啟英文手冊。

## 變更語言

1. 按一下 **說明** › **語言**。
2. 從清單中選取一種語言。

使用者介面變更為您選取的語言。

## 變更主題

1. 按一下 **選項** › **顯示** › **主題**。
2. 選取 **深色** 或 **淺色**。

## 移動工具列

您可以把工具列放在視窗的頂部、底部、左側或右側。工具列在左側或右側時，16 個通道可以使用視窗的全部高度。

1. 把指標放在工具列起始處的拖曳把手上。
2. 按住滑鼠按鈕。
3. 把工具列拖曳到視窗的一個邊緣。
4. 放開滑鼠按鈕。

再次啟動時，應用程式保留工具列的位置。

## 顯示選項

要變更顯示選項，按一下 **選項** › **顯示** › **選項**。**顯示選項** 視窗顯示以下設定：

| 設定 | 功能 |
| --- | --- |
| **以滑鼠拖曳捲動波形** | 快速拖曳波形並放開後，波形繼續移動。然後波形移動變慢並停止。 |
| **重複模式停止時更新最新資料** | 在 **重複** 模式下停止擷取時，應用程式顯示最後一次擷取的資料。這次擷取不完整。 |
| **自動捲動至最新資料** | 在串流模式下，波形移動以顯示最新的資料。 |
| **觸發位置置中顯示** | 在示波器模式下，應用程式在視窗中間顯示觸發位置。 |
| **在標題列顯示設定檔名稱** | 標題列顯示工作階段檔案的名稱。 |
| **字型大小** | 波形區中文字的大小。 |

## 記錄選項

應用程式可以記錄記錄檔。記錄檔有助於找出問題的原因。

1. 按一下 **說明** › **記錄選項**。
2. 在 **記錄層級** 中選取 0 到 5 之間的值。值越大，記錄的訊息越多。
3. 選取 **儲存至檔案**。
4. 要把新訊息加到現有記錄檔的結尾，選取 **附加模式**。
5. 按一下 **確定**。

要檢視記錄檔，在 **記錄選項** 視窗中按一下 **開啟**。要清除記錄檔，按一下 **清除**。

## 回報問題

按一下 **說明** › **回報問題**。應用程式在您的網頁瀏覽器中開啟專案的問題頁面。在回報中寫明應用程式版本、macOS 版本和裝置型號。如果可以，附上記錄檔。
