# 簡介

## 關於 Logic Analyze

Logic Analyze 是一個 macOS 應用程式，用於 DreamSourceLab 的邏輯分析儀。LANScapes 提供此應用程式。此應用程式來自 DSView。DSView 是 DreamSourceLab 的程式。DSView 使用 sigrok 專案的軟體。

此應用程式從 DSLogic 邏輯分析儀記錄數位訊號。然後，應用程式把訊號顯示為波形。您可以量測波形，也可以解碼串列協定。您還可以儲存資料，並把資料匯出為其他格式。

本手冊的範例使用 DSLogic Plus。其他 DSLogic 型號使用相同的步驟。它們的通道數、記憶體和取樣率的上限不同。

此應用程式還包含 `dslcap` 工具。此工具不使用主視窗擷取資料。請參閱 [dslcap 工具](13-dslcap.md)。

## 關於本手冊

本手冊依照 ASD-STE100 簡化技術英語的規則撰寫。每個句子都很短。程序中的每一步只給出一條指示。本手冊中的每個技術名稱只有一個意義。[技術名稱和動詞](15-terms.md)列出這些技術名稱。

本手冊使用以下文字格式：

- **粗體文字**表示應用程式中的標籤，例如按鈕、選單項目或欄位。
- `程式碼文字`表示鍵盤上的按鍵、指令、檔案名稱或您輸入的值。
- 選單路徑使用符號 ›，例如 **檔案** › **儲存...**。
- 有編號的步驟清單是一個程序。依照指定的順序執行這些步驟。

## 安全說明

本手冊使用以下安全標籤：

- **警告** 表示有受傷或死亡的風險。
- **注意** 表示有損壞設備的風險，或有遺失資料的風險。
- **說明** 提供對您有幫助的資訊。**說明** 後面的資訊不是指示。

安全說明位於它適用的步驟之前。開始程序之前，閱讀所有安全說明。

> [!WARNING]
> 不要把探棒連接到市電電壓。不要把探棒連接到與市電電壓有電氣連接的電路。探棒與電腦有電氣連接。此電壓可能造成受傷或死亡。

> [!CAUTION]
> 不要在通道輸入端施加超過裝置規格限值的電壓。電壓過高可能損壞邏輯分析儀。

> [!CAUTION]
> 邏輯分析儀的接地線透過 USB 纜線與電腦的接地相連。只把接地線連接到您量測的電路的接地。如果兩個接地的電壓不同，可能流過大電流，損壞電路、邏輯分析儀和電腦。

## 系統需求

需要以下設備：

- 一台裝有 macOS 的 Mac。版本資訊提供最低 macOS 版本。
- 一個 USB 連接埠。USB 3.0 連接埠速度最高。USB 2.0 連接埠也可以使用。
- 一台 DSLogic 邏輯分析儀、它的 USB 纜線和它的探棒纜線。

沒有邏輯分析儀時，您也可以使用此應用程式。**展示** 裝置產生測試訊號。您也可以開啟以前擷取的資料檔案。
