# 技術名稱和動詞

在本手冊中，以下每個技術名稱只有一個意義。本手冊的每個語言版本對每個技術名稱只使用一個譯名。

## 技術名稱

| 名稱 | 定義 |
| --- | --- |
| 應用程式 | Logic Analyze 程式。 |
| 緩衝模式 | 一種操作模式。在此模式下，裝置把取樣保存在記憶體中，直到擷取結束。 |
| 擷取 | 從開始到停止對訊號的一次記錄。 |
| 通道 | 裝置的一個輸入，以及顯示其資料的列。 |
| 通道模式 | 選取通道數和最高取樣率的設定。 |
| 游標 | 擷取中某一時間處的一條垂直線。游標用於量測。 |
| 解碼器 | 應用程式中讀取資料並找出協定訊框的部分。 |
| 展示裝置 | 應用程式中產生測試訊號的裝置。它沒有硬體。 |
| 裝置 | DSLogic 邏輯分析儀或 DSCope 示波器。 |
| 停駐面板 | 波形區旁邊的面板。 |
| 邊緣 | 從低準位到高準位的變化（上升緣），或從高準位到低準位的變化（下降緣）。 |
| 接地 | 電路的 0 V 點。 |
| 準位 | 數位訊號的狀態：高或低。 |
| 探棒 | 把通道連接到電路的線或夾子。 |
| 協定 | 匯流排上資料的規範，例如 UART、I2C 或 SPI。 |
| 脈衝 | 兩個邊緣之間的準位。 |
| 取樣 | 通道在某一時間的值。 |
| 取樣時長 | 一次擷取的時間長度。 |
| 取樣率 | 每個通道每秒的取樣數。 |
| 工作階段 | 包含應用程式和裝置設定的檔案。 |
| 設定 | 您可以在應用程式中變更的值。 |
| 串流模式 | 一種操作模式。在此模式下，裝置在擷取期間把取樣傳送到電腦。 |
| 臨界值 | 區分低準位和高準位的電壓。 |
| 時間尺規 | 波形區上方的時間刻度。 |
| 觸發 | 訊號中標記擷取中某一時間的條件。 |
| 觸發位置 | 觸發點在擷取中的位置，為取樣時長的百分比。 |
| 波形 | 顯示通道訊號的線。 |
| 波形區 | 視窗中顯示波形的部分。 |

## 技術動詞

| 動詞 | 定義 |
| --- | --- |
| 擷取 | 用裝置記錄訊號。 |
| 按一下 | 按下並放開滑鼠按鈕。 |
| 解碼 | 讀取資料並找出協定的訊框。 |
| 按兩下 | 快速按一下兩次。 |
| 拖曳 | 按住滑鼠按鈕移動一個項目。 |
| 匯出 | 以供其他程式使用的格式儲存資料。 |
| 按 | 按下鍵盤上的按鍵。 |
| 取樣 | 讀取訊號在某一時間的值。 |
| 輸入 | 用鍵盤寫入文字。 |
| 放大、縮小 | 顯示波形較短或較長的部分。 |
