# 擷取資料

開始擷取之前，設定以下項目：

1. 裝置選項。請參閱[裝置選項](05-device-options.md)。
2. 取樣率和取樣時長。請參閱[取樣率和取樣時長](06-sample-rate.md)。
3. 觸發（如有必要）。請參閱[觸發](07-trigger.md)。
4. 擷取模式。請參閱[擷取模式](#capture-modes)。

## 開始擷取

擷取有兩種：

- **開始** 開始一次標準擷取。如果您設定了觸發，裝置等待觸發。
- **立即** 立即開始一次擷取。裝置不使用觸發設定。

要開始標準擷取，按一下 **開始** 或按 `S`。要開始立即擷取，按一下 **立即** 或按 `I`。擷取期間，該按鈕變為 **停止**。按一下 **停止** 停止擷取。

### 緩衝模式下標準擷取的過程

1. 您按一下 **開始**。
2. 應用程式把設定傳送到裝置。
3. 如果沒有觸發，裝置立即開始記錄。如果有觸發，裝置等待觸發。
4. 裝置持續記錄，直到取樣時長結束或記憶體已滿。
5. 裝置把資料傳送到電腦。
6. 應用程式在波形區中顯示波形。

### 串流模式下標準擷取的過程

1. 您按一下 **開始**。
2. 應用程式把設定傳送到裝置。
3. 如果有觸發，裝置等待觸發。在循環模式下，裝置不使用觸發。
4. 擷取期間，裝置把資料傳送到電腦。
5. 擷取期間，應用程式顯示波形。
6. 擷取在取樣時長結束時停止。在循環模式下，擷取持續進行，直到您按一下 **停止**。

## 使用立即擷取

立即擷取與標準擷取相同，但不使用觸發設定。在以下情況使用立即擷取：

- 因為觸發條件沒有發生，標準擷取等待了很長時間。
- 您想檢視此時的訊號。
- 您想在變更觸發之前檢查訊號。

如果沒有訊號，標準擷取在觸發位置等待。狀態顯示 **等待觸發！**。立即擷取立即記錄訊號。

## 擷取模式 {#capture-modes}

要選取擷取模式，按一下工具列上的 **模式**。然後選取以下項目之一：

| 擷取模式 | 緩衝模式 | 串流模式 |
| --- | --- | --- |
| **單次** | 是 | 是 |
| **重複** | 是 | 是 |
| **循環** | 否 | 是 |

### 單次

裝置執行一次擷取。然後擷取停止。

在緩衝模式下，應用程式在擷取之後顯示波形。在串流模式下，應用程式在擷取期間顯示波形。

用此模式擷取一個訊號條件，或擷取此時的波形。

### 重複

裝置執行一次擷取。然後裝置自動開始下一次擷取。這個過程持續進行，直到您按一下 **停止**。

在緩衝模式下，應用程式顯示一個視窗，用於設定兩次擷取之間的間隔。您可以設定 0.1 s 到 10 s 的值。

用此模式檢視多次發生的訊號條件。例如，用它檢視每次電路重設後或每次按下按鈕後的訊號。與觸發一起使用此模式。

### 循環

此模式只在串流模式下可用。擷取持續進行，直到您按一下 **停止**。資料長於取樣時長時，最早的資料從視窗左側移出。最新的資料從右側移入。應用程式捨棄移出的資料。

不知道訊號條件何時發生時，使用此模式。擷取期間觀察波形。看到該條件時，按一下 **停止**。

> [!NOTE]
> 在循環模式下，裝置不使用觸發設定。

## 擷取狀態

擷取期間，波形區顯示狀態：

- **等待觸發！**：裝置等待觸發條件。
- **已觸發！**：觸發已發生。
- **% 已擷取**：擷取已完成的百分比。

擷取之後，波形區底部顯示 **觸發時間**。
