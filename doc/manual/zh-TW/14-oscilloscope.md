# 示波器和資料擷取模式

Logic Analyze 也可以操作 DreamSourceLab 的 DSCope 示波器。DSCope 有兩種裝置模式：

- **示波器**：用於週期固定的訊號和單一訊號條件。
- **資料擷取**：用於長時間的慢速訊號，例如電源電壓或感測器輸出。

DSLogic 裝置沒有這些模式。本章只提供主要程序。

## 連接 DSCope

> [!WARNING]
> 不要把探棒連接到市電電壓。不要把探棒連接到與市電電壓有電氣連接的電路。此電壓可能造成受傷或死亡。

> [!CAUTION]
> 探棒的接地、DSCope 的接地和電腦的接地連接在一起。只把探棒的接地連接到與電腦的接地電壓相同的點。電壓差可能損壞設備。

1. 用 USB 纜線把 DSCope 連接到電腦。
2. 啟動 Logic Analyze。確認裝置清單顯示 DSCope。
3. 把探棒連接到 DSCope 的輸入端。
4. 設定每支探棒上的衰減開關。
5. 把每支探棒的接地夾連接到電路的接地。
6. 把探棒尖端連接到訊號。

## 裝置選項

按一下 **選項** › **裝置選項...** 或按 `O`。

- **操作模式**：**一般** 用於量測。**內部測試** 只用於測試裝置。
- **頻寬限制**：**全頻寬** 或 **20MHz**。20 MHz 限制減少高頻雜訊。

## 校準 DSCope

輸入的增益和偏移隨溫度和濕度變化。校準 DSCope 以保持量測準確。

### 自動校準

> [!CAUTION]
> 校準之前，從輸入端移除所有探棒。校準期間輸入端上的訊號會產生不正確的校準值。

1. 開啟 **裝置選項** 視窗。
2. 按一下 **自動校準**。
3. 移除所有探棒。按一下 **確定**。校準持續幾分鐘。
4. 校準完成後，按一下 **儲存** 保留結果。

要停止校準，按一下 **中止**。然後裝置使用以前的校準值。

### 手動校準

1. 開啟 **裝置選項** 視窗。
2. 按一下 **手動校準**。
3. 按一下工具列上的 **開始**。
4. 要調整偏移，把探棒連接到接地。要調整增益，把探棒連接到已知電壓的訊號。
5. 設定要校準的垂直刻度。
6. 移動該通道的 **偏移** 或 **增益** 滑桿，直到波形正確。
7. 對每個垂直刻度重複步驟 5 和 6。
8. 按一下 **儲存**。

要捨棄變更，按一下 **中止**。要只在中斷裝置連線之前使用這些變更，按一下 **結束**。要回復初始值，按一下 **重設**。重設之後，再次執行自動校準。

## 通道設定

每個通道在波形區左側有以下控制項：

- **啟用**：開啟或關閉通道。
- **垂直刻度**：每格的電壓。視窗有 10 格。要變更刻度，在旋鈕上轉動滑鼠滾輪，或按一下旋鈕的上半部或下半部。您也可以按 `0` 或 `1` 選取一個通道的旋鈕，然後按 `↑` 或 `↓`。
- **耦合**：**DC** 或 **AC**。
- **探棒衰減**：設定 **x1** 或 **x10**，與探棒上的開關一致。
- **自動**：為輸入端上的訊號設定垂直刻度、水平刻度和觸發準位。

要向上或向下移動通道的波形，拖曳通道標籤。

## 水平刻度

在工具列上的清單中選取每格的時間。您也可以在波形區中轉動滑鼠滾輪。

## 開始和停止

- 按一下 **開始** 或按 `S` 開始連續擷取。按一下 **停止** 停止擷取。
- 按一下 **單次** 或按 `I` 擷取一個波形後停止。

## 觸發

按一下 **觸發** 或按 `T` 開啟觸發停駐面板。停駐面板有以下設定：

- **觸發位置**：觸發點在擷取中的位置，為百分比。
- **抑制時間**：觸發後裝置忽略新觸發的時間。用它從脈衝群得到穩定的波形。
- **觸發靈敏度**：觸發所需的電壓變化。值越大，忽略的雜訊越多。
- **觸發源**：**自動**、**通道 0**、**通道 1**、**通道 0 && 1** 或 **通道 0 | 1**。
- **觸發類型**：**上升緣** 或 **下降緣**。

要設定觸發準位，按一下該通道的觸發準位標籤。移動滑鼠。再按一下以設定準位。

## 量測

### 自動量測

波形區底部有 10 個自動量測方框。

1. 按一下一個量測方框。
2. 選取通道。
3. 選取量測項目。要清除該方框，按一下 **重設**。

下次啟動時，應用程式保留這些設定。

### 游標

- 要新增時間游標，按一下時間尺規。您也可以在波形區中按一下滑鼠右鍵，然後選取 **新增 Y 游標**。
- 要新增電壓游標，在波形區中按一下滑鼠右鍵，然後選取 **新增 X 游標**。每個電壓游標有兩條水平線。兩條線之間的標籤顯示電壓差。
- 要量測兩個游標之間的時間，使用量測停駐面板中的 **游標距離** 群組。

### 用指標量測

停止擷取後，把指標放在波形上。應用程式顯示指標處取樣的電壓。

要量測時間，在波形的空白區域按兩下。在第二個點按一下。在第三個點按一下，檢視頻率、週期和工作週期。按一下滑鼠右鍵取消。

## 頻譜（FFT）

1. 按一下 **函數** › **FFT**。
2. 選取 **啟用 FFT**。
3. 設定 **FFT 長度**、**取樣間隔**、**FFT 來源** 和 **FFT 視窗函數**。
4. 設定 **Y 軸模式** 和 **dBV 範圍**。
5. 按一下 **確定**。

頻譜顯示在波形下方。在頻譜中轉動滑鼠滾輪可縮放頻率刻度。拖曳頻譜可移動它。把指標放在頻譜上，檢視頻率和振幅。

## 數學通道

1. 按一下 **函數** › **數學**。
2. 選取 **啟用**。
3. 選取 **運算類型**：**加**、**減**、**乘** 或 **除**。
4. 選取 **第一來源** 和 **第二來源**。
5. 按一下 **確定**。

## 李沙育圖

1. 按一下 **選項** › **顯示** › **李沙育圖**。
2. 選取 **啟用**。
3. 為 **X 軸** 和 **Y 軸** 選取通道。
4. 按一下 **確定**。

## 資料擷取模式

1. 在工具列上的裝置模式清單中，選取 **資料擷取**。
2. 開啟 **裝置選項** 視窗。
3. 為每個通道設定 **啟用**、**耦合** 和 **伏特/格**。
4. 要顯示其他單位，設定 **對應單位**、**對應最小值** 和 **對應最大值**。例如，以 °C 顯示溫度感測器的輸出。
5. 按一下 **確定**。
6. 在工具列上選取取樣率和取樣時長。
7. 按一下 **開始** 或按 `S`。

擷取期間不能變更通道設定。在最高取樣率 10 MHz 下，最大取樣時長約為 10 秒。在 1 kHz 下，擷取可以持續一天。

資料擷取模式使用示波器模式的校準。如果某個通道顯示偏移，在示波器模式下校準裝置。
