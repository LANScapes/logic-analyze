# Termes techniques et verbes

Chacun de ces termes techniques a un seul sens dans ce manuel. Chaque version linguistique de ce manuel utilise un seul terme pour chaque terme technique.

## Termes techniques

| Terme | Définition |
| --- | --- |
| application | Le programme Logic Analyze. |
| mode tampon | Le mode de fonctionnement dans lequel l'appareil conserve les échantillons dans sa mémoire jusqu'à la fin de la capture. |
| capture | Un enregistrement des signaux, du démarrage à l'arrêt. |
| voie | Une entrée de l'appareil, et la ligne qui affiche ses données. |
| mode des voies | Le paramètre qui sélectionne le nombre de voies et la fréquence d'échantillonnage maximale. |
| curseur | Une ligne verticale à un instant de la capture. Vous utilisez les curseurs pour les mesures. |
| décodeur | Une partie de l'application qui lit les données et trouve les trames d'un protocole. |
| appareil de démonstration | Un appareil de l'application qui produit des signaux de test. Il n'a pas de matériel. |
| appareil | L'analyseur logique DSLogic ou l'oscilloscope DSCope. |
| panneau | Une zone sur le côté de la zone des formes d'onde. |
| front | Un passage d'un niveau bas à un niveau haut (front montant) ou d'un niveau haut à un niveau bas (front descendant). |
| masse | Le point 0 V d'un circuit. |
| niveau | L'état d'un signal numérique : haut ou bas. |
| sonde | Le fil ou la pince qui relie une voie au circuit. |
| protocole | La spécification des données sur un bus, par exemple UART, I2C ou SPI. |
| impulsion | Un niveau entre deux fronts. |
| échantillon | La valeur d'une voie à un instant. |
| durée d'échantillonnage | La durée d'une capture. |
| fréquence d'échantillonnage | Le nombre d'échantillons par seconde, pour chaque voie. |
| session | Un fichier avec les paramètres de l'application et de l'appareil. |
| paramètre | Une valeur que vous pouvez changer dans l'application. |
| mode flux | Le mode de fonctionnement dans lequel l'appareil envoie les échantillons à l'ordinateur pendant la capture. |
| seuil | La tension qui sépare un niveau bas d'un niveau haut. |
| règle de temps | L'échelle de temps au-dessus de la zone des formes d'onde. |
| déclenchement | Une condition dans les signaux qui marque un instant de la capture. |
| position du déclenchement | La position du point de déclenchement dans la capture, en pourcentage de la durée d'échantillonnage. |
| forme d'onde | La ligne qui affiche le signal d'une voie. |
| zone des formes d'onde | La partie de la fenêtre qui affiche les formes d'onde. |

## Verbes techniques

| Verbe | Définition |
| --- | --- |
| capturer | Enregistrer les signaux avec l'appareil. |
| cliquer | Appuyer sur un bouton de la souris et le relâcher. |
| décoder | Lire des données et trouver les trames d'un protocole. |
| double-cliquer | Cliquer deux fois rapidement. |
| faire glisser | Déplacer un élément avec le bouton de la souris enfoncé. |
| exporter | Enregistrer des données dans un format pour un autre programme. |
| appuyer sur | Enfoncer une touche du clavier. |
| échantillonner | Lire la valeur d'un signal à un instant. |
| saisir | Écrire du texte avec le clavier. |
| zoom avant, zoom arrière | Afficher une partie plus courte ou plus longue de la forme d'onde. |
