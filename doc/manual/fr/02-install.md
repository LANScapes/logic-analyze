# Installer et démarrer l'application

## Installer l'application

<!-- edition: download -->
1. Allez sur la page des versions du projet : <https://github.com/LANScapes/logic-analyze/releases>.
2. Téléchargez le fichier ZIP de la version la plus récente.
3. Ouvrez le fichier ZIP dans le Finder. Le Finder extrait **Logic Analyze.app**.
4. Faites glisser **Logic Analyze.app** dans le dossier **Applications**.
<!-- end edition -->
<!-- edition: appstore -->
1. Ouvrez l'App Store sur le Mac.
2. Cherchez Logic Analyze dans l'App Store.
3. Installez l'application. L'App Store place **Logic Analyze.app** dans le dossier **Applications**.
<!-- end edition -->

L'application contient toutes les bibliothèques, le firmware et les décodeurs de protocole nécessaires. Vous n'installez pas de pilote sur macOS.

## Démarrer l'application

1. Connectez l'analyseur logique à l'ordinateur. Consultez [Connecter le DSLogic Plus](04-connect.md).
2. Ouvrez **Logic Analyze** depuis le dossier **Applications** ou depuis le Launchpad.
3. Si macOS affiche un message sur l'application, cliquez sur **Ouvrir**.

Au premier démarrage, l'application peut afficher la fenêtre **Documents**. Cliquez sur **Ouvrir** pour lire ce manuel. Cliquez sur **Ignorer** pour fermer la fenêtre. Cliquez sur **Ne plus afficher** si vous ne voulez plus voir cette fenêtre.

## Mettre à jour l'application

<!-- edition: download -->
1. Cliquez sur **Aide** › **Mise à jour**. L'application ouvre la page des versions dans votre navigateur web.
2. Si la page des versions affiche une version plus récente, téléchargez-la.
3. Quittez Logic Analyze.
4. Remplacez **Logic Analyze.app** dans le dossier **Applications** par la nouvelle version.

L'application conserve vos paramètres quand vous la remplacez.
<!-- end edition -->
<!-- edition: appstore -->
L'App Store met à jour l'application. Pour chercher une mise à jour immédiatement, faites ces étapes :

1. Ouvrez l'App Store sur le Mac.
2. Ouvrez la liste des mises à jour.
3. Si Logic Analyze est dans la liste, mettez-la à jour.

L'application conserve vos paramètres quand elle se met à jour.
<!-- end edition -->

## Ouvrir ce manuel

Cliquez sur **Aide** › **Manuel...**. L'application ouvre ce manuel dans la langue de l'interface utilisateur. Si le manuel n'existe pas dans cette langue, l'application ouvre le manuel en anglais.

## Changer la langue

1. Cliquez sur **Aide** › **Langue**.
2. Sélectionnez une langue dans la liste.

L'interface utilisateur passe dans la langue que vous sélectionnez.

## Changer le thème

1. Cliquez sur **Options** › **Affichage** › **Thèmes**.
2. Sélectionnez **Sombre** ou **Clair**.

## Déplacer la barre d'outils

Vous pouvez placer la barre d'outils en haut, en bas, à gauche ou à droite de la fenêtre. Avec la barre d'outils à gauche ou à droite, 16 voies peuvent utiliser toute la hauteur de la fenêtre.

1. Placez le pointeur sur la poignée au début de la barre d'outils.
2. Maintenez le bouton de la souris enfoncé.
3. Faites glisser la barre d'outils vers un bord de la fenêtre.
4. Relâchez le bouton de la souris.

L'application conserve la position de la barre d'outils au prochain démarrage.

## Options d'affichage

Pour changer les options d'affichage, cliquez sur **Options** › **Affichage** › **Options**. La fenêtre **Options d'affichage** contient ces paramètres :

| Paramètre | Fonction |
| --- | --- |
| **Défilement de la forme d'onde par glisser** | Quand vous faites glisser la forme d'onde rapidement et la relâchez, la forme d'onde continue à se déplacer. Ensuite, elle ralentit et s'arrête. |
| **Mettre à jour les dernières données à l'arrêt du mode répétitif** | Quand vous arrêtez une capture en mode **Répétitif**, l'application affiche les données de la dernière capture, qui n'est pas complète. |
| **Défilement auto vers les dernières données** | En mode flux, la forme d'onde se déplace pour afficher les données les plus récentes. |
| **Afficher le déclenchement au centre** | En mode oscilloscope, l'application affiche la position du déclenchement au milieu de la fenêtre. |
| **Afficher la session dans la barre de titre** | La barre de titre affiche le nom du fichier de session. |
| **Taille de police** | La taille du texte dans la zone des formes d'onde. |

## Options de journalisation

L'application peut enregistrer un fichier journal. Le fichier journal aide à trouver la cause d'un problème.

1. Cliquez sur **Aide** › **Journalisation**.
2. Sélectionnez une valeur de 0 à 5 dans **Niveau de journalisation**. Une valeur plus élevée enregistre plus de messages.
3. Sélectionnez **Enregistrer dans un fichier**.
4. Pour ajouter les nouveaux messages à la fin du fichier journal existant, sélectionnez **Mode ajout**.
5. Cliquez sur **OK**.

Pour voir le fichier journal, cliquez sur **Ouvrir** dans la fenêtre **Options de journalisation**. Pour effacer le fichier journal, cliquez sur **Effacer**.

## Signaler un problème

Cliquez sur **Aide** › **Signaler un bug**. L'application ouvre la page des problèmes du projet dans votre navigateur web. Indiquez dans votre rapport la version de l'application, la version de macOS et le modèle de l'appareil. Si possible, joignez le fichier journal.
