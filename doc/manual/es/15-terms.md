# Términos técnicos y verbos

Cada uno de estos términos técnicos tiene un solo significado en este manual. Cada versión de idioma de este manual usa un solo término para cada término técnico.

## Términos técnicos

| Término | Definición |
| --- | --- |
| aplicación | El programa Logic Analyze. |
| modo Buffer | El modo de funcionamiento en el que el dispositivo guarda las muestras en su memoria hasta el final de la captura. |
| captura | Un registro de las señales, desde el inicio hasta la parada. |
| canal | Una entrada del dispositivo, y la fila que muestra sus datos. |
| modo de canales | El ajuste que selecciona el número de canales y la frecuencia de muestreo máxima. |
| cursor | Una línea vertical en un instante de la captura. Los cursores sirven para las mediciones. |
| decodificador | Una parte de la aplicación que lee los datos y encuentra las tramas de un protocolo. |
| dispositivo de demostración | Un dispositivo de la aplicación que produce señales de prueba. No tiene hardware. |
| dispositivo | El analizador lógico DSLogic o el osciloscopio DSCope. |
| panel | Una zona al lado del área de formas de onda. |
| flanco | Un cambio de un nivel bajo a un nivel alto (flanco ascendente) o de un nivel alto a un nivel bajo (flanco descendente). |
| masa | El punto de 0 V de un circuito. |
| nivel | El estado de una señal digital: alto o bajo. |
| sonda | El cable o la pinza que conecta un canal al circuito. |
| protocolo | La especificación de los datos en un bus, por ejemplo UART, I2C o SPI. |
| pulso | Un nivel entre dos flancos. |
| muestra | El valor de un canal en un instante. |
| duración de muestreo | La duración de una captura. |
| frecuencia de muestreo | El número de muestras por segundo, para cada canal. |
| sesión | Un archivo con los ajustes de la aplicación y del dispositivo. |
| ajuste | Un valor que puede cambiar en la aplicación. |
| modo Stream | El modo de funcionamiento en el que el dispositivo envía las muestras al ordenador durante la captura. |
| umbral | La tensión que separa un nivel bajo de un nivel alto. |
| regla de tiempo | La escala de tiempo encima del área de formas de onda. |
| disparo | Una condición en las señales que marca un instante de la captura. |
| posición del disparo | La posición del punto de disparo en la captura, como porcentaje de la duración de muestreo. |
| forma de onda | La línea que muestra la señal de un canal. |
| área de formas de onda | La parte de la ventana que muestra las formas de onda. |

## Verbos técnicos

| Verbo | Definición |
| --- | --- |
| capturar | Registrar las señales con el dispositivo. |
| hacer clic | Pulsar y soltar un botón del ratón. |
| decodificar | Leer datos y encontrar las tramas de un protocolo. |
| hacer doble clic | Hacer clic dos veces rápidamente. |
| arrastrar | Mover un elemento con el botón del ratón pulsado. |
| exportar | Guardar datos en un formato para otro programa. |
| pulsar | Presionar una tecla del teclado. |
| muestrear | Leer el valor de una señal en un instante. |
| escribir | Introducir texto con el teclado. |
| acercar, alejar | Mostrar una parte más corta o más larga de la forma de onda. |
