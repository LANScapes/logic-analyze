# Lista de términos (español)

Términos fijos de la traducción al español del manual. Cada término inglés tiene una sola traducción.

| English | Español |
| --- | --- |
| app | aplicación |
| buffer mode | modo Buffer |
| capture (n) | captura |
| capture (v) | capturar |
| channel | canal |
| channel mode | modo de canales |
| click | hacer clic en |
| computer | ordenador |
| cursor | cursor |
| decode | decodificar |
| decoder | decodificador |
| demo device | dispositivo de demostración |
| device | dispositivo |
| dock | panel |
| double-click | hacer doble clic |
| drag | arrastrar |
| edge | flanco |
| export | exportar |
| falling edge | flanco descendente |
| ground | masa |
| level | nivel |
| press | pulsar |
| probe | sonda |
| protocol | protocolo |
| pulse | pulso |
| rising edge | flanco ascendente |
| sample (n) | muestra |
| sample (v) | muestrear |
| sample duration | duración de muestreo |
| sample rate | frecuencia de muestreo |
| select | seleccionar |
| session | sesión |
| setting | ajuste |
| stream mode | modo Stream |
| threshold | umbral |
| time ruler | regla de tiempo |
| toolbar | barra de herramientas |
| trigger | disparo |

| type | escribir |
| waveform | forma de onda |
| waveform area | área de formas de onda |
| zoom in, zoom out | acercar, alejar |
| WARNING / CAUTION / NOTE | ADVERTENCIA / PRECAUCIÓN / NOTA |

Instrucciones: imperativo con «usted» («Haga clic en», «Seleccione», «Pulse»).

Etiquetas de la interfaz en negrita: texto exacto de lang/es/*.json de la traducción de la aplicación (rama i18n/app-translations), sin los aceleradores «&» y sin los dos puntos finales. Etiquetas que quedan en inglés porque no tienen traducción: **OK**, **USB 2.0**, **USB 3.0**, **CK**, **TI**, **TO**, **SCL**, **SDA**, **1X**, **x1**, **x10**, **+**, **×**. La carpeta de macOS **Applications** se escribe **Aplicaciones**, como la muestra el Finder en español.
