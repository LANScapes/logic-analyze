# Term list: English – Polski

Bold UI labels use the exact Polish strings of the app translation (`lang/pl/*.json`, accelerators removed). Labels without a Polish string stay in English. Native macOS dialog buttons and folders use the macOS Polish names (**Zachowaj**, **Otwórz**, folder **Aplikacje**).
