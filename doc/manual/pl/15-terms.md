# Terminy i czasowniki techniczne

Każdy z tych terminów technicznych ma w tym podręczniku tylko jedno znaczenie. Każda wersja językowa tego podręcznika używa tylko jednej nazwy dla każdego terminu technicznego.

## Terminy techniczne

| Termin | Definicja |
| --- | --- |
| aplikacja | Program Logic Analyze. |
| tryb buforowy | Tryb pracy, w którym urządzenie przechowuje próbki w swojej pamięci do końca rejestracji. |
| rejestracja | Jeden zapis sygnałów, od startu do zatrzymania. |
| kanał | Jedno wejście urządzenia i wiersz, który pokazuje jego dane. |
| tryb kanałów | Ustawienie, które wybiera liczbę kanałów i maksymalną częstotliwość próbkowania. |
| kursor | Pionowa linia w jednym czasie rejestracji. Kursorów używasz do pomiarów. |
| dekoder | Część aplikacji, która odczytuje dane i znajduje ramki protokołu. |
| urządzenie demonstracyjne | Urządzenie w aplikacji, które tworzy sygnały testowe. Nie ma sprzętu. |
| urządzenie | Analizator logiczny DSLogic lub oscyloskop DSCope. |
| panel boczny | Panel z boku obszaru przebiegów. |
| zbocze | Zmiana z poziomu niskiego na poziom wysoki (zbocze narastające) lub z poziomu wysokiego na poziom niski (zbocze opadające). |
| masa | Punkt 0 V obwodu. |
| poziom | Stan sygnału cyfrowego: wysoki lub niski. |
| przewód pomiarowy | Przewód lub zacisk, który łączy kanał z obwodem. |
| protokół | Specyfikacja danych na magistrali, na przykład UART, I2C lub SPI. |
| impuls | Poziom między dwoma zboczami. |
| próbka | Wartość kanału w jednym czasie. |
| czas próbkowania | Czas trwania rejestracji. |
| częstotliwość próbkowania | Liczba próbek na sekundę dla każdego kanału. |
| sesja | Plik z ustawieniami aplikacji i urządzenia. |
| ustawienie | Wartość, którą możesz zmienić w aplikacji. |
| tryb strumieniowy | Tryb pracy, w którym urządzenie wysyła próbki do komputera podczas rejestracji. |
| próg | Napięcie, które oddziela poziom niski od poziomu wysokiego. |
| linijka czasu | Skala czasu nad obszarem przebiegów. |
| wyzwalanie | Warunek w sygnałach, który oznacza czas w rejestracji. |
| pozycja wyzwalania | Pozycja punktu wyzwolenia w rejestracji jako procent czasu próbkowania. |
| przebieg | Linia, która pokazuje sygnał kanału. |
| obszar przebiegów | Część okna, która pokazuje przebiegi. |

## Czasowniki techniczne

| Czasownik | Definicja |
| --- | --- |
| rejestrować | Zapisywać sygnały za pomocą urządzenia. |
| kliknąć | Nacisnąć i zwolnić przycisk myszy. |
| dekodować | Odczytać dane i znaleźć ramki protokołu. |
| kliknąć dwukrotnie | Kliknąć szybko dwa razy. |
| przeciągnąć | Przesunąć element z przytrzymanym przyciskiem myszy. |
| eksportować | Zapisać dane w formacie dla innego programu. |
| nacisnąć | Wcisnąć klawisz na klawiaturze. |
| próbkować | Odczytać wartość sygnału w jednym czasie. |
| wpisać | Napisać tekst na klawiaturze. |
| powiększyć, pomniejszyć | Pokazać krótszą lub dłuższą część przebiegu. |
