# Technical names and verbs

Each of these technical names has only one sense in this manual. Each language version of this manual uses only one name for each technical name.

## Technical names

| Name | Definition |
| --- | --- |
| app | The Logic Analyze program. |
| buffer mode | The operation mode in which the device keeps the samples in its memory until the end of the capture. |
| capture | One record of the signals, from the start to the stop. |
| channel | One input of the device, and the row that shows its data. |
| channel mode | The setting that selects the number of channels and the maximum sample rate. |
| cursor | A vertical line at one time in the capture. You use cursors for measurements. |
| decoder | A part of the app that reads the data and finds the frames of a protocol. |
| demo device | A device in the app that makes test signals. It has no hardware. |
| device | The DSLogic logic analyzer or the DSCope oscilloscope. |
| dock | A panel at the side of the waveform area. |
| edge | A change from a low level to a high level (rising edge) or from a high level to a low level (falling edge). |
| ground | The 0 V point of a circuit. |
| level | The condition of a digital signal: high or low. |
| probe | The wire or the clip that connects a channel to the circuit. |
| protocol | The specification for data on a bus, for example UART, I2C or SPI. |
| pulse | A level between two edges. |
| sample | The value of a channel at one time. |
| sample duration | The time length of a capture. |
| sample rate | The number of samples in each second, for each channel. |
| session | A file with the settings of the app and of the device. |
| setting | A value that you can change in the app. |
| stream mode | The operation mode in which the device sends the samples to the computer during the capture. |
| threshold | The voltage that divides a low level from a high level. |
| time ruler | The scale of time above the waveform area. |
| trigger | A condition in the signals that marks a time in the capture. |
| trigger position | The position of the trigger point in the capture, as a percentage of the sample duration. |
| waveform | The line that shows the signal of a channel. |
| waveform area | The part of the window that shows the waveforms. |

## Technical verbs

| Verb | Definition |
| --- | --- |
| capture | To record the signals with the device. |
| click | To push and release a mouse button. |
| decode | To read data and find the frames of a protocol. |
| double-click | To click two times fast. |
| drag | To move an item with the mouse button held. |
| export | To save data in a format for a different program. |
| press | To push a key on the keyboard. |
| sample | To read the value of a signal at one time. |
| type | To write text with the keyboard. |
| zoom in, zoom out | To show a shorter or a longer part of the waveform. |
