# 用語集（日本語）

この表は翻訳者用です。マニュアルには表示されません。各英語の用語には、マニュアル全体で 1 つの訳語だけを使います。

太字の UI ラベルは、アプリの翻訳ファイル `lang/ja/*.json` の同じ ID の文字列から取っています（`&` のアクセラレータ記号は除いています）。Qt の標準ボタン **OK** はそのままです。翻訳がないラベルは英語のままにします。
