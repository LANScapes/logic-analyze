# dslcap ツール

`dslcap` ツールは、メインウィンドウを使わずに DSLogic デバイスからデータをキャプチャします。スクリプトや自動テストで使います。このツールはサンプルをバイナリファイルに書き込みます。結果を含む JSON オブジェクトを 1 つ、標準出力に書き込みます。

このツールはアプリバンドルの中にあります。

```sh
"/Applications/Logic Analyze.app/Contents/MacOS/dslcap"
```

> [!NOTE]
> 同時にデバイスを使えるプログラムは 1 つだけです。`dslcap` を使う前に、Logic Analyze を終了してください。

## デバイスを一覧表示する

ライブラリが見つけられるデバイスを一覧表示するには、次のコマンドを入力します。

```sh
dslcap --list
```

接続された各 DSLogic デバイスの USB 識別子を一覧表示するには、次のコマンドを入力します。

```sh
dslcap --list-ids
```

`--list-ids` コマンドは、macOS が保持している USB デバイスの情報だけを読みます。デバイスにデータを送りません。出力には、各デバイスのモデル、USB の位置、レジストリ識別子が含まれます。

## データをキャプチャする

次のコマンドは、チャンネル 0 と 1 で、10 MHz で 1000000 サンプルをキャプチャします。

```sh
dslcap --channels 0,1 --samplerate 10000000 --samples 1000000 --out /tmp/capture
```

ツールはサンプルを `/tmp/capture.bin` に書き込みます。この名前のファイルがすでにある場合、ツールはエラーで停止します。ツールはファイルを置き換えません。

キャプチャのオプションは次のとおりです。

| オプション | 機能 | 初期値 |
| --- | --- | --- |
| `--channels LIST` | 記録するチャンネル。例：`0,1,2`。 | `0` |
| `--samplerate HZ` | サンプルレート（Hz）。 | `10000000` |
| `--samples N` | 各チャンネルのサンプル数。 | `1000000` |
| `--vth VOLTS` | しきい値電圧。 | `1.6` |
| `--mode MODE` | `buffer` または `stream`。 | `buffer` |
| `--trigger CH[:T]` | チャンネル CH のトリガ。T には `R`（立ち上がりエッジ）、`F`（立ち下がりエッジ）、`C`（立ち上がりエッジまたは立ち下がりエッジ）、`1`（ハイレベル）、`0`（ローレベル）を使います。 | トリガなし。CH だけを指定すると `R`。 |
| `--trigpos PERCENT` | サンプル数に対するパーセントでのトリガ位置。 | `10` |
| `--timeout SEC` | キャプチャの最大時間（秒）。 | `30` |
| `--out PATH` | 出力ファイルのパス（拡張子 `.bin` なし）。 | このオプションは必須です。 |
| `--log-level N` | 標準エラー出力に出すライブラリメッセージの量。0（なし）から 5（すべて）。 | `1` |

ツールは、デバイスを使う前にすべてのオプションを調べます。オプションが正しくない場合、ツールは停止してエラーを出します。

## 出力ファイル

`.bin` ファイルには、チャンネル番号の小さい順にチャンネルが入っています。各チャンネルについて、そのチャンネルのすべてのサンプルが入っています。各バイトに 8 サンプルが入ります。最初のサンプルは最下位ビットです。各チャンネルのデータは、8 バイト単位の整数個を占めます。したがって、各チャンネルは `ceil(samples / 64) × 8` バイトを使います。

## JSON の結果

ツールは、1 行に JSON オブジェクトを 1 つ書き込みます。キャプチャが正しく終わると、オブジェクトにはデバイス名、サンプルレート、サンプル数、チャンネルが入ります。しきい値電圧、モード、トリガ、キャプチャの時間、`.bin` ファイルのパスも入ります。キャプチャが正しくない場合、オブジェクトには `error` キーが入ります。その場合、ツールは `.bin` ファイルを作りません。

終了ステータスが 0 で、JSON オブジェクトが完全な場合にだけ、結果を使います。

## 終了ステータス

| ステータス | 意味 |
| --- | --- |
| 0 | キャプチャは完了しました。 |
| 1 | 動作中にエラーが発生しました。例：I/O エラー。 |
| 2 | オプションが正しくないか、その設定がデバイスにありません。 |
| 3 | キャプチャは完了しませんでした。 |

## dslcap を起動するプログラムのためのオプション

- `--parent-fd N`：このツールを起動したプログラムが記述子 N のパイプを閉じると、ツールは停止します。キャプチャが完了していない場合、ツールは出力ファイルを削除します。
- `--res DIR`：ファームウェアファイルのフォルダ。通常、ツールはこのフォルダを自動で見つけます。環境変数 `DSLCAP_RES` を設定することもできます。
- `--res-manifest FD`：ツールは、各ファームウェアファイルをデバイスに送る前に、そのファイルの SHA-256 値を調べます。

これらのオプションの詳しい説明は、ソースコードのファイル `tools/dslcap/README.md` にあります。
