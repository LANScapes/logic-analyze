# オシロスコープモードとデータ収集モード

Logic Analyze は、DreamSourceLab の DSCope オシロスコープも操作できます。DSCope には 2 つのデバイスモードがあります。

- **オシロスコープ**：周期が一定の信号と、1 つの信号条件のため。
- **データ収集**：長い時間の低速の信号のため。例：電源電圧、センサの出力。

DSLogic デバイスには、これらのモードはありません。この章では主な手順だけを示します。

## DSCope を接続する

> [!WARNING]
> プローブを商用電源の電圧に接続しないでください。商用電源と電気的に接続された回路にプローブを接続しないでください。この電圧により、けがまたは死亡の原因となります。

> [!CAUTION]
> プローブのグランド、DSCope のグランド、コンピュータのグランドはつながっています。プローブのグランドは、コンピュータのグランドと同じ電圧の点にだけ接続してください。電圧の差で機器が損傷します。

1. USB ケーブルで DSCope をコンピュータに接続します。
2. Logic Analyze を起動します。デバイスの一覧に DSCope が表示されることを確認します。
3. プローブを DSCope の入力に接続します。
4. 各プローブの減衰スイッチを設定します。
5. 各プローブのグランドクリップを回路のグランドに接続します。
6. プローブの先端を信号に接続します。

## デバイスオプション

**オプション** › **デバイスオプション...** をクリックするか、`O` を押します。

- **動作モード**：測定には **通常**。**内部テスト** はデバイスのテスト専用です。
- **帯域制限**：**全帯域** または **20MHz**。20 MHz の制限で高周波ノイズが減ります。

## DSCope をキャリブレーションする

入力のゲインとオフセットは、温度と湿度で変わります。測定を正確に保つため、DSCope をキャリブレーションします。

### 自動キャリブレーション

> [!CAUTION]
> キャリブレーションの前に、すべてのプローブを入力から外してください。キャリブレーション中に入力に信号があると、キャリブレーション値が正しくなくなります。

1. **デバイスオプション** ウィンドウを開きます。
2. **自動キャリブレーション** をクリックします。
3. すべてのプローブを外します。**OK** をクリックします。キャリブレーションは数分続きます。
4. キャリブレーションが完了したら、**保存** をクリックして結果を保持します。

キャリブレーションを止めるには、**中止** をクリックします。その後、デバイスは前のキャリブレーション値を使います。

### 手動キャリブレーション

1. **デバイスオプション** ウィンドウを開きます。
2. **手動キャリブレーション** をクリックします。
3. ツールバーの **開始** をクリックします。
4. オフセットを調整するには、プローブをグランドに接続します。ゲインを調整するには、電圧がわかっている信号にプローブを接続します。
5. キャリブレーションする垂直スケールを設定します。
6. 波形が正しくなるまで、チャンネルの **オフセット** または **ゲイン** のスライダを動かします。
7. 垂直スケールごとに、ステップ 5 と 6 を繰り返します。
8. **保存** をクリックします。

変更を破棄するには、**中止** をクリックします。デバイスを外すまでだけ変更を使うには、**終了** をクリックします。初期値に戻すには、**リセット** をクリックします。リセットの後は、自動キャリブレーションをもう一度実行します。

## チャンネルの設定

各チャンネルには、波形エリアの左に次の操作部品があります。

- **有効**：チャンネルをオンまたはオフにします。
- **垂直スケール**：1 目盛りあたりの電圧。ウィンドウには 10 目盛りがあります。スケールを変えるには、ノブの上でマウスホイールを回すか、ノブの上部または下部をクリックします。`0` または `1` を押してチャンネルのノブを選択し、`↑` または `↓` を押すこともできます。
- **カップリング**：**DC** または **AC**。
- **プローブ減衰**：プローブのスイッチに合わせて **x1** または **x10** を設定します。
- **自動**：入力にある信号に合わせて、垂直スケール、水平スケール、トリガレベルを設定します。

チャンネルの波形を上下に動かすには、チャンネルラベルをドラッグします。

## 水平スケール

ツールバーの一覧で、1 目盛りあたりの時間を選択します。波形エリアでマウスホイールを回すこともできます。

## 開始と停止

- 連続キャプチャを開始するには、**開始** をクリックするか、`S` を押します。止めるには、**停止** をクリックします。
- 波形を 1 回キャプチャして停止するには、**単発** をクリックするか、`I` を押します。

## トリガ

トリガのドックを開くには、**トリガ** をクリックするか、`T` を押します。ドックには次の設定があります。

- **トリガ位置**：キャプチャ内のトリガ点の位置（パーセント）。
- **ホールドオフ時間**：トリガの後、デバイスが新しいトリガを無視する時間。パルスの群から安定した波形を得るのに使います。
- **トリガ感度**：トリガに必要な電圧の変化。値が大きいほど、多くのノイズを無視します。
- **トリガソース**：**自動**、**チャンネル 0**、**チャンネル 1**、**チャンネル 0 && 1**、**チャンネル 0 | 1**。
- **トリガタイプ**：**立ち上がりエッジ** または **立ち下がりエッジ**。

トリガレベルを設定するには、チャンネルのトリガレベルのラベルをクリックします。マウスを動かします。もう一度クリックして、レベルを設定します。

## 測定

### 自動測定

波形エリアの下部に、自動測定のボックスが 10 個あります。

1. 測定ボックスをクリックします。
2. チャンネルを選択します。
3. 測定項目を選択します。ボックスを空にするには、**リセット** をクリックします。

アプリは、次回の起動のためにこれらの設定を保持します。

### カーソル

- 時間のカーソルを追加するには、タイムルーラをクリックします。波形エリアで右マウスボタンをクリックし、**Y カーソルを追加** を選択することもできます。
- 電圧のカーソルを追加するには、波形エリアで右マウスボタンをクリックし、**X カーソルを追加** を選択します。各電圧カーソルには水平線が 2 本あります。線の間のラベルに電圧の差が表示されます。
- 2 つのカーソルの間の時間を測定するには、測定のドックの **カーソル間距離** グループを使います。

### ポインタで測定する

キャプチャを止めた後、ポインタを波形に置きます。アプリは、ポインタの位置のサンプルの電圧を表示します。

時間を測定するには、波形の空いている部分をダブルクリックします。2 つ目の点をクリックします。3 つ目の点をクリックすると、周波数、周期、デューティ比が表示されます。取り消すには、右マウスボタンをクリックします。

## スペクトル（FFT）

1. **機能** › **FFT** をクリックします。
2. **FFT 有効** を選択します。
3. **FFT 長**、**サンプル間隔**、**FFT ソース**、**FFT 窓関数** を設定します。
4. **Y 軸モード** と **dBV レンジ** を設定します。
5. **OK** をクリックします。

スペクトルは波形の下に表示されます。スペクトルの上でマウスホイールを回すと、周波数のスケールがズームします。スペクトルをドラッグすると動きます。ポインタをスペクトルに置くと、周波数と振幅が表示されます。

## 演算チャンネル

1. **機能** › **演算** をクリックします。
2. **有効** を選択します。
3. **演算の種類** を選択します：**加算**、**減算**、**乗算**、**除算**。
4. **ソース 1** と **ソース 2** を選択します。
5. **OK** をクリックします。

## リサジュー図形

1. **オプション** › **表示** › **リサジュー** をクリックします。
2. **有効** を選択します。
3. **X 軸** と **Y 軸** のチャンネルを選択します。
4. **OK** をクリックします。

## データ収集モード

1. ツールバーのデバイスモードの一覧で、**データ収集** を選択します。
2. **デバイスオプション** ウィンドウを開きます。
3. 各チャンネルで、**有効**、**カップリング**、**V/div** を設定します。
4. 別の単位で表示するには、**マップ単位**、**マップ最小値**、**マップ最大値** を設定します。たとえば、温度センサの出力を °C で表示します。
5. **OK** をクリックします。
6. ツールバーで、サンプルレートとサンプル時間を選択します。
7. **開始** をクリックするか、`S` を押します。

キャプチャ中はチャンネルの設定を変更できません。最高のサンプルレート 10 MHz では、最大サンプル時間は約 10 秒です。1 kHz では、キャプチャを 1 日続けられます。

データ収集モードは、オシロスコープモードのキャリブレーションを使います。チャンネルにオフセットがある場合は、オシロスコープモードでデバイスをキャリブレーションします。
