# トリガ

トリガは信号の条件です。条件が発生すると、デバイスはその時間をトリガ点としてマークします。トリガを使うと、調べたい部分の信号をキャプチャできます。

アプリには 2 種類のトリガがあります。

- **シンプルトリガ**：1 つ以上のチャンネルのエッジまたはレベル。
- **高度なトリガ**：一連の条件、またはシリアルバスの値。

トリガのドックを開くには、ツールバーの **トリガ** をクリックするか、`T` を押します。

> [!NOTE]
> 信号がトリガ条件に合わない場合、キャプチャは待ち続けます。トリガなしで信号を見るには、**即時** をクリックします。待機を止めるには、**停止** をクリックします。

## トリガ位置

**トリガ位置** の設定で、キャプチャ内のトリガ点の位置を設定します。値はサンプル時間に対するパーセントです。

- 小さい値（例：10%）では、トリガの後の信号が多く表示されます。
- 大きい値（例：90%）では、トリガの前の信号が多く表示されます。

トリガ位置はデバイスのメモリを使います。したがって、トリガ位置はバッファモードでだけ設定できます。ストリームモードでは、トリガ位置は常に約 1% です。

## シンプルトリガ

波形エリアの各チャンネルラベルには、トリガボタンが 5 つあります。左から順に、次のボタンです。

1. 立ち上がりエッジ
2. ハイレベル
3. 立ち下がりエッジ
4. ローレベル
5. 立ち上がりエッジまたは立ち下がりエッジ

![チャンネルラベルのトリガボタン](../figures/simple-trigger-buttons.png)

シンプルトリガを設定するには、次のステップを実行します。

1. トリガのドックを開きます。
2. **シンプルトリガ** を選択します。
3. チャンネルのラベルで、必要なトリガボタンをクリックします。ボタンの色が変わります。
4. チャンネルのトリガを取り消すには、同じボタンをもう一度クリックします。
5. **トリガ位置** を設定します。

複数のチャンネルにトリガを設定すると、すべての条件が同じサンプルで発生する必要があります（論理 AND）。

## 高度なトリガ

> [!NOTE]
> 高度なトリガは、バッファモードでだけ使えます。使うには、**動作モード** を **バッファモード** に設定します。[デバイスオプション](05-device-options.md)を参照してください。

高度なトリガを使うには、トリガのドックで **高度なトリガ** を選択します。次に、**ステージトリガ** タブまたは **シリアルトリガ** タブを選択します。

### 各チャンネルの値

ステージトリガとシリアルトリガでは、16 文字の行を使います。各文字が 1 つのチャンネルの条件です。右端の文字はチャンネル 0 です。左端の文字はチャンネル 15 です。

| 文字 | 条件 |
| --- | --- |
| `X` | すべての値（そのチャンネルは影響しません）。 |
| `0` | ローレベル。 |
| `1` | ハイレベル。 |
| `R` | 立ち上がりエッジ。 |
| `F` | 立ち下がりエッジ。 |
| `C` | 立ち上がりエッジまたは立ち下がりエッジ。 |

### ステージトリガ

ステージトリガは一連の条件です。各条件が 1 つのステージです。デバイスは最初にステージ 0 を調べます。ステージの条件が発生すると、デバイスは次のステージに進みます。最後のステージが完了すると、トリガが発生します。ステージは最大 16 個使えます。

各ステージには次の設定があります。

- チャンネル条件の行が 2 つ。
- 各行の `==` または `!=`。`==` では、チャンネルがその行と一致すると条件が発生します。`!=` では、チャンネルがその行と一致しないと条件が発生します。
- **And** または **Or**。この設定で 2 つの行を結び付けます。
- **カウンタ**：ステージが完了するまでに、条件が発生する必要がある回数。
- **連続**：このチェックボックスを選択すると、条件は途切れずに続くサンプルで発生する必要があります。

![ステージトリガの設定](../figures/stage-trigger-panel.png)

ステージトリガを設定するには、次のステップを実行します。

1. **トリガ段数** で、ステージの数を選択します。
2. 右側のステージの一覧で、ステージ 0 をクリックします。
3. 1 行目にチャンネル条件を入力します。
4. 必要な場合は、2 行目にチャンネル条件を入力し、**And** または **Or** を選択します。
5. **カウンタ** に値を入力します。
6. 他の各ステージについて、ステップ 2 から 5 を繰り返します。

次に 3 つの例を示します。

**例 1。** チャンネル 0 が 1000 サンプルより長くハイのままのときにトリガします。

1. **トリガ段数** を 1 に設定します。
2. ステージ 0 の 1 行目で、チャンネル 0 に `1` を入力します。
3. **連続** を選択します。
4. **カウンタ** を 1000 に設定します。

![例 1](../figures/stage-example-level-count.png)

**例 2。** チャンネル 0 の立ち上がりエッジ、またはチャンネル 1 の立ち下がりエッジでトリガします。

1. **トリガ段数** を 1 に設定します。
2. ステージ 0 の 1 行目で、チャンネル 0 に `R` を入力します。
3. 2 行目で、チャンネル 1 に `F` を入力します。
4. **Or** を選択します。

![例 2](../figures/stage-example-or.png)

**例 3。** チャンネル 0 の立ち上がりエッジ、次にチャンネル 1 の立ち下がりエッジ 100 回、次にチャンネル 2 のハイレベルでトリガします。

1. **トリガ段数** を 3 に設定します。
2. ステージ 0 で、チャンネル 0 に `R` を入力します。
3. ステージ 1 で、チャンネル 1 に `F` を入力します。**カウンタ** を 100 に設定します。
4. ステージ 2 で、チャンネル 2 に `1` を入力します。

![例 3](../figures/stage-example-sequence.png)

### シリアルトリガ

シリアルトリガは、シリアルバスのデータ値を見つけます。シフトレジスタとして動作します。設定は次のとおりです。

- **開始フラグ**：シリアルトリガを開始する条件。
- **停止フラグ**：シフトレジスタをクリアする条件。
- **クロックフラグ**：シフトレジスタに 1 ビットを追加する条件。
- **データチャンネル**：データを送るチャンネル。
- **データビット**：値のビット数。
- **データ値**：トリガを発生させる値。

開始フラグが発生した後、デバイスはクロックフラグのたびにデータチャンネルを読み取ります。デバイスはこのビットをシフトレジスタに入れます。シフトレジスタの最後のビットが **データ値** と等しくなると、トリガが発生します。停止フラグが発生すると、デバイスはシフトレジスタをクリアします。

![シリアルトリガの設定](../figures/serial-trigger-panel.png)
<!-- TODO: new screenshot -->

**例 4。** I2C バスに値 `010000100` が現れたときにトリガします。チャンネル 0 は SCL、チャンネル 1 は SDA です。

1. **開始フラグ** を、SCL がハイのときの SDA の立ち下がりエッジに設定します：右端の 2 文字に `F1`。
2. **停止フラグ** を、SCL がハイのときの SDA の立ち上がりエッジに設定します：`R1`。
3. **クロックフラグ** を SCL の立ち上がりエッジに設定します：チャンネル 0 に `R`。
4. **データチャンネル** を 1 に設定します。
5. **データビット** を 9 に設定します。
6. **データ値** に `010000100` を入力します。

![例 4](../figures/serial-example-i2c.png)

**例 5。** SPI バスの MOSI に値 `0x1234` が現れたときにトリガします。チャンネル 0 は CS#、チャンネル 1 は CLK、チャンネル 2 は MISO、チャンネル 3 は MOSI です。

1. **開始フラグ** を CS# の立ち下がりエッジに設定します：チャンネル 0 に `F`。
2. **停止フラグ** を CS# の立ち上がりエッジに設定します：チャンネル 0 に `R`。
3. **クロックフラグ** を CLK の立ち上がりエッジに設定します：チャンネル 1 に `R`。
4. **データチャンネル** を 3 に設定します。
5. **データビット** を 16 に設定します。
6. **データ値** に `0001001000110100` を入力します。

![例 5](../figures/serial-example-spi.png)

値を 16 進数で入力するには、**16進形式で入力** を選択します。次に、**16進** フィールドに値を入力します。
