# アプリのインストールと起動

## アプリをインストールする

1. プロジェクトのリリースページを開きます：<https://github.com/LANScapes/logic-analyze/releases>。
2. 最新リリースの ZIP ファイルをダウンロードします。
3. Finder で ZIP ファイルを開きます。Finder が **Logic Analyze.app** を展開します。
4. **Logic Analyze.app** を **アプリケーション** フォルダにドラッグします。

このアプリには、必要なライブラリ、ファームウェア、プロトコルデコーダがすべて含まれます。macOS ではドライバをインストールしません。

## アプリを起動する

1. ロジックアナライザをコンピュータに接続します。[DSLogic Plus を接続する](04-connect.md)を参照してください。
2. **アプリケーション** フォルダまたは Launchpad から **Logic Analyze** を開きます。
3. macOS がアプリについてのメッセージを表示したら、**開く** をクリックします。

アプリを初めて起動すると、**ドキュメント** ウィンドウが表示されることがあります。このマニュアルを読むには、**開く** をクリックします。ウィンドウを閉じるには、**無視** をクリックします。このウィンドウを再び表示しない場合は、**今後表示しない** をクリックします。

## アプリを更新する

1. **ヘルプ** › **更新** をクリックします。アプリが Web ブラウザでリリースページを開きます。
2. リリースページに新しいバージョンがあれば、ダウンロードします。
3. Logic Analyze を終了します。
4. **アプリケーション** フォルダの **Logic Analyze.app** を新しいバージョンに置き換えます。

アプリを置き換えても、設定は保持されます。

## このマニュアルを開く

**ヘルプ** › **マニュアル...** をクリックします。アプリは、ユーザーインターフェイスの言語でこのマニュアルを開きます。その言語のマニュアルがない場合は、英語のマニュアルを開きます。

## 言語を変更する

1. **ヘルプ** › **言語** をクリックします。
2. 一覧から言語を選択します。

ユーザーインターフェイスが選択した言語に変わります。

## テーマを変更する

1. **オプション** › **表示** › **テーマ** をクリックします。
2. **ダーク** または **ライト** を選択します。

## ツールバーを移動する

ツールバーは、ウィンドウの上、下、左、右に置けます。ツールバーが左または右にあると、16 チャンネルがウィンドウの高さ全体を使えます。

1. ツールバーの先頭にあるつまみにポインタを置きます。
2. マウスボタンを押したままにします。
3. ツールバーをウィンドウの端までドラッグします。
4. マウスボタンを放します。

次回の起動時も、アプリはツールバーの位置を保持します。

## 表示オプション

表示オプションを変更するには、**オプション** › **表示** › **オプション** をクリックします。**表示オプション** ウィンドウに次の設定があります。

| 設定 | 機能 |
| --- | --- |
| **マウスドラッグで波形をスクロール** | 波形をすばやくドラッグして放すと、波形は動き続けます。その後、波形の動きは遅くなり、止まります。 |
| **繰り返しモード停止時に最新データへ更新** | **繰り返し** モードでキャプチャを停止すると、最後のキャプチャのデータを表示します。このキャプチャは完了していません。 |
| **最新データへ自動スクロール** | ストリームモードで、最新のデータを表示するように波形が動きます。 |
| **トリガ位置を中央に表示** | オシロスコープモードで、トリガ位置をウィンドウの中央に表示します。 |
| **タイトルバーにセッション名を表示** | タイトルバーにセッションファイルの名前を表示します。 |
| **フォントサイズ** | 波形エリアの文字の大きさです。 |

## ログ設定

アプリはログファイルを記録できます。ログファイルは問題の原因を調べるのに役立ちます。

1. **ヘルプ** › **ログ設定** をクリックします。
2. **ログレベル** で 0 から 5 の値を選択します。値が大きいほど、多くのメッセージを記録します。
3. **ファイルに保存** を選択します。
4. 既存のログファイルの最後に新しいメッセージを追加するには、**追記モード** を選択します。
5. **OK** をクリックします。

ログファイルを見るには、**ログ設定** ウィンドウで **開く** をクリックします。ログファイルを消去するには、**消去** をクリックします。

## 問題を報告する

**ヘルプ** › **不具合報告** をクリックします。アプリが Web ブラウザでプロジェクトの Issue ページを開きます。報告には、アプリのバージョン、macOS のバージョン、デバイスのモデルを書いてください。可能であれば、ログファイルを添付してください。
