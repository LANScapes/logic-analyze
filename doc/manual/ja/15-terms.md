# 技術名称と動詞

このマニュアルでは、次の各技術名称に意味が 1 つだけあります。このマニュアルの各言語版では、各技術名称に 1 つの訳語だけを使います。

## 技術名称

| 名称 | 定義 |
| --- | --- |
| アプリ | Logic Analyze プログラム。 |
| バッファモード | キャプチャが終わるまで、デバイスがサンプルをメモリに保持する動作モード。 |
| キャプチャ | 開始から停止までの、信号の 1 回の記録。 |
| チャンネル | デバイスの 1 つの入力と、そのデータを表示する行。 |
| チャンネルモード | チャンネル数と最大サンプルレートを選択する設定。 |
| カーソル | キャプチャ内のある時間に引かれた縦線。カーソルは測定に使います。 |
| デコーダ | データを読み、プロトコルのフレームを見つける、アプリの一部。 |
| デモデバイス | テスト信号を作る、アプリ内のデバイス。ハードウェアはありません。 |
| デバイス | DSLogic ロジックアナライザまたは DSCope オシロスコープ。 |
| ドック | 波形エリアの横にあるパネル。 |
| エッジ | ローレベルからハイレベルへの変化（立ち上がりエッジ）、またはハイレベルからローレベルへの変化（立ち下がりエッジ）。 |
| グランド | 回路の 0 V の点。 |
| レベル | デジタル信号の状態：ハイまたはロー。 |
| プローブ | チャンネルを回路に接続する線またはクリップ。 |
| プロトコル | バス上のデータの仕様。例：UART、I2C、SPI。 |
| パルス | 2 つのエッジの間のレベル。 |
| サンプル | ある時間におけるチャンネルの値。 |
| サンプル時間 | 1 回のキャプチャの時間の長さ。 |
| サンプルレート | 各チャンネルの 1 秒あたりのサンプル数。 |
| セッション | アプリとデバイスの設定を含むファイル。 |
| 設定 | アプリで変更できる値。 |
| ストリームモード | キャプチャ中に、デバイスがサンプルをコンピュータに送る動作モード。 |
| しきい値 | ローレベルとハイレベルを分ける電圧。 |
| タイムルーラ | 波形エリアの上にある時間の目盛り。 |
| トリガ | キャプチャ内の時間をマークする、信号の条件。 |
| トリガ位置 | キャプチャ内のトリガ点の位置。サンプル時間に対するパーセント。 |
| 波形 | チャンネルの信号を示す線。 |
| 波形エリア | ウィンドウのうち、波形を表示する部分。 |

## 技術動詞

| 動詞 | 定義 |
| --- | --- |
| キャプチャする | デバイスで信号を記録すること。 |
| クリックする | マウスボタンを押して放すこと。 |
| デコードする | データを読み、プロトコルのフレームを見つけること。 |
| ダブルクリックする | すばやく 2 回クリックすること。 |
| ドラッグする | マウスボタンを押したまま項目を動かすこと。 |
| エクスポートする | 別のプログラム用の形式でデータを保存すること。 |
| 押す | キーボードのキーを押し下げること。 |
| サンプリングする | ある時間における信号の値を読むこと。 |
| 入力する | キーボードで文字を書くこと。 |
| ズームイン、ズームアウトする | 波形の短い部分または長い部分を表示すること。 |
