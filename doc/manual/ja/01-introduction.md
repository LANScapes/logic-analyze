# はじめに

## Logic Analyze について

Logic Analyze は、DreamSourceLab のロジックアナライザ用の macOS アプリです。LANScapes がこのアプリを提供します。このアプリは DSView から作られています。DSView は DreamSourceLab のプログラムです。DSView は sigrok プロジェクトのソフトウェアを使います。

このアプリは、DSLogic ロジックアナライザからデジタル信号を記録します。次に、信号を波形として表示します。波形を測定できます。シリアルプロトコルをデコードできます。データを保存し、他の形式にエクスポートすることもできます。

このマニュアルの例では DSLogic Plus を使います。他の DSLogic モデルも同じ手順で操作します。チャンネル数、メモリ、サンプルレートの上限はモデルによって異なります。

このアプリには `dslcap` ツールも含まれます。このツールは、メインウィンドウを使わずにデータをキャプチャします。[dslcap ツール](13-dslcap.md)を参照してください。

## このマニュアルについて

このマニュアルは ASD-STE100 簡略技術英語の規則に従って書かれています。各文は短くしています。手順の各ステップには指示が 1 つだけあります。このマニュアルの各技術名称には意味が 1 つだけあります。[技術名称と動詞](15-terms.md)に技術名称の一覧があります。

このマニュアルでは次の表記を使います。

- **太字**は、アプリのラベルを示します。たとえば、ボタン、メニュー項目、フィールドです。
- `コード表記`は、キーボードのキー、コマンド、ファイル名、または入力する値を示します。
- メニューの階層は記号 › で示します。例：**ファイル** › **保存...**。
- 番号付きのステップの一覧は手順です。ステップを示された順に実行します。

## 安全上の指示

このマニュアルでは、安全上の指示に次のラベルを使います。

- **警告** は、けがまたは死亡のリスクを示します。
- **注意** は、機器の損傷のリスク、またはデータのリスクを示します。
- **注記** は、役に立つ情報を示します。**注記** の後の情報は指示ではありません。

安全上の指示は、それが適用されるステップの前にあります。手順を始める前に、すべての安全上の指示を読んでください。

> [!WARNING]
> プローブを商用電源の電圧に接続しないでください。商用電源と電気的に接続された回路にプローブを接続しないでください。プローブはコンピュータと電気的に接続されています。この電圧により、けがまたは死亡の原因となります。

> [!CAUTION]
> デバイス仕様の上限を超える電圧をチャンネル入力に加えないでください。電圧が高すぎると、ロジックアナライザが損傷します。

> [!CAUTION]
> ロジックアナライザのグランド線は、USB ケーブルを通してコンピュータのグランドに接続されています。グランド線は、測定する回路のグランドにだけ接続してください。2 つのグランドの電圧が異なると、大きな電流が流れます。この電流で、回路、ロジックアナライザ、コンピュータが損傷します。

## システム要件

次の機器が必要です。

- macOS が動作する Mac。最小 macOS バージョンはリリースノートに記載されています。
- USB ポート。USB 3.0 ポートで速度が最も高くなります。USB 2.0 ポートも使えます。
- DSLogic ロジックアナライザ、その USB ケーブル、そのプローブケーブル。

ロジックアナライザがなくてもアプリを使えます。**デモ** デバイスはテスト信号を作ります。以前のキャプチャのデータファイルを開くこともできます。
