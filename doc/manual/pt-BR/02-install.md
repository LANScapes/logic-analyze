# Instalar e iniciar o aplicativo

## Instalar o aplicativo

1. Vá para a página de versões do projeto: <https://github.com/LANScapes/logic-analyze/releases>.
2. Baixe o arquivo ZIP da versão mais nova.
3. Abra o arquivo ZIP no Finder. O Finder extrai o **Logic Analyze.app**.
4. Arraste o **Logic Analyze.app** para a pasta **Aplicativos**.

O aplicativo contém todas as bibliotecas, o firmware e os decodificadores de protocolo necessários. Você não instala um driver no macOS.

## Iniciar o aplicativo

1. Conecte o analisador lógico ao computador. Consulte [Conectar o DSLogic Plus](04-connect.md).
2. Abra o **Logic Analyze** na pasta **Aplicativos** ou no Launchpad.
3. Se o macOS mostrar uma mensagem sobre o aplicativo, clique em **Abrir**.

Quando o aplicativo inicia pela primeira vez, ele pode mostrar a janela **Documento**. Clique em **Abrir** para ler este manual. Clique em **Ignorar** para fechar a janela. Clique em **Não mostrar novamente** se você não quiser ver esta janela de novo.

## Atualizar o aplicativo

1. Clique em **Ajuda** › **Atualizar**. O aplicativo abre a página de versões no seu navegador da web.
2. Se a página de versões mostrar uma versão mais nova, baixe-a.
3. Feche o Logic Analyze.
4. Substitua o **Logic Analyze.app** na pasta **Aplicativos** pela nova versão.

O aplicativo mantém as suas configurações quando você o substitui.

## Abrir este manual

Clique em **Ajuda** › **Manual...**. O aplicativo abre este manual no idioma da interface. Se o manual não estiver disponível nesse idioma, o aplicativo abre o manual em inglês.

## Mudar o idioma

1. Clique em **Ajuda** › **Idioma**.
2. Selecione um idioma na lista.

A interface muda para o idioma que você seleciona.

## Mudar o tema

1. Clique em **Opções** › **Exibir** › **Temas**.
2. Selecione **Escuro** ou **Claro**.

## Mover a barra de ferramentas

Você pode colocar a barra de ferramentas em cima, embaixo, à esquerda ou à direita da janela. Com a barra de ferramentas à esquerda ou à direita, 16 canais podem usar a altura total da janela.

1. Coloque o ponteiro na alça no início da barra de ferramentas.
2. Mantenha o botão do mouse pressionado.
3. Arraste a barra de ferramentas até uma borda da janela.
4. Solte o botão do mouse.

O aplicativo mantém a posição da barra de ferramentas quando você o inicia de novo.

## Opções de exibição

Para mudar as opções de exibição, clique em **Opções** › **Exibir** › **Opções**. A janela **Opções de exibição** mostra estas configurações:

| Configuração | Função |
| --- | --- |
| **Rolar a forma de onda arrastando o mouse** | Quando você arrasta a forma de onda rápido e a solta, a forma de onda continua a se mover. Depois, ela se move mais devagar e para. |
| **Atualizar com os dados mais recentes ao parar o modo repetitivo** | Quando você para uma captura no modo **Repetitiva**, o aplicativo mostra os dados da última captura, que não está completa. |
| **Rolar automaticamente até os dados mais recentes** | No modo stream, a forma de onda se move para mostrar os dados mais novos. |
| **Exibir a posição do gatilho no centro** | No modo osciloscópio, o aplicativo mostra a posição do gatilho no meio da janela. |
| **Exibir a sessão na barra de título** | A barra de título mostra o nome do arquivo de sessão. |
| **Tamanho da fonte** | O tamanho do texto na área da forma de onda. |

## Opções de log

O aplicativo pode registrar um arquivo de log. O arquivo de log ajuda a encontrar a causa de um problema.

1. Clique em **Ajuda** › **Opções de log**.
2. Selecione um valor de 0 a 5 em **Nível de log**. Um valor mais alto registra mais mensagens.
3. Selecione **Salvar em arquivo**.
4. Para adicionar as mensagens novas ao fim do arquivo de log que você já tem, selecione **Modo de anexação**.
5. Clique em **OK**.

Para ver o arquivo de log, clique em **Abrir** na janela **Opções de log**. Para apagar o arquivo de log, clique em **Limpar**.

## Relatar um problema

Clique em **Ajuda** › **Relatar erro**. O aplicativo abre a página de problemas do projeto no seu navegador da web. No seu relatório, informe a versão do aplicativo, a versão do macOS e o modelo do dispositivo. Se possível, anexe o arquivo de log.
