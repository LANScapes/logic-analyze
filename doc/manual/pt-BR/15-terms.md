# Nomes e verbos técnicos

Cada um destes nomes técnicos tem um só sentido neste manual. Cada versão deste manual em outro idioma usa somente um nome para cada nome técnico.

## Nomes técnicos

| Nome | Definição |
| --- | --- |
| aplicativo | O programa Logic Analyze. |
| modo buffer | O modo de operação em que o dispositivo guarda as amostras na sua memória até o fim da captura. |
| captura | Um registro dos sinais, do início até a parada. |
| canal | Uma entrada do dispositivo e a linha que mostra os seus dados. |
| modo de canais | A configuração que seleciona o número de canais e a taxa de amostragem máxima. |
| cursor | Uma linha vertical em um tempo da captura. Você usa cursores para medições. |
| decodificador | Uma parte do aplicativo que lê os dados e encontra os quadros de um protocolo. |
| dispositivo de demonstração | Um dispositivo no aplicativo que gera sinais de teste. Ele não tem hardware. |
| dispositivo | O analisador lógico DSLogic ou o osciloscópio DSCope. |
| painel | Um painel ao lado da área da forma de onda. |
| borda | Uma mudança de um nível baixo para um nível alto (borda de subida) ou de um nível alto para um nível baixo (borda de descida). |
| terra | O ponto de 0 V de um circuito. |
| nível | A condição de um sinal digital: alto ou baixo. |
| ponta de prova | O fio ou a garra que conecta um canal ao circuito. |
| protocolo | A especificação dos dados em um barramento, por exemplo UART, I2C ou SPI. |
| pulso | Um nível entre duas bordas. |
| amostra | O valor de um canal em um tempo. |
| duração da amostragem | O tempo de uma captura. |
| taxa de amostragem | O número de amostras em cada segundo, para cada canal. |
| sessão | Um arquivo com as configurações do aplicativo e do dispositivo. |
| configuração | Um valor que você pode mudar no aplicativo. |
| modo stream | O modo de operação em que o dispositivo envia as amostras ao computador durante a captura. |
| limiar | A tensão que separa um nível baixo de um nível alto. |
| régua de tempo | A escala de tempo acima da área da forma de onda. |
| gatilho | Uma condição nos sinais que marca um tempo na captura. |
| posição do gatilho | A posição do ponto do gatilho na captura, como porcentagem da duração da amostragem. |
| forma de onda | A linha que mostra o sinal de um canal. |
| área da forma de onda | A parte da janela que mostra as formas de onda. |

## Verbos técnicos

| Verbo | Definição |
| --- | --- |
| capturar | Registrar os sinais com o dispositivo. |
| clicar | Pressionar e soltar um botão do mouse. |
| decodificar | Ler dados e encontrar os quadros de um protocolo. |
| dar um clique duplo | Clicar duas vezes rápido. |
| arrastar | Mover um item com o botão do mouse pressionado. |
| exportar | Salvar dados em um formato para um outro programa. |
| pressionar | Apertar uma tecla do teclado. |
| amostrar | Ler o valor de um sinal em um tempo. |
| digitar | Escrever texto com o teclado. |
| ampliar, reduzir | Mostrar uma parte mais curta ou mais longa da forma de onda. |
